# Gyeongnam opening shape

Reuses the highlighted Gyeongnam province path from the WAVE repository's `public/maps/korea-sgis-2020.svg` at commit `89d207e2e0898db721f85b8a2b4e1c977a0a4bb1`. Mainland and islands are preserved; municipal internal boundaries are not added. It is normalized into a particle target, not displayed as a raster image.

Source: [StatGarten SGIS 2020 SVG](https://github.com/statgarten/maps/blob/d5f8ea3208f19a73a01f865847d20cc195ae91ba/svg/simple/전국_시도_경계.svg). This is a simplified 2020 display boundary, not a current surveying/navigation dataset.
