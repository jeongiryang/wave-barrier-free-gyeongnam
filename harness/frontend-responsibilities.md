## 결과를 남기는 최소 단위

`요구 ID / F규칙 → 원 PR·현재 결정 → 바꾼 화면·상태 → 주 담당 판단 → 실제 확인과 증거 → 남은 항목`을 적는다. PR 제목이나 merge 여부만으로 채택을 판단하지 않는다. 미머지 종료라도 통합된 원안이 있고, 머지된 원안도 후속 변경으로 대체될 수 있다. 실제 코드에 진입점이 없지만 제거 의도가 기록되지 않았다면 **의도 불명·후속 확인**으로 남긴다.

단순 글자·간격·색상 수정은 관련 폭/상태의 전후 렌더링으로 확인한다. 상태·인증·비동기 변경은 관련 기존 테스트를 실행하고 필요한 실패 회귀만 추가한다. 같은 증거로 여러 F규칙을 확인할 수 있으면 재사용한다. 이 문서는 새 CI job·모델 호출·주기 감사·전 역할 실행을 추가하지 않는다.
