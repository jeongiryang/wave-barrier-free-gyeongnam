WAVE serves variable WOFF2 subsets of the official font locally. Each block covers
1024 consecutive Unicode codepoints present in the original font; no supported
characters are removed overall. CSS unicode-range loads only required blocks.
Weights 100–900, font-display: swap. The source font is not committed twice.

Generated with FontTools 4.65.0 and Brotli 1.2.0. These are artifact-generation tools,
not application dependencies. No external font requests or extra CSP hosts are used.
