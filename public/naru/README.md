# 나루

2026-09-12 사용자 요청으로 Codex 내장 이미지 생성 도구에서 제작한 WAVE 여행 동행 캐릭터다. 원본의 투명 배경을 유지해 웹 전달용 128px·512px WebP로 압축했다. 원본은 작업 산출물에 보존한다. 외부 유료 API는 사용하지 않았다.

프롬프트: 물결 모양의 민트·라벤더 캐릭터, 친절한 눈과 부드러운 미소, 작은 여행 가방과 나침반 표시, 가볍게 인사하는 전신 자세. 성인과 가족 모두에게 어울리는 차분한 여행 동행자. 단순하고 명확한 3D 클레이 형태, 투명 배경, 로봇·의료 기호·문구·워터마크 없음. WAVE 색상 #b9e8df, #b9a6d8, #2b2632, #6940a6.

상태는 CSS 동작과 별도 한국어 텍스트로 전달한다. 동작 감소 설정에서는 정지한다. 이 캐릭터는 관광 정보의 출처나 안전 인증을 뜻하지 않는다.
