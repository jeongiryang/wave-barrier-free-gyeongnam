## 제출 기능 보존

Notion 원본 보관의 제출확정 기능설명서와 로컬 `WAVE_기능설명서_제출확정본_2026-09-21.pdf`의 SHA-256은 `19ae06e7cc5478edb1317708d5e9cf3fa02c7a5e6e1875084983c2bde56edd1b`로 일치한다. `harness/submission-pages.json`의 31쪽과 `harness/features.json`의 79개 요구를 기준으로 한다. 연결된 검사 파일 150개가 존재하는 사실은 실행 통과를 뜻하지 않는다.

- 나루 첫 화면에서 일정 준비 폼 진입이 빠진 것을 복구했다. ‘여행 처음 만들기’는 지역·날짜·동행을 입력하여 일정안을 요청하는 기존 폼을 연다. AI 연결이 없는 경우 직접 도구로 계속한다.
- 장소 상세는 기본정보·이용과 편의·후기, 방문 전 문의, 현장 화면 대화, 도움 요청, 음성·대본, 담기를 보존한다. 나루를 닫지 않고 겹쳐 열고 돌아온다.
- 나루 안팎의 검색·일정 도구는 같은 portal host를 이동시킨다. 대상 host를 바꾸어 컴포넌트를 재생성하는 방식으로 초안을 지우지 않는다.
- 사용자 요청의 카드 도착 표시는 **이동만 누적한 시각**이다. 제출본 14–15쪽의 체류·휴식·고정 방문을 반영한 실제 시간표는 별도로 유지하고 ‘방문 시간표’에서 확인한다. 운영시간 점검·저장·캘린더의 기존 시간 계산을 단순 이동 시각으로 덮지 않는다.
