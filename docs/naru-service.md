# 나루 운영과 품질 확인

나루는 WAVE의 여행 가이드다. 글이나 음성을 문자로 확인해 보내면 무료 자체 운영 모델이 작업 의도를 해석한다. 실제 코스는 관광지 ID·편의 근거·방문 정보·날씨·축제 날짜를 서버가 조회해 구성한다. 모델이 장소·시설·경로를 만들어서 저장하지 않는다.

## 실행 경계

브라우저 → same-origin `/api/assistant` → 인증된 WAVE 게이트웨이 → DSW의 전용 Ollama 순서로 연결한다. `/api/assistant/journey`가 실제 관광 데이터를 확인하고 단계별 진행과 일정안을 전달한다. 브라우저는 사용자가 확인한 변경안만 현재 여행에 반영한다. 같은 날의 이동 구간은 별도 경로 API에서 확인한다.

2026-09-12 구성은 Ollama 0.34.0, Gemma 4 26B Q4_K_M, 8K 문맥, 의도 구조화 온도 0이다. API 요청과 실제 게이트웨이 옵션을 함께 맞췄다. DSW의 A6000 4장 중 WAVE에 지정한 1장만 사용하며 다른 작업을 종료하지 않는다. 모델 상주는 응답 지연을 줄이기 위한 설정이다. 추가 GPU 또는 무료 모델 교체는 같은 평가에서 품질·지연·메모리 병목이 드러난 뒤 판단한다.

- `~/wave-naru` 아래 전용 서비스와 제한된 권한의 환경 파일을 사용한다.
- Ollama와 게이트웨이는 각각 루프백 18764·18765에서 동작한다. Ollama를 공개하지 않는다.
- 공개 연결은 운영자가 소유한 별도 Tailscale 등록과 HTTPS Funnel이다. 타인의 연구실 Tailscale 계정이나 관리자 승인을 사용하지 않는다.
- Vercel 서버 환경의 AI base URL·모델·인증 토큰만 연결한다. 인증 토큰·계정 비밀번호는 코드, 문서, 브라우저 번들에 넣지 않는다.
- 게이트웨이 무인증 요청은 거부한다. 타임아웃·입력 크기·동시 작업 수·속도 제한을 적용하며 질문과 답변을 로그나 DB에 남기지 않는다.
- 모델/게이트웨이 장애는 나루의 재시도와 직접 편집으로 복구한다. 관광 API 실패와 모델 실패를 같은 상태로 설명하지 않는다.

## 같은 여행을 유지하는 규칙

직접 편집과 나루는 같은 날짜·순서·체류·휴식·고정 방문을 사용한다. 변경안 도착 전 사용자가 조건이나 일정을 바꾸면 오래된 안의 적용을 막는다. 적용한 안은 상태가 유지되는 동안 되돌릴 수 있다. 다른 계정 여행을 열 때는 현재 여행을 기기 여행집에 보관하고 새 값을 한 번에 교체한다. 저장 공간이 부족하면 원래 일정을 덮어쓰지 않고 복구 안내를 한다.

필요한 편의는 결과를 늘리려고 자동 해제하지 않는다. 공식 정보에 없는 시설은 미확인, 명시적 부재는 불일치, 조회 실패는 제공처 문제로 구분한다. 실내 대안은 이름만 보고 정하지 않고 공식 소개의 공간 근거를 확인한다. 축제는 실제 개최 기간 안에만 넣으며 기존 여행 날짜를 조용히 바꾸지 않는다.

## 반복 가능한 모델 평가

개발 서버에서 `node scripts/evaluate-naru.mjs`를 실행한다. 특정 범주는 `node scripts/evaluate-naru.mjs wheel,senior,festival`처럼 고를 수 있다. 명시적으로 승인된 배포를 검사하려면 `WAVE_EVAL_BASE`를 지정한다. 실제 LLM·관광 제공처를 호출하므로 일상 단위 검사나 모든 Actions에 넣지 않는다. 입력은 합성 방문자 요청이며 결과는 표준 출력의 JSON으로 남는다. 약 6.2초 간격으로 실행해 서비스 제한을 존중한다.

일반·휠체어·고령자·임산부·영유아·시각·청각·비·축제·다일·수정·삭제·빈 결과·API 오류의 14개 범주와, 실제 일정 적용 뒤 이동수단·날짜·출발시각·휴식·두 번째 장소 삭제의 후속 대화 5개를 비교한다. 의도만 성공했다고 코스 완성을 PASS로 세지 말고 실제 장소·날짜·편의·고정 방문·적용/복원과 경로를 함께 검사한다. 실패 분기의 강제 주입은 별도 E2E에서 한다.

이번 평가에서 조건을 말하지 않았는데 모델이 지역·이동수단·날짜 기본값을 채우는 문제를 발견해 사용자 발화와 현재 상태로 다시 검증했다. 부모님의 보행 부담, 주말·요일 날짜, 축제의 실제 개최일과 기존 일정 대체도 보강했다. 후속 요청은 바꿀 항목만 적용하고 아이 동행·유아 편의 직접 요청을 보존하며, 말하지 않은 피로 사유로 방문을 줄이지 않는다. 실제 의도 응답은 대체로 1초 안팎, 관광 정보 확인은 대체로 수 초였으며 모델·GPU 확대가 필요한 병목은 확인되지 않았다. 제공처 지연이나 미확인 시설은 모델 크기로 해결하지 않는다.

- 진주성 `126833`의 우천 대안: 진주남강유등전시관 `3429810`. 실내 공간 근거와 미확인 휠체어 편의를 함께 표시했다.
- 아라가야문화제 `3377089`: 2026-09-18–20의 실제 행사 기간을 확인하고 함안박물관 `130693` 등 주변 방문과 연결했다.

사례는 2026-09-12의 조회 결과이며 이후 제공처 값의 보증이 아니다. 배포별 최종 증거는 해당 PR과 [제품 검증 기록](product-upgrade-20260912.md)에 연결한다.
