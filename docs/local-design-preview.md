# 실제 공개 데이터로 로컬 디자인 확인

Node.js 22.13 이상 및 ASCII 경로의 프로젝트에서 의존성을 설치한 뒤 실행합니다.

```sh
npm run dev:preview -- --port 4183 --strictPort
```

http://127.0.0.1:4183 에서 로컬 프론트를 확인합니다. 화면 수정은 자동으로 반영됩니다.
공개 게시글 목록·상세, 관광정보, 축제, 날씨 등 기존 허용 목록의 GET 요청만 WAVE Production API를 사용합니다.
응답을 정적 예시로 바꾸거나 저장소에 복제하지 않습니다. 제공처 오류도 실제 상태 그대로 표시합니다.

로그인, 개인 여행, 글 작성·수정·삭제, 나루 요청은 로컬 서버에 남습니다. 해당 기능의 실제 실행에는 별도 로컬 백엔드 설정이 필요합니다.
운영 서비스의 인증 쿠키나 비밀키를 로컬로 복사하지 않습니다. 일반 `npm run dev`는 공개 API 연결 없이 기존 로컬 동작을 유지합니다.
