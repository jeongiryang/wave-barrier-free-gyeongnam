## 2쪽: 서비스 소개

### 서비스 개요

W.A.V.E는 필요한 편의시설을 기준으로 경남 여행지를 찾고, 공식 관광정보의 확인 범위를
살펴 일정과 이동을 계획하는 Web 서비스다. 여행자는 장소별 편의정보에서 확인된 내용과
추가 확인이 필요한 내용을 구분한 뒤, 방문 날짜·순서·이동 구간을 직접 정하고 출발 전
정보를 다시 확인한다.

### 주제 선정 이유

여행지의 사진이나 인기만으로는 나에게 필요한 편의를 판단하기 어렵다. 휠체어 이용,
걷기 부담, 영유아 동반, 임산부, 시각·청각 지원 등 필요한 편의가 달라지고, 관광지의
시설 정보만으로 출발지부터 목적지까지의 이동을 판단할 수도 없다.

W.A.V.E는 여행자의 필요를 먼저 묻고 공식 정보에서 확인할 수 있는 항목을 보여준다.
장소 선택 이후에도 날짜별 일정, 이동 정보, 날씨와 출발 전 확인을 연결해 여행자가
부족한 정보를 알고 다음 결정을 내리도록 돕는다.

### 이용 대상과 로그인

이동이나 관광지 이용에 필요한 편의를 미리 확인하려는 여행자와 동행자가 이용한다.
장애·건강 상태를 진단하거나 분류하지 않으며 사용자가 직접 선택한 시설 조건을 다룬다.
관광 탐색, 일정 편집, 지도, 출발 전 확인, 이 기기 저장과 공유는 로그인 없이 이용한다.
공개 여행 후기는 로그인 없이 읽을 수 있다. 커뮤니티 글·댓글·좋아요·신고에는 계정이 필요하다.

## 5쪽: 경상남도 지역특화

특화 지역은 **경상남도**다. 경남 18개 시·군을 지도와 텍스트 목록에서 선택하고

특정 광역자치단체 안의 여러 기초자치단체라는 공지의 지역 범위에 해당한다.

### 1. 필요한 편의로 경남 여행지 찾기

지역과 여행 주제, 필요한 편의를 선택한 뒤 사용자가 검색을 실행한다.
결과는 선택한 조건과 공식 관광정보를 연결해 보여주며, 조건이 바뀌면 다시 검색해
현재 선택에 맞는 결과를 확인한다.

흐름: 지역 선택 → 여행 주제·필요 편의 선택 → 검색 실행 → 장소 결과 확인

화면: [#353 Production 기능 1 캡처 대기]

### 2. 공식 편의정보의 근거 확인

장소 상세에서 편의항목의 원문과 확인 상태를 살펴본다. ‘확인됨’은 공식 데이터에
해당 편의가 기재됐다는 뜻이며 ‘미확인’은 제공된 정보만으로 판단할 수 없다는 뜻이다.
시설 없음이나 이용 불가로 기재된 항목은 불일치로 구분한다.
필요한 편의의 긍정 근거가 있는 현재 추천 장소를 일정에 담을 수 있다.

흐름: 장소 선택 → 편의항목·원문 확인 → 출처·조회 시각 확인 → 일정에 추가

화면: [#353 Production 기능 2 캡처 대기]

### 3. 날짜별 일정과 이동 편집

장소의 방문 날짜와 순서, 하루 시작 시각을 직접 바꾼다. 순서 변경은 드래그 외에
버튼과 키보드로도 조작할 수 있다. 지도와 이동 정보에서 조회 대상 날짜·출발지·목적지를
확인하고, 제공기관이 반환한 경로와 W.A.V.E의 추정값을 구분해 읽는다.
한 구간의 조회 결과를 일정 전체의 이동 확인으로 간주하지 않는다.

흐름: 장소 담기 → 날짜·시각 배정 → 순서 편집 → 이동 구간·수단 선택 → 결과 확인

화면: [#353 Production 기능 3 캡처 대기]

### 4. 출발 전 정보와 상황 변화 확인

날씨, 관광 집중률, 교통과 장소 편의정보의 조회 상태를 한곳에서 확인한다.
조회에 실패했거나 정보가 없는 항목은 재확인 대상으로 남긴다. 날씨와 혼잡 예측이
일정에 줄 수 있는 영향을 살펴보고, 다른 장소나 방문 순서를 비교한 뒤 사용자가 일정을 수정한다.

흐름: 출발 전 확인 열기 → 출처별 조회 상태 확인 → 영향·대안 비교 → 사용자 일정 수정

화면: [#353 Production 기능 4 캡처 대기]

### 5. 여행 보관·공유와 현장 경험 연결

내 여행집에 일정을 보관하고 같은 브라우저에서 다시 열어 편집한다. 공유 링크는
선택 조건과 공식 장소 식별자를 바탕으로 여행을 다시 구성한다. 장소에 연결된 공개 후기는
작성자의 현장 경험으로 읽을 수 있으며 공식 편의정보와 별도로 표시한다. 후기 작성에는 로그인이 필요하다.

흐름: 여행집에 보관 → 다시 열기·편집 / 공유 링크 만들기 → 장소별 공개 후기 확인

## 7쪽: KTO OpenAPI 활용

한국관광공사의 관광·무장애 정보를 지역과 장소 탐색의 근거로 활용한다.
원천 응답에서 읽은 시설 정보와 W.A.V.E가 계산한 추천 정렬 기준을 구분한다.

| 핵심 API | 코드상 서비스·operation | 서비스 활용 내용 |
| --- | --- | --- |
| 무장애 여행정보 | `KorWithService2 / areaBasedList2, detailWithTour2` | 지역 관광지 탐색, 접근로·주차·화장실 등 장소별 편의 원문과 확인 상태 |
| 국문 관광정보 | `KorService2 / areaBasedList2, detailCommon2, searchKeyword2, searchFestival2` | 관광지 이름·주소·좌표·소개·이미지와 국문 관광 탐색 |
| 영문 관광정보 | `EngService2 / areaBasedList2` | 영어 화면의 지역 관광정보 |

위 표는 코드상 활용 범위다. 최종 제출 목록은 실제 인증키의 개발기간 호출 이력과
#353 이후 Production의 화면 표출을 함께 대조해 확정한다. 코드에 존재하는 operation을
모두 운영 검증 완료로 표시하지 않는다.

관광사진, 오디오 가이드, 두루누비, 중심·연관 관광지, 관광 집중률, 방문 통계와
기타 관광 보강 API는 [API 감사](../api-integration-audit.md)의 목록에서 최종 배포의
호출·표출 증거가 확인된 항목만 추가한다. 과거 응답을 현재 정상 상태로 재사용하지 않는다.
정확한 호출 위치는 `server/tourism/`와 `server/shared/tourism-provider.ts`에서 대조한다.

### 원천 정보와 W.A.V.E 계산

| 구분 | 의미 |
| --- | --- |
| 공식 편의 원문 | 한국관광공사가 제공한 해당 시설 항목의 내용 |
| 확인 상태 | W.A.V.E가 원문을 확인됨·불일치·미확인으로 구분한 결과 |
| 추천 정렬 | 중복 제거한 전체 선택 편의항목 중 긍정적으로 확인된 항목의 비율 |
| 정보 확인 범위 | 전체 선택 편의항목 중 긍정 또는 부정 정보가 있는 항목의 비율 |
| 조회 시각 | W.A.V.E가 정보를 조회한 시각. 제공처의 시설 갱신일과 다름 |

산식 근거는 `lib/accessibility-score.js`, `server/tourism/accessibility-model.ts`와
`features/planner/components/PlaceEvidenceSummary.tsx`다. 추천 정렬에는 사진·인기·후기를
합산하지 않는다. 알려진 항목이 하나도 없으면 점수는 미확인으로 남는다.
긍정 근거가 없는 장소는 일반 추천과 일정 추가에서 제외한다.
이 계산은 한국관광공사의 접근성 인증, 현장 조사 결과나 여행 안전 확률이 아니다.

출처는 `출처: ⓒ한국관광공사` 또는 `출처: ⓒ한국관광콘텐츠랩`으로 표시한다.
W.A.V.E는 독립적으로 운영하는 서비스이며 공사 공식 서비스로 표현하지 않는다.
관광 원본 응답 전체를 서비스 DB에 복제하지 않는다. 응답 캐시, 기기 일정 보관과
공유 여행 저장은 각각 별도의 처리 범위이며 API별 이용 조건과 대조한다.

인증키는 저장소·기능설명서·캡처에 넣지 않는다. 실제 활용 API와 신청자별 인증키는
공식 제출 화면에서 비공개로 대조한다. 대표 API 1개의 운영계정 신청은 공식 안내의 선택 사항이다.

해제 여부가 확인되지 않은 동안 대중교통 전체 정상화나 조회 성공을 주장하지 않는다.
제한 중에는 성공 화면을 만들기 위한 반복 조회를 수행하지 않는다.

## 9쪽: 차별성·발전계획

### 서비스 차별성

W.A.V.E는 여행자의 필요에서 탐색을 시작하고 공식 정보로 확인한 내용과 아직 모르는
내용을 함께 보여준다. 장소별 시설 정보, 날짜별 일정, 구간별 이동과 출발 전 확인을
연결하되 각각의 확인 범위를 유지한다. 여행자는 추천 이유를 원문과 항목 수로 살펴보고
직접 일정을 수정할 수 있다. 현장 후기는 공식 시설 정보와 별도로 읽으며 후기나 사진이
편의 근거의 계산을 바꾸지 않는다.

### 현재 한계

공식 데이터에는 누락과 갱신 지연이 있을 수 있다. 시설 정보가 있어도 실제 운영 여부와
개인별 이용 가능성을 보장하지 않는다. 저상버스, 경사, 승강기 운휴 등 이동 전 구간의
접근성 정보가 모두 제공되는 것은 아니다. 외부 API의 승인 범위·이용 한도·응답 상태에 따라
조회 가능한 정보가 달라진다. 조회 실패·정보 없음·예측값은 확인 완료로 바꾸지 않는다.
자동 접근성 검사는 실제 장애인 이용자와 화면 낭독기 검수를 대신하지 않는다.

### 개인정보와 위치정보

여행 조건, 저장 장소, 일정과 내 여행집은 이 브라우저에 보관한다. 사이트 데이터를 삭제하면
함께 사라지며 서버에서 복원할 수 없다. 공유 여행은 선택 조건·날짜·장소 식별자와
출발지 표시 이름 등을 서버에 30일간 보관한다. 정밀 현재 위치를 공유 URL이나 공유 데이터에
넣지 않는다. 계정과 공개 커뮤니티 데이터는 기기 저장 여행과 별도로 처리한다.

현재 위치는 사용자가 버튼을 누르고 브라우저 권한을 허용할 때만 사용한다.
현재 위치를 출발지로 선택한 상태에서는 W.A.V.E 경로 API 요청을 차단한다.
공개 거점이나 지도에서 직접 선택한 지점의 경로는 Kakao·ODsay에 요청한다.
지도 SDK·타일과 사용자가 실행한 주변 검색에는 화면 영역, 접속 정보나 지도 중심 좌표가
처리될 수 있다. 모든 위치 처리가 기기 안에서 끝난다고 설명하지 않는다.
위치정보 관련 신고·동의 요건은 운영주체의 별도 공식 검토 대상으로 남긴다.

### 발전계획

실제 이용자와 동행자의 사용성 검증을 통해 편의항목의 설명과 일정 편집을 개선한다.
제공처별 정보 갱신과 실패 상태를 점검하고 미확인 항목을 운영기관에 확인하는 동선을
보강한다. 현장 제보 검토, 운영 문의 대응과 데이터 복원 절차를 정비한다.
아직 수행하지 않은 검증과 운영 활동은 완료 실적으로 기재하지 않는다.
