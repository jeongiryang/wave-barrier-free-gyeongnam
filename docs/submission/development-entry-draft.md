## 2쪽: 서비스 소개

- 유형: Web.
- 개요: 필요한 편의를 기준으로 경남 여행지를 비교하고 일정·이동·출발 전 확인을 연결하는 여행 계획 서비스.
- 주제 선정 이유: 관광지의 편의시설과 실제 이동 여건은 서로 다른 정보다. 사용자는 여행지를
  고른 뒤에도 날짜·구간별 교통·운영 상태를 다시 확인해야 한다. W.A.V.E는 공식 관광정보의
  확인 범위와 미확인 항목을 구분하고, 사용자가 직접 선택한 장소를 한 일정에서 확인하도록 돕는다.
- 운영 주소: https://wave-barrier-free-gyeongnam.vercel.app/

## 3쪽: 핵심 기능 목록

1. 경남 18개 시·군·활동·필요 편의를 선택해 관광지 검색.
2. 공식 관광·무장애 정보를 근거로 장소 비교, 편의정보 상세 확인.
3. 장소를 일정에 담고 날짜·순서·시작 시간을 편집.
4. 지도·자동차·대중교통 경로와 날씨·혼잡 정보를 확인.
5. 이 기기에 일정 저장·복원, 공유 링크 및 여행 후기 연결.

운영 중인 기능 범위를 기술한 목록이다. 모든 구간 완료 판정·미래 후기 차단 등 #287 이후 수정은
미배포 상태이므로 수정본 캡처와 최종 설명에 완료형으로 쓰지 않는다. 장애 없는 이동을 보장하지 않는다.

## 5쪽: 경상남도 지역특화

경상남도 18개 시·군을 선택하며 지역별 공식 관광지와 편의정보를 탐색한다.
일정과 경로는 선택한 장소의 날짜·순서와 연결한다. 지역 선택 지도는 출처가 표시된 경계 자산과
텍스트 목록을 제공한다. 특정 광역자치단체 안의 여러 기초자치단체라는 공지의 지역 범위에 해당한다.
가점 적용은 심사기관 판단이며 경남 RTO 특별상 자격을 주장하지 않는다.

## 6쪽: 핵심 기능별 흐름도

공식 양식의 기능명·설명·화면·단계 설명 칸을 유지하고 필요한 경우 최대 5개 기능으로 복제한다.

| 기능 | 흐름 | 화면 증거와 한계 |
| --- | --- | --- |
| 조건별 검색 | 지역 → 필요한 편의 → 활동 → 날짜 → 명시적 검색 | 추천 전 자동 선택·요청이 없는지 최종 배포 확인 |

## 7쪽: KTO OpenAPI 활용

정확한 서비스·operation 목록, 호출 위치, 출력 화면은 [API 감사](../api-integration-audit.md)와
`server/tourism/`, `server/shared/tourism-provider.ts`에서 대조한다. 활용 실적은 실제 인증키의
개발기간 호출 이력과 서비스 화면을 함께 제출기관이 확인한다. 키 값은 이 문서에 쓰지 않는다.

필수 원고: 한국관광공사 무장애 여행정보·국문 관광정보·영문 관광정보로 지역과 장소의
편의 근거를 제공한다. 관광사진·오디오·걷기 코스·관광 집중률 등 보조 제공처는
최종 Production 실호출 및 표출을 확인한 API만 최종 목록에 넣는다.
미검증 API를 단순히 코드에 있다는 이유로 활용 실적으로 기재하지 않는다.

출처 문구는 `출처: ⓒ한국관광공사` 또는 `출처: ⓒ한국관광콘텐츠랩`을 사용한다.
관광 원본 응답은 서비스 DB에 복제하지 않는다. 정확한 캐시·브라우저 저장 경계는 API별로 대조한다.

## 8쪽: 기타 데이터

Kakao 지도·로컬·자동차 경로, ODsay 대중교통 경로, Open-Meteo 날씨,

관광 추천 데이터 출처와 구분한다. 외부 제공처의 이용 조건·도메인 승인은 최종 운영 설정과 대조한다.

## 9쪽: 차별성·발전계획

- 차별성: 필요한 편의를 기준으로 공식 근거와 미확인을 나누어 보고, 장소 선택에서 날짜·이동 확인까지
  이어지는 흐름. 사용자 제보는 공식 점수와 합치지 않는다. 접근 가능성을 임의 백분율이나 안전 보장으로 표현하지 않는다.
- 추천 방식: 선택한 편의항목의 긍정 근거와 알려진 항목 수를 기반으로 비교한다.
  원천 데이터의 누락·갱신 지연 및 이동 경로 접근성 정보 부족이 한계다. 설명과 실제 산식은 최종 코드에서 대조한다.
- 운영 계획: 제공처 실패 모니터링, 출처·정보 갱신 확인, 실제 이용자·화면 낭독기 검수,
  운영자 제보 처리 및 정기 복원 훈련. 시행하지 않은 활동은 향후 계획으로 표시한다.
- 개인정보: 기기 저장과 서버 공유·계정·공개 후기를 구분한다. GPS 출발지의 서버 경로 요청은 차단한다.
  지도 SDK·타일·주변 검색의 외부 처리까지 기기 내 처리라고 주장하지 않는다. 법적 의무는 공식 검토가 남았다.
