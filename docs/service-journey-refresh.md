# 서비스 이용하기 재구성

- 사진 코스 복원은 `/photo-course` 선택형 도구로 분리한다.
- 메인 `/planner`는 `내 여행 만들기`를 최상단 핵심 워크스페이스로 두고 여행 조건 → 추천 여행지 → W.A.V.E ROUTE → 상황·여행정보를 한 흐름 안에 묶는다.
- 기존 `06 믿을 수 있는 여행 추천` 별도 섹션은 제거한다. 출처·상태 정보는 필요한 기능 카드 안에서 계속 표시한다.
- 길찾기 비교는 도보·자전거·대중교통·자동차 기준이며 실제 API 시간이 있는 수단을 최소 예상시간 순으로 보여준다. 직접 계산할 수 없는 수단은 임의 시간을 만들지 않고 카카오맵으로 이어준다.
- 장소 상세는 공식 접근성 정보와 카카오 리뷰 링크에 더해 실제 존재하는 W.A.V.E 커뮤니티 관련 글을 함께 표시한다.
