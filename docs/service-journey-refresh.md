# 여행 계획 사용자 흐름

- 사진 코스 복원은 `/photo-course` 선택형 도구로 분리한다.
- 메인 `/planner`는 여행 조건 → 여행지 → 이 기기 일정·길찾기 → 출발 전 확인의 네 단계로 구성한다.
- 사용자가 `일정에 추가`한 장소만 실제 일정의 기준으로 삼는다. 추천 장소를 다시 조합한 별도 하루 코스는 만들지 않는다.
- 조건을 바꾸면 추천이 자동으로 갱신된다. 수동 조회는 오류 복구 상황에만 제공한다.
- 날씨·혼잡 등 부가 여행 정보와 공급자 진단은 접힌 상세 영역으로 두고, 핵심 네 단계를 먼저 읽을 수 있게 한다.
- 길찾기 비교는 도보·자전거·대중교통·자동차 기준이며 실제 API 시간이 있는 수단을 최소 예상시간 순으로 보여준다. 직접 계산할 수 없는 수단은 임의 시간을 만들지 않고 카카오맵으로 이어준다.
- 장소 상세는 공식 접근성 정보와 카카오 리뷰 링크에 더해 실제 존재하는 W.A.V.E 커뮤니티 관련 글을 함께 표시한다.
