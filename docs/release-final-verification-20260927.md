# 9월 27일 잔여 기능 검증

## 이번에 고친 사용자 영향

- 나루의 지도 도구가 사라진 `#itinerary-map`에 초점을 보내던 문제를 실제 지도 섹션 `#navigation`으로 수정했다. 도구 진입·기능 수행·복귀와 기존 여행 보존을 검사한다.
- 저장 장소 좌표가 모두 정상일 때 좌표 복원 도구가 빈 화면이 되지 않도록, 추가 조회가 필요 없다는 안내와 접근성 미확인 한계를 표시한다.
- 댓글 변경 후 최신 내용을 읽는 동안 기존 게시글을 유지한다. 저장 성공 뒤 재조회만 실패한 경우 저장 실패로 오해하지 않도록 분리해서 안내한다. 인증 주체 변경 시에는 이전처럼 새로 불러온다.
- ODsay·Kakao 경로가 실제 반환됐는데 제공처의 `queryStatus`가 `not-requested`로 남는 오류를 수정했다. 성공·정상 빈 결과·실패 및 검증된 경로 수를 일치시킨다.
- 작은 일정 썸네일에서 사진 미확인 안내가 잘리지 않도록 간결한 두 줄 표시와 접근성 이름을 제공한다. 큰 사진 카드의 상세 안내는 유지한다.

## 실제 제공처·화면 근거

운영 `509bff5`에서 ODsay 앱 7013의 로그인된 계정 화면을 확인했다. 2026-09-27 01:58 KST 활성 Basic, 현재 호출 0/30건이었다. 제한된 두 요청 후 02:02 화면은 성공 호출 1/30건·전체 요청 2건이었다. 키·요금제·계정 설정은 바꾸지 않았다.

첫 743m 구간은 정상 경로 없음이었다. 실제 나루 여행의 통영시립도서관→강구안 구간은 ODsay 대안 3개(20/21/21분, 도보 398/381/398m, 환승 0회)를 반환했다. 경로 조회를 휠체어 통행 보장으로 해석하지 않는다. 이 응답은 정상 경로 반환 근거이며 실제 승차 검증은 아니다.

실제 운영 Kakao 지도 SDK와 35개 타일의 로딩을 확인했다. 같은 SHA의 정확한 공개 장소 쌍에만 위 ODsay 응답을 재생하여 일정의 이동시간 연결을 확인했고, 다른 구간의 추가 제공처 조회는 차단했다. 따라서 지도 SDK는 실제 연결, 재사용한 경로 응답은 재생 검증으로 구분한다.

독립 API 검토는 기존 응답에 더해 시작·종료 health 포함 11개 읽기 요청을 사용했다. 공식 장소 4개 ID·사진·시설 원문·운영정보·축제기간·날씨를 대조했다. Odii/축제 주변 화장실의 정상 빈 결과와 주차 대안 제공처의 502 오류는 구별해 기록했다. 실제 응답을 재생한 화면 검사 6개는 API 추가 호출 없이 데이터 표시와 일정 보존을 확인한다.

## 검증 구성

- `e2e/naru-tool-completion.spec.ts`: 기존 도메인 검사와 연결해 외부 화면으로 나가는 도구의 초점·의미 있는 조작·나루 복귀 공백을 보완한다. 전체 28개 UI 도구 목록을 새로 세는 검사로 완주를 대신하지 않는다.
- `e2e/community-comment-refresh.spec.ts`: 저장 후 재조회 대기·실패 때 본문 유지 및 경합 회귀.
- ODsay/Kakao 관련 단위 검사: 실제 반환 경로 수, 정상 빈 결과, 제한·파싱·연결 검증 실패의 상태 대조.
- 독립 시각 QA: 소개·여행 설계·일정·커뮤니티·축제 5개 화면을 1440/960/390px에서 확인. 실제 API 사진과 합성 화면의 범위를 구분한다.

로컬의 일회성 실제 계정 검증 결과와 민감정보를 제거한 자료는 `harness-results/release-final/`에 보존한다. 최종 CI/Audit/배포 커밋과 배포 후 실증 결과는 PR에 연결한다. 이전 SHA의 근거를 새 SHA의 실제 실행으로 표시하지 않는다.

## 남은 경계

사용자는 현재 실제 휴대전화·화면낭독기를 사용할 수 없다고 확인했다. 가상 모바일·키보드·axe 검사를 실기기나 TalkBack/VoiceOver 실증으로 표시하지 않는다. 실제 데이터가 없는 음원/시설의 정상 빈 응답도 양성 콘텐츠 성공은 아니다. 전체 79개 요구의 출시 판정은 이러한 미확인 범위와 제공처 오류를 포함해 수용 기준별로 판단해야 한다.

## b493e1b 배포 후 확인

[PR #717](https://github.com/jeongiryang/wave-barrier-free-gyeongnam/pull/717)의 main `b493e1b60e11fbc857510851782389267b78c934`에서 [필수 CI](https://github.com/jeongiryang/wave-barrier-free-gyeongnam/actions/runs/36258415224), [CD](https://github.com/jeongiryang/wave-barrier-free-gyeongnam/actions/runs/36258562265), [전체 Release Audit](https://github.com/jeongiryang/wave-barrier-free-gyeongnam/actions/runs/36258417229)가 성공했다. 전체 감사는 단위 1,707개, 브라우저 2,302개 통과 및 의도된 모바일 중복 2개 제외를 기록했다. 이 결과는 이후 추가 수정의 검사를 대신하지 않는다.

- 운영 브라우저 읽기 검사 8개 통과. 실제 로컬 나루 모델의 생성·후속 조정 응답은 약 3.97초/3.71초, 첫 여행 제안까지 전체 UI 시간은 약 8.49초였다. 날짜·공식 장소·120분 방문·고정 방문 보존과 되돌리기를 검증했다. 모델 실패를 일부러 유발하거나 실제 장애 복구 시간까지 측정하지는 않았다.
- 제출용 계정으로 댓글 저장/재조회·공감 유지/취소, 비회원 기기 관심글 저장/해제·수정된 원문의 재조회가 통과했다. 검증용 댓글·게시글은 삭제했고 404를 확인했다.
- 나루 도구 목록에서 저장 버튼으로 진입해 실제 계정에 저장하고, 새 브라우저에서 날짜·방문시간·고정 방문을 복원했다. 작성 중이던 나루 질문도 보존됐다. 검증용 여행만 삭제하고 계정의 기존 여행 목록·수정 버전·내용이 동일함을 확인했다. 인증 대기 중 저장 도구에 진입하면 초점이 누락되는 별도 회귀는 아래 후속 수정 대상이다.
- 원래 창원 대중교통 smoke 조건과 실제 나루 통영 구간 모두 통과했다. ODsay 경로는 각각 4개/3개이며 조회 상태와 결과 수가 일치했다. 계정 한도 확인과 합쳐 [기존 ODsay 보류 #454](https://github.com/jeongiryang/wave-barrier-free-gyeongnam/issues/454)를 종료했다.
- 전체 운영 API smoke는 주차 대안 502에서 중단됐다. 앞선 경로 성공과 전체 API 통과는 구분한다. 원래 제공처 계약 검사에서 한 번에 30,000건을 요청하는 코드가 공식 최대 1,000건을 위반한다는 결함을 발견해 후속 수정 중이다.
- 관광사진의 실제 저작자 `라이브스튜디오`와 촬영월 `201904`는 관광정보 fallback에서 생성되지 않는 값이므로 PhotoGallery 직접 응답 근거로 확인했다. 여좌천·경화역의 추가 Odii 표본도 정상 빈 결과였으며 실제 양성 음원/대본을 확보했다고 표시하지 않는다.

## 운영 검증에서 발견한 후속 보완

주차 요청은 [공식 명세](https://www.data.go.kr/data/15012896/standard.do)의 최대 1,000건과 `pwdbsPpkZoneYn=Y` 필터를 적용했다. 최대 20페이지·동시 2요청·전체 17.5초 안에 총 건수·페이지·고유 ID가 모두 일치한 목록만 사용하고 프로세스 내 24시간 공유 캐시로 중복 다운로드를 줄인다. 중간 오류·상한·불완전 응답은 근처 주차장 없음으로 표시하지 않는다. 안전한 제공처 오류 메타데이터를 보존하며, 독립 QA가 재현한 한도 오류와 명시적 시간 초과의 동시 발생도 모두 남긴다. 실제 502의 원인 코드와 배포 후 복구는 별도 운영 확인 대상이다.

나루 저장 도구는 인증 대기 중 버튼이 비활성 상태여도 활성화되는 변화를 감지해 초점을 전달한다. 기존 5초 관찰 기한은 유지했다. 저장·날짜·지도 관련 데스크톱/모바일 6개 회귀에서 저장 완료와 나루 초안·일정 복귀를 확인했다.

반려동물·웰니스 카드는 주소와 제공된 설명을 함께 보여주며, 설명·조건이 없을 때 미확인 상태를 유지한다. 동일 공식 장소의 운영시간·연락처는 이용시간 확인을 펼친 뒤 조회한다. 실제 여좌천 ID128792의 상시 개방·연중무휴·운영기관 연락처와 천마온천 ID2755780의 05:00–21:00·연중무휴·연락처를 확인했으며, 이를 동반 조건이나 치료 효과의 확인으로 해석하지 않는다. 카드의 밝은 정보 패널과 야간 테마 간 글자 대비 충돌도 보완했다.

독립 연속 과업은 검색→나루 담기·의도한 되돌리기→503 뒤 재전송→일정 지정→기기 저장까지 18행동, 예정하지 않은 되돌아감 0회였다. 합성 응답의 최초 반응·복구 계측과 실제 모델 성공 시간은 분리했다. 실기기·실제 모델 장애 복구를 합성 검사의 성공으로 대신하지 않는다.
