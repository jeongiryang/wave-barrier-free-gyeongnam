## 목적

`PlannerPage`에 남은 API health, 지역 날씨, 관광 확장 데이터의 상태·요청·취소와
race 방어를 독립 controller hook으로 이동한다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 모두 점진 분리하고 검증·병합·배포까지 완료하도록 위임
- AI: 외부 신호 상태·side effect 이동, 회귀 테스트와 PR 처리

## 구현

- `usePlannerSignals`가 health, weather, enrichment 상태와 loading을 소유한다.
- enrichment 요청은 이전 요청을 abort하고 현재 controller가 아닌 응답을 무시한다.
- 지역 변경 weather 요청은 독립적으로 실패하며 관광 plan과 route를 막지 않는다.
- Planner page는 반환된 신호를 일정 영향과 사용자 표현에 조합한다.
