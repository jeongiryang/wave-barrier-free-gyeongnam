# PR-192 — 랜딩 미리보기의 두 테마 글자 대비 보강

## 목적

PR #189와 #191 이후에도 랜딩 화면에 남은 밝은·어두운 테마의 글자 대비 미달을
정리한다. 소개 화면의 작은 안내문뿐 아니라 실제 기능 흐름을 설명하는 조건·일정·
경로·상황 대응 미리보기가 WCAG 2 AA 본문 기준 4.5:1 이상을 유지하게 한다.

## 원인

- 밝은 화면의 `SCROLL`, 다섯 개 `.preview-note`, 접근성 정보 안내문이
  `3.05~4.23:1`에 머물렀다.
- 어두운 화면에서는 상위 미리보기 표면만 어두워지고 일정 배지·활성 경로 카드처럼
  안쪽의 밝은 표면이 남았다.
- 민트 배지와 고정 초록 핀은 테마 토큰이 뒤집힌 뒤 밝은 글자와 조합됐다.
- 지역 미리보기와 여행 데이터 신호 노드는 반투명 흰 표면을 유지하면서 글자 토큰만
  밝게 바뀌었다.

## 변경

- `landing-foundations.css` — 밝은 화면 스크롤 안내 색을 보강한다.
- `landing-explorer.css` — 지역 미리보기 보조문 색과 어두운 화면의 반투명 카드·
  신호 노드 표면을 함께 조정한다.
- `landing-stories.css` — 미리보기 안내문, 접근성 설명, 일정 배지, 활성 경로,
  상황 대응 배지와 경로 핀의 전경·배경 쌍을 두 테마에 맞춘다.
- `landing-theme-contrast.spec.ts` — 관련 선택자 전체를 밝은·어두운 화면 및
  데스크톱·모바일 프로젝트에서 실제 계산해 4.5:1 이상인지 검사한다.

## 설계 판단

글자색만 일괄 변경하지 않았다. 어두운 화면에서 밝게 남은 하위 표면은 주변 미리보기와
같은 짙은 청록 계열로 내리고, 의도적으로 밝게 유지한 민트 배지는 짝이 되는 어두운
글자 토큰을 썼다. 고정 초록 핀은 테마에 따라 바뀌지 않는 배경이므로 흰 글자를
명시해 5.02:1을 확보했다.
