# PR 134 — 지역 캐릭터 데이터와 SVG 렌더러 분리

- 경남 18개 시·군 캐릭터의 브랜드 데이터와 SVG 렌더링 구현을 독립적으로 관리한다.

- 지역 캐릭터 테스트가 구성 데이터의 18개 지역과 렌더러 연결을 각각 검증한다.
