## 목적

한 화면에 조건·추천·일정·지도·교통·상황 정보가 모두 이어지는 플래너에서 처음 온
사용자가 다음 행동을 찾기 어려운 문제를 줄인다. 기존 깊은 기능을 삭제하지 않고,
질문 하나씩 따라가는 집중 보기와 모든 도구를 펼치는 전체 보기를 함께 제공한다.

## 역할 구분

- 사람: 역대 공모전 수상작을 참고해 W.A.V.E에 맞는 기능·UI/UX와 README 소개를
  적용하고, 기존 UI를 고수하지 않는 제품 개선 방향을 승인했다.
- AI: Issue #225 적합성 검토, 질문형 정보 구조 설계, 코드·스타일·문서·테스트 변경,
  로컬 품질 검사와 PR 작성, CI·배포 확인을 수행한다.

## 구현

- 새 여행자는 `조건 → 여행지 → 일정 → 출발 확인` 중 현재 단계 하나만 본다.
- 단계 제목은 `어떤 여행이 편안할까요?`, `왜 이 장소가 나에게 맞을까요?`,
  `어떤 순서로 움직이면 편할까요?`, `지금 출발해도 괜찮을까요?`로 연결한다.
- 한 단계씩/전체 보기 전환과 기기 내 보기 방식 저장을 제공한다.
- 데스크톱 고정 레일, 모바일 44px 하단 탐색, 키보드와 동작 감소 계약을 유지한다.
- README 1분 소개와 수상작 참고 적용 기록에 실제 새 흐름을 반영한다.

## 검증

```text
npm run lint          통과
npm run typecheck     통과
npm test              219 pass / 0 fail
npm run build:vercel  성공
```

질문형 단계 전환과 전체 보기 복귀 Playwright 시나리오를 추가했다. 로컬 Chromium
다운로드가 네트워크 타임아웃으로 끝나 실행 자체는 시작되지 않았으며, GitHub CI의
설치된 Chromium 결과를 병합 조건으로 사용한다.
