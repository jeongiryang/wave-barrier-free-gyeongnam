# PR-120 — 도움말 focus와 spotlight 분리

## 목적

도움말 controller에 단계 상태, dialog focus trap, scroll·resize·highlight geometry가 함께 있던 구조를
접근성 수명주기와 시각적 spotlight 수명주기로 분리한다.

## 변경

- Escape·Tab focus trap·이전 focus 복원을 `useHelpTourFocus`로 이동
- 대상 scroll, highlight geometry, resize observer와 style 계산을 `useTourSpotlight`로 이동
- `useHelpTour`는 단계 선택·이전/다음·열기/닫기 orchestration에 집중
- 통합 접근성·모바일 도움말 회귀 테스트 source 경계 갱신

## 안전성

prefers-reduced-motion scroll, focus 복원, portal dialog semantics, viewport·dialog 겹침 보정,
requestAnimationFrame·ResizeObserver·event listener cleanup을 유지한다.

## 검증

## 영향

키보드 접근성 변경과 spotlight geometry·성능 변경을 독립적으로 검증할 수 있다.
