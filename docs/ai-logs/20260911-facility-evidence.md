## 목적
후보15/23. 장소 상세에서 방문일 기준 항목별 제보를 비교하고, 해당 항목을 고른 후기 초안을 작성한다. 사진은 실제 방문일·설명과 공개 확인 후 등록하며 원본 대신 메타데이터를 제거한 작은 JPEG 두 장까지 저장한다. 기존 공식 점수와 구분하고 신고·수정·삭제 흐름을 유지한다.

## 역할 구분
사람은 모든 후보 구현·merge/deploy를 승인했고 대규모 조작 감사/회귀·리팩토링/제출 점검은 다음으로 미뤘다. AI는 이 기능의 화면/API/추가 DB migration과 안내를 구현한다. 개인 자료를 쓰거나 사용자/카카오 메시지를 보내지 않는다.

## 검증
사진·필수 날짜·공개 확인·한도·메타데이터, 이력 날짜/원문/상충/주장소, 같은 출처·로그인·작성자·본문 크기를 직접 실행하는 단위 검사를 추가했다. 새 기능과 기존 현장 제보 브라우저8건 PASS(초기); 사진 실패 보존·후기 상세·편집 제거와 이력 재시도/이전 기록, 1440/960/390/320 및 axe. 최종 테마 보정 후 typecheck/lint(오류0·기존경고12)/unit857/build:vercel/performance PASS. 최종 변경 기능 E2E8건 PASS, CSS69.99/70KiB·Planner182.87/270KiB. 독립 QA 진행. 전체 제품 조작 감사는 수행하지 않는다.

기존 canonical migration 검사에 새012의 두 문장과 선행008/011의 위치를 명시적으로 추가했고, 공개 SQL 분기 수6→7 및 사진 본문 제한14,000→360,000bytes 계약을 갱신했다. 기존 보호/검사 범위를 줄이지 않았다.

## 결과와 제한
신규 API나 외부 유료 저장소 없음. 사용자 생성 사진은 Neon 저장량·전송에 영향을 주며 최대크기 두 장당 JPEG약240KiB, base64약320KiB. 목록은 사진 본문을 조회하지 않는다. JPEG구조/메타데이터 검사는 완전한 픽셀 인증·방문 인증·얼굴 익명화가 아니다. 사용자 사진/게시글을 실제 운영에 작성하는 검수는 하지 않는다. 전체 조작 감사·회귀 분석/리팩토링·제출 점검 및 #488은 별도 후속 범위다.
