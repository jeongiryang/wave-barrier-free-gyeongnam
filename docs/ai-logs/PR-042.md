# PR #42 AI 작업 로그

## 요청

- 각 지역별 마스코트가 실제로 적용됐는지 검토한다.
- 미적용 상태라면 18개 지역을 빠짐없이 구분해 화면에 반영한다.

## 검토 결과

- 기존 지역 지도는 거창 `🎭`, 창원 `🌸`, 사천 `✈️`처럼 지역별 이모지 한 글자를 사용했다.
- 별도 마스코트 에셋이나 캐릭터 컴포넌트는 없었다.
- 공식 지자체 마스코트의 라이선스와 2차 이용 범위를 확인하지 않은 채 복제하는 방식은 공모전 공개 서비스에 적합하지 않다고 판단했다.

## 변경

- 지역 이야기에서 모티프를 딴 W.A.V.E 오리지널 `RegionMascot` SVG 컴포넌트를 추가했다.
- 18개 시·군마다 색상, 상징 모티프와 별칭을 각각 지정했다.
- 경남 지도 표식, 현재 선택 지역 카드, 공식 사진이 없는 미리보기 화면에 같은 캐릭터를 사용했다.
- SVG는 텍스트 이모지와 외부 이미지 요청 없이 렌더링되며 작은 지도 표식에서도 얼굴과 지역 색을 유지한다.
- hover·active 상태와 선택 카드에 그림자·기울기·확대 효과를 추가하고 기존 동작 감소 정책을 따른다.
- PR #41의 확정 SHA를 고정하고 기능 변경인 이 PR을 `v0.8.0`으로 추가했다.

## 권리·접근성 검토

- 지자체 공식 캐릭터나 상표 이미지를 복제하지 않은 프로젝트 자체 창작 도형이다.
- 버튼의 접근 가능한 이름은 기존 지역명과 이야기 문구를 유지한다.
- 장식용 SVG는 스크린 리더에서 중복 낭독되지 않게 숨긴다.
