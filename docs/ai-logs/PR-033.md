## 목적

지역·테마·편의 조건을 바꿀 때마다 별도의 `공공데이터로 코스 찾기` 버튼을
눌러야 했던 절차를 없애고, 조건 선택만으로 추천 결과가 자동 갱신되게 한다.

## 설계

- 조건 변경 후 550ms 동안 추가 입력을 기다린 뒤 한 번만 조회
- 새 조건이 들어오면 이전 관광 API 요청을 `AbortController`로 취소
- 자동 갱신에서는 사용자의 현재 스크롤 위치를 강제로 이동하지 않음
- 수동 `결과 새로고침` 버튼은 네트워크 재시도 수단으로 유지
- 마지막으로 시작된 요청만 로딩 상태를 종료해 오래된 응답의 UI 덮어쓰기 방지
