# PR 137 — 플래너 위치·상황·예매 행동 분리

## 목적

- 하나의 행동 훅에 섞인 지도 위치 선택, 상황 변화 대응, 공식 예매 보조를 각 사용자 의도별로 분리한다.

## 변경

- `usePlannerPointActions`: 출발·도착 선택과 지도·보강 장소의 경로 연결을 담당한다.
- `usePlannerImpactAction`: 비 예보·관광 집중 변화의 테마 변경과 대안 경로 행동을 담당한다.
- `useBookingRouteClipboard`: 공식 예매 사이트에 사용할 출발·도착 문구 복사를 담당한다.
- `usePlannerActions`는 세 행동 훅을 조합하는 파사드가 됐다.
- 플래너 구조 테스트가 분리된 행동 모듈을 함께 검증한다.
