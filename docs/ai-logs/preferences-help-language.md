## 실제 문제와 수정

- 영어 화면에서도 환경설정·도움말 본문이 한국어였다. KO/EN 선택·화면 색상·동작 감소·앱 설치,
  영어 부분 지원과 원문 데이터 한계, 공개 4페이지 도움말을 번역했다. 한국어/영어만 유지한다.
- guided 플래너의 숨겨진 단계도 도움말 대상에 포함됐다. 실제 화면에 보이는 영역만 안내하고
  조건 단계의 실제 제목을 강조한다. 지역→편의→활동→날짜→명시적 검색으로 설명을 맞췄다.
- 진행 점 그래픽의 generic div에 있던 ARIA 이름은 `role=img`로 의미를 갖게 했다.
- 번역 후 초기 플래너 JS gzip **270.82 KiB > 기존 270 KiB** 예산을 재현했다. 기준을 높이지 않고
  도움말 내용·번역을 사용자가 Help를 요청할 때 import한다. 중복 요청은 잠그고 실패 시 새로고침
  안내를 제공한다. 재진입과 초점 복귀·실패 후 새로고침 복구를 실제 브라우저에서 확인한다.
- 390px 설정 패널 x=-1px을 캡처에서 발견했다. transform을 갖는 헤더 기준으로 fixed 패널의
  양쪽 여백을 설정하고 모바일 언어 선택을 세로 배치했다. 전체 document overflow 0만으로 넘김이
  없다고 판단하지 않고 패널 좌표를 별도 assertion으로 검사한다.

## 검증

- 초기 관련 E2E 52 pass/2 fail: 도움말 진행 그래픽 ARIA 오류. 수정 후 54/54,
  지연 import 실패·복구 추가 후 **56/56**. axe·포커스·숨은 단계·모션·명시적 PWA 설치를 유지했다.
- 기존 한국어 literal source 검사 3곳은 같은 문구와 영어 counterpart를 함께 요구하도록 갱신했다.
  테스트 삭제·새 skip·timeout 증가·성능 예산 변경은 없다.
- 최종 lint/typecheck PASS, unit/contract **280/280**, Vercel production build PASS.
  성능: CSS gzip 68.81/70 KiB, landing JS gzip 112.82/155 KiB, planner JS gzip **268.55/270 KiB**.
  CSS 보정 후 전체 Playwright·axe **279 pass / 기존 skip 1 / 실패 0** (2.2분).
- 320/390/960/1440px × light/dark × 설정/도움말 **16개 캡처**: 한국어 잔여·콘솔 오류·넘침·
  패널 화면 밖 배치 0. 390 설정·960 설정·320 도움말·1440 도움말 화면을 직접 확인했다.
- React 검토: 정적 도움말 코드는 클릭 때 로드하고 캐시한다. locale에 맞는 문구는 render에서 계산,
  기존 focus trap·복귀·reduced motion 계약을 보존한다. 새 모델 API나 서비스는 없다.
