## 요청

- README를 최신 서비스 상태에 맞게 갱신하고 더 보기 좋게 구성한다.

## 변경

- W.A.V.E 로고, 프로덕션·API 바로가기, CI·CD·릴리즈·Node·Vercel 배지를 상단에 배치했다.
- 프로젝트 목적과 공모전 제출 부문·지정과제를 현재 정책 문서와 일치시켰다.
- 실제 운영 기능, 키 설정 기능, 비한국어 Beta, 공개 로그인 비활성 상태를 구분한 기능 표를 추가했다.
- 사용자 흐름과 시스템 구성을 Mermaid 다이어그램으로 정리했다.
- 실시간 OpenAPI, Neon 저장 범위, GPS 비저장 원칙을 명시했다.
- 로컬 실행, 환경 변수 필요도, CI·CD, 릴리즈, 저장소 구조와 협업 규칙을 최신화했다.
- PR #40의 확정 SHA를 고정하고 이 PR을 `v0.7.6` 백필 대상으로 추가했다.

- 환경 변수는 `.env.example`과 실제 서버·인증 코드 사용처를 대조했다.
- 공개 계정 진입점이 제거되고 Neon Auth 라우트와 컴포넌트만 유지된 상태를 반영했다.
- 배포 방식은 `ci.yml`, `cd.yml`, `vercel.json`과 설정 문서를 대조했다.
