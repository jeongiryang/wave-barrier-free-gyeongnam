## 목적

`worker/index.ts`가 관광·공유 일정 orchestration과 함께 좌표 검증, KORAIL·TAGO 조회,
ODsay·Kakao 경로 조립, 지도 설정과 연결 상태 응답까지 직접 소유했다. 교통 경로 계약을
독립 handler로 옮겨 제공기관 변경이 관광·저장 흐름에 번지지 않게 한다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 모두 점진 분리하고 검증·병합·배포까지 완료하도록 위임
- AI: 교통 handler 책임 식별·이동, 회귀 테스트·문서 갱신과 PR 처리

## 구현

- `server/transport/handler.ts`에 경로 좌표 검증과 거리 계산을 이동했다.
- KORAIL·TAGO 맥락 데이터와 ODsay·Kakao 경로 대안 조합을 동일 도메인 경계에 모았다.
- 지도 SDK 공개 설정과 API 연결 상태 응답도 교통·지도 handler에서 제공한다.
- Worker는 URL routing과 관광·공유 일정 orchestration만 유지한다.
