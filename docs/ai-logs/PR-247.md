## 목적

키 존재만 보여 주는 설정 health 응답을 외부 API 정상 동작으로 오해하지 않도록 범위를 명시하고, Production의 핵심 화면·API를 실제로 호출하는 반복 검증을 운영 자동화에 추가한다.

## 역할 구분

- 사람: 외부 API 계정·Secret 제공, Neon 백업·복원과 공모 제출처럼 계정 소유자만 가능한 운영 작업
- AI: 점검 범위 설계, 설정 health 계약 강화, Production 실응답 검사와 GitHub Actions 일정 추가, 회귀·빌드·보안 검증, PR·배포 처리

## 변경

- `/api/health`가 설정 검사임을 `scope`로 밝히고 필수 키 누락 시 HTTP 503을 반환한다.
- 날씨, 장소 검색, 자동차 경로, 국문·영문 관광 추천, 확장 관광정보, 커뮤니티, 인증 세션과 주요 공개 화면을 검사하는 `npm run check:production`을 추가한다.
- 매일 06:00 KST에 같은 검사를 실행하는 `Production API Smoke` workflow를 추가한다.
- 점검 결과에는 응답시간과 성공 항목만 남기고 키·원본 응답은 출력하지 않는다.

- 대상 로직 검사 통과
- `npm run lint` 통과

- 전체 회귀·빌드·성능·보안 감사는 최신 `main` 반영 뒤 다시 실행한다.

## 결과와 제한

- ODsay와 테마휴게소처럼 선택 키가 없는 기능은 실패 조건에서 제외한다.
- Neon 백업 복원과 보호된 Cron 호출은 별도의 관리자 권한·Secret이 필요하므로 공개 점검이 대신하지 않는다.
