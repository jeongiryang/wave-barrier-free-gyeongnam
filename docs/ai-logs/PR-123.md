# PR 122 — 플래너 외부 신호 수명주기 분리

## 목적

- 한 훅에서 함께 처리하던 서비스 상태, 지역 날씨, 여행 보강 데이터 요청을 각 데이터 수명주기별로 분리한다.

## 변경

- `useServiceHealth`: 서비스 가용성 확인과 완료 상태를 관리한다.
- `useRegionWeather`: 지역 변경에 따른 날씨 조회와 로딩 상태를 관리한다.
- `usePlannerEnrichment`: 행사·숙박 등 여행 보강 정보 요청, 취소, 오래된 응답 차단을 관리한다.
- `usePlannerSignals`는 신호 훅을 조합하고 화면의 보강 정보 탭 상태만 소유한다.
- 구조·경쟁 상태 테스트가 분리된 파일을 함께 검증하도록 갱신했다.
