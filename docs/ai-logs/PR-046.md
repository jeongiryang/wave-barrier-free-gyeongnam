# PR #46 AI 작업 로그

## 발견

- README는 비한국어 번역을 Beta로 설명하지만 실제 언어 선택 UI에는 표시가 없었다.
- 긴 언어명이 헤더에서 차지하는 폭을 제한하는 방식이 단순해 선택 상태와 지원 수준을 함께 이해하기 어려웠다.
- 데스크톱 언어·테마·동작 효과 컨트롤의 높이가 40px로 저장소의 44px 터치 목표보다 작았다.

## 변경

- 한국어를 제외한 7개 언어의 선택 항목과 현재 선택 상태에 `Beta`를 표시한다.
- 언어 선택기와 Beta 배지를 하나의 반응형 그룹으로 구성한다.
- 780px 이하에서는 언어 코드 중심의 좁은 선택기를 유지하고, 380px 이하에서는 화면 폭을 위해 시각 배지만 숨기되 선택 목록의 Beta 표시는 유지한다.
- 언어·테마·동작 효과 컨트롤을 전 화면에서 최소 44px로 확대한다.
- 다크 모드에서도 Beta 배지 대비를 유지한다.

## 검증

- 8개 언어 설정 중 한국어 1개만 정식, 나머지 7개 Beta 회귀 테스트
- 780px·380px 헤더 폭 및 44px 터치 영역 정적 검증
- lint, typecheck, test, Vercel production build
