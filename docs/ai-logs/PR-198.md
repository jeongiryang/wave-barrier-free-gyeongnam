# PR-198 — 낮은 혼잡도 범례의 라이트 대비

## 목적

Production의 실제 혼잡도 24%에서만 나타난 `crowd-low` 범례 수치가 라이트
표면에서 대비 4.29에 머무는 문제를 고친다.

## 변경

- 라이트 `crowd-low` 범례색을 `#0e7a52`에서 `#0b7049`로 조정해 실제 합성
  배경 `#cfede2`에서 대비 4.92를 확보한다.
- E2E 공용 fixture를 28%(moderate)에서 24%(low)로 바꿔 공통 4.5:1 검사가
  실제 운영 상태를 포함하게 한다.

## 검증 기준

- lint, typecheck, 165개 단위·통합 테스트, Vercel build
- 데스크톱·모바일 브라우저·접근성 E2E 전체
- 배포 후 Production 라이트·다크 직접 측정
