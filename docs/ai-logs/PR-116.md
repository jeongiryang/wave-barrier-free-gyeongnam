# PR-116 — 공공교통 조회와 표시 모델 분리

## 목적

공공교통 context 파일이 KORAIL·TAGO endpoint 조회, 순차 도착정보 조회, 공급자 상태와 사용자 표시 모델을
함께 소유하던 구조를 provider adapter·view model·orchestration으로 분리한다.

## 변경

- KORAIL·TAGO 기본 조회와 첫 정류장 도착정보 요청을 `public-provider-queries`로 이동
- provider 상태, 인근 정류장·도착·열차·dataset 표시 모델을 `public-context-model`로 이동
- `public-context`는 snapshot 조회와 model 조합만 담당하는 facade로 축소
- 서버 모듈 경계 회귀 테스트 갱신

## 안전성

환경변수 존재 여부, provider별 partial failure, 첫 정류장 기반 도착 조회, 사용 가능한 데이터 우선 표시,
추정하지 않는 missing·error·ready·live 상태를 유지한다.

TAGO endpoint 변경과 사용자용 교통 상태 표현을 서로 독립적으로 수정하고 테스트할 수 있다.
