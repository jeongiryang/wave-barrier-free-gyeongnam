## 바뀐 사용자 경험

18개 지역의 사진 카드를9장씩 두 줄에 배치한다. 충분히 넓고 높은 화면에서는 여행 준비 장면 마지막에 두 줄이 드러나고, 아래로 스크롤하면 위 사진들은 오른쪽·아래 사진들은 왼쪽으로 흐른다. 위로 스크롤하면 반대로 돌아가며 구간이 끝나면 다음 소개로 이어진다. 작은 화면과 모션 감소에서는 두 줄을 각각 직접 가로로 탐색한다. 모든 지역의 전체 사진 앨범, 이전/다음 지역, 일시정지, 지역별 여행 설계 링크를 유지한다.

사진 저작자·한국관광공사·원본 링크는 사진 위에서 읽을 수 있게 두고 흰 하단 블록을 제거한다. Hero/장면의 기존CC 원본·라이선스 글자도 별도 배경 없이 유지한다. 사진 전체의 어두운 그라데이션과 글자 그림자로 읽힘을 보완한다. 우측 섹션 목록과 모바일 이동 선택은 투명하며, 각 항목이 실제로 놓인 사진/밝은 구간을 읽어 글자색을 바꾼다. WAVE 글자는 보존하고 보라색 세 막대 장식만 제거한다.

## 직접 확인한 보정

- 자동 앨범 전환이 필름의 가로 위치를 덮어써12초 뒤 점프하던 문제를 재현했다. 스크롤이 위치를 제어하는 동안 자동 전환은 위치를 옮기지 않고, 사용자가 지역을 고르면 직접 탐색에 우선권을 준다.
-320px에서 긴 사진 출처가 두 줄로 늘며 사진 선택 버튼 하단을 가리던 문제를 재현했다. 모바일 선택기·제목·여행 시작 버튼과 출처의 세로 공간을 분리했다. 버튼 아래5px 클릭과 출처 영역과의 기하 간격을 검사한다.
- 투명 rail의 색을 전체 목록 중앙 한 곳으로 판단하면 서로 다른 구간에 걸친 항목이 읽히지 않았다. 항목별 실제 배경으로 판정하고 장면 전환·화면 크기·모션 감소 변경에 맞춰 갱신한다. 모션 감소에서도 남던 reveal transition을 즉시 표시로 바꿨다.
- 사진 탐색은 현재/다음 앨범만 미리 준비한다. 두 줄의 다른 지역 사진은 native lazy 이미지이며, 새 계약에 맞춰 실제 화면 이미지와 speculative Image() 요청을 별도로 검증한다. 데이터 절약은 미리 가져오기를 하지 않는다.
