  로컬 브라우저 설치 제한으로 미검증
- 후속 회귀 보강: `전체 저장 일정 수`와 `현재 검색 결과에서 저장한 장소 수`를 분리하고,
  예전 일정은 계속 열람할 수 있되 현재 조건의 여행지 선택 완료로 계산되지 않도록 수정
- 후속 로컬 검사: 관련 정적 테스트, `npm run typecheck`, `npm run lint` 통과
- 후속 Playwright 시도: 대상 2개 시나리오의 desktop/mobile 4건 모두 Chromium 실행 파일
  부재로 브라우저 시작 전에 중단. Chromium 다운로드도 네트워크 타임아웃으로 중단했으며,
  제품 실패나 PASS로 기록하지 않고 최신 원격 CI 확인 대상으로 유지
