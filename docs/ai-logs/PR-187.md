# PR-187 — 모바일 지도·지역 표식 최종 조작 영역 보강

## 목적

열린 PR 통합 이후에도 과거 지도 겹침 수정에서 범위 밖으로 남았던 두 모바일 조작성
항목을 실제 main 기준으로 재검토해 마무리한다.

## 재검토 결과

- 지도 상단 명령 버튼은 기본 35px, 지도 유형 버튼은 29px 높이였고 모바일에서도
  그대로였다. 또한 명령 목록은 수평 스크롤이지만 scrollbar를 완전히 숨겼다.
- 랜딩 경남 지역 표식은 모바일에서 최소 높이 32px였다.

둘 다 기능 자체는 동작하지만 손가락 조작에서는 불필요하게 작은 목표 영역이다.

## 변경

- `app/styles/mobile-interaction-hardening.css`
  - 780px 이하 지도 명령 버튼을 최소 44px로 확대
  - 수평 명령 목록에 thin scrollbar와 proximity scroll snap 적용
  - 680px 이하 좁은 화면에서 18개 지역 표식을 최소 44×44px로 확대
  - `touch-action: manipulation`으로 탭 동작을 명확하게 함
- 최종 cascade에서 덮어쓰이도록 `app/layout.tsx`의 마지막 스타일 import로 배치
- `e2e/mobile-touch-targets.spec.ts`
  - 390×844에서 모든 지역 표식이 44×44 이상인지 확인
  - 18개 표식을 실제로 차례로 눌러 이웃 표식이 클릭을 가로채지 않는지 확인
  - 지도 명령 버튼 전체가 44×44 이상인지 확인
  - 명령 목록이 실제 수평 overflow를 가지며 끝까지 스크롤해 지도 공유 버튼에 도달하는지 확인

## 검증 중 발견한 테스트 결함

첫 CI에서는 마지막 검증의 `/공유/` 선택자가 지도 `↗ 공유`와 플래너의
`공유 링크 만들기 ↗` 두 버튼을 동시에 잡아 strict-mode로 실패했다. 제품 동작 실패가
아니었으며 선택자를 `nav.map-command-bar` 내부의 정확한 `↗ 공유`로 한정한 뒤 다시
전체 CI를 실행한다.

## 범위

시각적 지도 좌표와 지역 캐릭터 위치는 바꾸지 않는다. 데스크톱 레이아웃에도 영향을
주지 않으며 680px 이하 좁은 화면에서 지역 표식 조작 영역만 확대한다.
