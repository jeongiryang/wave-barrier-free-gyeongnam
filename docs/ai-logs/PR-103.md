# PR-103 — 지도 여정 action과 shell 수명주기 분리

## 목적

지도 controller에 남아 있던 브라우저 위치·저장·공유·내보내기와 fullscreen·키보드
수명주기를 지도 렌더링 orchestration에서 분리한다.

## 변경

- 위치 이동, 기기 저장, Web Share·clipboard, PNG/JPG 내보내기를 `useMapJourneyActions`로 이동
- fullscreen, Escape 취소, 패널 변화 후 지도 resize를 `useMapShell`로 이동
- `useRouteMapController`는 provider 도구와 renderer 조립에 집중
- 브라우저 platform API가 상위 controller에 다시 섞이지 않도록 구조 회귀 테스트 보강

## 안전성

현재 위치 좌표를 서버나 저장소에 남기지 않는 정책, local-only 경로 저장, 공유 취소
처리, fullscreen fallback, Kakao·Leaflet resize 동작을 유지한다.

## 검증

## 영향

지도 provider·renderer 변경과 브라우저 platform action 변경의 영향 범위가 분리되고,
상위 controller는 지도 기능 조립 역할로 축소된다.
