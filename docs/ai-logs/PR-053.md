# PR #53 · 프로덕션 검색·설치 메타데이터 정합화

## 발견

- Google Search Console 소유권 태그는 있었지만 canonical, robots, sitemap,
  웹앱 manifest와 공유 메타데이터가 없었다.
- README의 다국어 목록에는 실제로 제공하지 않는 스페인어가 적혀 있고
  실제 독일어·러시아어가 빠져 있었다.
- 공유 여행 문서는 최신 contentId 복원 정책보다 포괄적으로만 설명했다.
- 릴리즈 문서의 고정 총계는 자동 릴리즈가 계속 늘어나는 구조와 맞지 않았다.

## 구현

- 프로덕션 URL을 metadata base와 canonical의 단일 기준으로 지정했다.
- Open Graph, Twitter, 검색로봇 지시와 앱 manifest를 추가했다.
- `/api/`와 개인 공유 경로 `/trip/`는 검색 대상에서 제외하고 공개 랜딩과
  여행 설계 화면만 sitemap에 포함했다.
- README의 언어·공유 데이터 정책과 릴리즈 안내를 실제 구현에 맞췄다.

## 검증

- metadata route 타입과 production build 산출 경로 확인
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `git diff --check`

Secret과 외부 서비스 설정은 변경하지 않았다.
