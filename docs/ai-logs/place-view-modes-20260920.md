# 여행지 목록·격자 보기

- 작성자: 정이량 / Codex
- AI 도구: Codex
- 목적: 여행지 찾기의 가로 목록 외에 사진 중심 격자 보기를 제공한다.
- 사람: 보기 형식 전환 요구, 기존 PR·검증·배포 권한.
- AI: 구현, 반응형·접근성·상태 보존 검증, PR 및 운영 검증.

## 구현
- 여행지 찾기 상단의 아이콘과 이름이 있는 목록형/격자형 버튼. aria-pressed와 키보드 조작 지원.
- 추천·편의 미확인·직접 검색 결과에 같은 보기 적용. 기존 장소 상세·담기·비교 상태와 근거 표시 유지.
- 화면 폭에 따라 격자 열 수 조절, 좁은 화면에서는 세로 카드 한 열.
- 여행 데이터와 분리된 로컬 보기 설정. SSR 기본값 목록형, 외부 저장소 구독으로 복원. 저장 실패 시 현재 페이지에서 전환 가능.

## 검증
- 1440/960/390px 실제 렌더링, 사진 비율·버튼 44px·넘침, 키보드 및 axe.
- 선택 장소 보존, 새로고침 후 보기 복원, 직접 검색과 저장 공간 쓰기 실패 합성 브라우저 검증.
- 단위 검사 1,501개 성공. 최종 lint·타입·빌드·성능 및 PR CI 결과는 PR에 기록한다.
- 실제 제공처 데이터를 새로 검증하는 변경은 아니다. 최종 운영 화면은 배포 후 별도 확인한다.
