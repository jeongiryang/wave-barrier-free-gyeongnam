## 통합 수정

- 설정 타입·초기 복원·저장을 합치고 색 구분 보조를 effect/memo 의존성에 포함했다. 설정 변경이 다른 설정 조작 없이 즉시 반영된다.
- native radio 그룹은 선택된 항목 한 개가 Tab 정지점이다. 다른 크기는 기존 Arrow 키 검사로 확인한다.
- 내비게이션 줄바꿈 검사는 장식 SVG 대신 실제 글자 span의 줄을 측정한다.
- 크기 변경 알림은 해당 설정 내부에서 찾는다. 다른 설정의 live region을 잘못 세지 않는다.
- 모바일 상세의 역방향 순환은 하단 닫기 → 오디오 → 도착 미리보기 순서를 확인하고 정방향도 유지한다.
- 지도 출발지 작은 글자의 대비 부족(4.48:1)을 실제 글자색 조정으로 수정했다.
