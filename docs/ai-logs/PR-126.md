# PR 125 — 지도 출발·도착 선택과 경로 비교 화면 분리

## 목적

- 지도 작업공간에 함께 있던 출발·도착 검색, 지도 표시, 경로 비교 책임을 독립 화면 단위로 분리한다.

## 변경

- `TripPointPicker`: 출발지·도착지 검색, 기본 출발지와 추천 장소 선택을 담당한다.
- `RouteComparisonPanel`: 정렬 기준, 로딩·빈 상태, 경로 대안 비교를 담당한다.
- `RouteMapWorkspace`: 지도 툴바와 지도, 두 하위 화면을 조합한다.
- 제품·구조 테스트가 분리된 화면을 함께 검증하도록 갱신했다.
