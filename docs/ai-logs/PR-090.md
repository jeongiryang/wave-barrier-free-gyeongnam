# PR-090 — 랜딩 경험과 섹션 경계 분리

## 목적

랜딩 페이지가 인트로 접근성, 지역 사진 요청, 스크롤 효과, 콘텐츠 데이터와
모든 화면 섹션을 직접 소유하던 구조를 기능별 경계로 분리한다.

## 변경

- 랜딩 인트로, 헤더, 히어로, 가치 제안, 지역 이야기, 근거·CTA·푸터를 컴포넌트로 분리
- 지역·가치 콘텐츠 카탈로그를 `content` 모듈로 이동
- 지역 사진 조회, 스크롤 진행, reveal, view transition을 `useLandingExperience`로 이동
- 내부 페이지 이동을 Next.js `Link`로 통일
- 랜딩 페이지는 기능 조립과 route-level wiring에 집중
- 랜딩 기능 경계와 기존 사용자 흐름을 검증하는 회귀 테스트 보강

## 안전성

인트로의 3-state 판정과 reduced-motion 정책, 지역 사진 timeout/fallback,
기존 카피·DOM class·접근성 의미를 유지한다. API, DB, 인증, 환경변수 변경은 없다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test` (65/65)
- `npm run build:vercel`

## 영향

랜딩 동작과 URL은 유지되며, 이후 섹션 변경의 영향 범위와 테스트 가능성이 줄어든다.
