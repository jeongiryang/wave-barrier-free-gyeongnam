# PR-090 — 랜딩 route와 브라우저 동작 경계 분리

## 목적

랜딩 route가 인트로, 헤더, 스크롤 관찰, 지역 사진 요청과 모든 화면 섹션을
직접 소유하던 구조를 제품 섹션과 브라우저 동작 경계로 분리한다.

## 변경

- `app/page.tsx`를 route-level 조합과 wiring에 집중하도록 축소
- 인트로, 헤더, hero, manifesto, 지역 이야기, closing을 독립 컴포넌트로 분리
- 지역·접근성 정적 콘텐츠를 `content` 모듈로 이동
- 스크롤 진행, reveal 관찰, view transition, 지역 사진 요청을
  `useLandingExperience`로 분리
- 내부 페이지 이동을 Next `Link`로 통일
- 랜딩 위임 구조와 기존 제품 정책을 회귀 테스트에 반영

## 안전성

인트로의 `checking/show/hidden` 사전 판정, reduced motion, focus trap,
지역 사진 요청 취소·timeout과 재시도 동작을 그대로 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

API 응답, DB, 인증, 환경변수, migration 변경은 없다.
