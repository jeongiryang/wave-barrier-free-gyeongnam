# PR-117 — 랜딩 모션과 지역사진 분리

## 목적

랜딩 experience hook이 scroll progress, reveal observer, pointer effect, 지역 선택, 사진 API·retry를
함께 소유하던 구조를 독립 controller와 client 경계로 분리한다.

## 변경

- scroll 방향·progress·reveal·pointer effect를 `useLandingMotion`으로 이동
- 지역 선택·preview·사진 cache·retry를 `useLandingRegions`로 이동
- 지역사진 HTTP 계약을 landing client data layer로 이동
- 기존 `useLandingExperience`는 두 controller를 조합하는 얇은 facade로 축소
- landing 회귀 테스트 source 경계 갱신

## 안전성

prefers-reduced-motion, IntersectionObserver cleanup, 10초 사진 timeout, 실패 후 재시도,
view transition fallback과 HTTPS 서버 사진 정책을 유지한다.

## 검증

- `npm run lint`

## 영향

랜딩 모션 성능을 조정할 때 지역사진 네트워크 상태를 건드릴 필요가 없다.
