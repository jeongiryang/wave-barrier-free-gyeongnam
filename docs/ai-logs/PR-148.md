# PR-148 — Content-Security-Policy에 자원 출처 지시어 추가

## 목적

스크립트 출처를 제한하지 않던 CSP에 `default-src`와 종류별 지시어를 넣는다.

## 문제

기존 정책은 네 가지뿐이었다.

```
base-uri 'self'; form-action 'self'; frame-ancestors 'none'; object-src 'none'
```

폼 전송과 프레임 삽입은 막지만 **스크립트·연결·이미지 출처에는 아무 제한이 없었다.**
주입된 스크립트가 임의의 외부 호스트에서 코드를 불러오거나 데이터를 보내는 것을
막을 수 없다. 이 저장소는 로그인 폼과 사용자 작성 커뮤니티를 함께 운영하므로
이 지시어들이 비어 있는 상태가 특히 아쉽다.

## 조사

정책을 정하기 전에 앱이 실제로 무엇을 부르는지 확인했다.

- 브라우저가 부르는 외부 스크립트는 `dapi.kakao.com`의 지도 SDK 하나뿐이다
  (`features/routing/kakao-sdk.ts`). SDK가 내부적으로 daumcdn·kakaocdn 하위
  도메인을 더 부른다.
- API 호출은 전부 같은 출처의 `/api/*`를 지난다. Open-Meteo, ODsay, 공공데이터
  포털은 모두 서버에서만 부른다.
- 이미지는 한국관광공사가 주는 **임의의 https 호스트**에서 온다. 여기에
  Wikimedia 지도 이미지와 OpenStreetMap 타일이 더해진다.
- Google Fonts나 분석 도구는 앱 코드에서 쓰지 않는다. 번들 문자열에 보이는
  `fonts.googleapis.com`, `us.i.posthog.com`은 의존성 내부 문자열이며 실제로
  호출되지 않는다.

## 변경

```
default-src 'self';
script-src 'self' 'unsafe-inline' https://*.kakao.com https://*.daumcdn.net https://*.kakaocdn.net;
style-src  'self' 'unsafe-inline';
img-src    'self' data: blob: https:;
font-src   'self' data:;
connect-src 'self' https://*.kakao.com https://*.daumcdn.net https://*.kakaocdn.net https://*.tile.openstreetmap.org;
frame-src  'self' https://*.kakao.com https://*.daumcdn.net;
worker-src 'self' blob:;
manifest-src 'self';
```

기존 네 지시어는 그대로 둔다.

## 설계 판단

**`'unsafe-inline'`을 뺄 수 없었다.** RSC 하이드레이션 페이로드가 인라인
스크립트로 들어가고, 현재 Vinext/Nitro 구성에는 nonce를 주입할 지점이 없다.
그래도 지금보다는 낫다. 외부 스크립트 호스트가 카카오 계열로 좁혀지므로
"임의의 호스트에서 코드를 불러오는" 경로는 닫힌다.

**`img-src`는 `https:`로 열어 두었다.** 관광사진 호스트를 목록으로 고정하면
제공기관이 CDN을 바꿀 때 사진이 통째로 사라진다. 무장애 정보를 확인하러 온
사용자에게 사진이 안 보이는 쪽이 더 큰 손해다.

**카카오는 와일드카드로 잡았다.** SDK가 부르는 하위 도메인이 기능(타일,
로드뷰, 검색)마다 다르고 문서로 고정돼 있지 않다. 지도가 깨지는 것보다
`*.kakao.com` 범위를 허용하는 편이 낫다.

## 검증

- `npm run lint` 통과 (경고 0)
- `npm run typecheck` 통과 (오류 0)
- `npm test` 통과 (67/67)
- `npm run build:vercel` 통과
- 빌드 산출물의 외부 출처를 직접 조사해 정책이 앱 자신을 막지 않는지 확인했다.
- 기존 헤더 테스트를 확장해 `default-src` 존재, `script-src`에 전체 와일드카드나
  `'unsafe-eval'`이 없을 것, 카카오 출처 포함, `img-src https:`, `connect-src 'self'`를
  고정했다.

## 남은 위험

**브라우저에서 카카오 지도를 실제로 띄워 확인하지 못했다.** 이 저장소는 Vercel
자체 Git 배포를 꺼 두어 PR 프리뷰가 없고, 로컬에는 카카오 JavaScript 키가 없다.
정적 분석과 빌드 산출물 조사까지가 이번에 확인할 수 있는 범위다.

병합 후 프로덕션에서 지도 화면을 한 번 열어 콘솔에 CSP 위반이 없는지 확인해야
한다. 위반이 나오면 해당 호스트를 `script-src`/`connect-src`에 추가하는 후속
PR로 처리한다.
