# PR #51 · 프로토타입 추천 대체 데이터 제거

## 요청과 판단

외부 관광 API가 느리거나 실패했을 때 코드에 고정된 `demo-*` 장소가 실제 추천
결과 영역에 노출되는 경로를 제품·데이터 신뢰성 감사에서 확인했다. 화면에
미리보기라고 표기하더라도 사용자가 공식 데이터 기반 추천으로 오해할 수 있으므로
production 서비스에는 적합하지 않다고 판단했다.

## 구현

- 창원 기본 화면과 API 실패 시 사용하던 고정 장소·동선 데이터를 제거했다.
- 조건이 바뀌면 기존 조건의 결과를 즉시 비우고 loading skeleton을 표시한다.
- 공식 API 오류와 정상적인 검색 결과 없음 상태를 서로 다른 문구와 ARIA 역할로
  구분했다.
- 오류 상태에서 공식 데이터만 다시 조회하는 44px 재시도 버튼을 제공한다.
- 장소 결과가 바뀔 때 이전 경로·목적지·교통 응답도 함께 초기화해 서로 다른
  조건의 데이터가 섞이지 않게 했다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `git diff --check`

실제 비밀키와 환경 변수는 변경하지 않았다.
