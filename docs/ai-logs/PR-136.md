# PR 135 — 커뮤니티 상세 리소스·공감·댓글 상태 분리

## 목적

- 상세 훅에 섞인 게시글 조회, 공감·삭제, 댓글 작성·편집 수명주기를 독립적으로 테스트하고 변경할 수 있게 한다.

## 변경

- `useCommunityPostResource`: 게시글·댓글 조회와 화면 상태를 담당한다.
- `useCommunityPostEngagement`: 로그인 확인, 공감 반영, 본인 게시글 삭제를 담당한다.
- `useCommunityCommentActions`: 댓글 작성·수정·삭제와 편집 폼 상태를 담당한다.
- `useCommunityDetail`은 세 훅과 세션·복귀 경로를 조합하는 파사드가 됐다.
- 커뮤니티 제품 테스트가 분리된 훅을 함께 검증한다.

## 안전성

- 비로그인 참여 시 원래 게시글로 돌아오는 로그인 경로와 서버 권한 검증 계약을 유지했다.
