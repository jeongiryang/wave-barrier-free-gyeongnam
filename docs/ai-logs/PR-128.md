# PR 127 — 커뮤니티 목록 수명주기와 게시글 저장소 분리

## 목적

- 커뮤니티 필터·인증 링크와 목록 네트워크 상태를 분리하고, 게시글 저장소의 조회·변경·응답 매핑 책임을 독립시킨다.

## 변경

- `useCommunityPostList`: 페이지 조회, 타임아웃, 요청 취소, 로딩·오류 상태를 담당한다.
- `useCommunityBoard`: 검색·카테고리·장소 조건과 로그인 후 글쓰기 경로를 조합한다.
- `post-read-repository`: 목록·상세·댓글 조회를 담당한다.
- `post-write-repository`: 작성·수정·삭제와 쓰기 빈도 제한을 담당한다.
- `post-mappers`: DB 행을 공개 응답으로 변환하고 작성자 권한 표기를 계산한다.
- `posts-repository`는 기존 API import를 보존하는 안정된 파사드가 됐다.
