# PR #69 · 제품 스타일 순차 레이어 분리

- PR: https://github.com/jeongiryang/wave-barrier-free-gyeongnam/pull/69
- 제목: `refactor: 제품 스타일 순차 레이어 분리`
- 작성자: `jeongiryang`
- 최종 상태: 진행 중
- AI 도구: Codex

## 목적

139KB의 `product-experience.css`에 랜딩, 플래너, 지도, 상황 대응과 후속 보정이
한 파일로 이어져 있어 스타일 변경의 탐색 범위가 넓었다. 기존 cascade를 바꾸지
않으면서 연속된 책임 단위로 나눈다.

## 역할 구분

- 사람: 남은 분리 대상을 승인 대기 없이 점진적으로 처리하고 검증·병합·배포까지 완료하도록 위임
- AI: 스타일 경계 감사, 무손실 분리, 회귀 테스트·문서 갱신, 로컬 검사와 PR 처리

## 구현

- 초기 랜딩·플래너 골격을 `product-foundations.css`로 분리했다.
- 도구 중심 플래너 위계를 `planner-workspace.css`로 분리했다.
- 지도·경로·날씨 UI를 `map-experience.css`로 분리했다.
- 상황 대응과 Deep Ocean 최종 보정을 `product-refinements.css`로 분리했다.
- 실제 import 순서를 회귀 테스트로 고정했다.

## 검증

- 분리 전 파일과 네 레이어를 import 순서대로 합친 결과의 바이트 동등성 확인
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 결과와 제한

- CSS 선언과 cascade 순서는 동일하며 의도된 화면 변경은 없다.
- 기능별 후속 수정은 18~51KB 범위의 해당 레이어 안에서 진행할 수 있다.
