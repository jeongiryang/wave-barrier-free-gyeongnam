# PR-118 — 관광 확장정보 query와 표시 모델 분리

## 목적

확장 관광정보 handler가 입력 날짜·언어 해석, 다중 provider orchestration, 방문자 집계, 콘텐츠 변환,
provenance 상태를 함께 소유하던 구조를 query·source·model 경계로 분리한다.

## 변경

- 지역·테마·언어·행사 날짜 fallback을 `enrichment-query`로 이동
- 방문자·수요 집계, 관광 콘텐츠 변환과 provider 상태를 `enrichment-model`로 이동
- `insights`는 query, 기존 enrichment sources, 표시 모델을 조합하는 얇은 orchestration으로 축소
- 서버 모듈 경계 회귀 테스트 갱신

## 안전성

공식 source별 partial failure, 최근 방문자 집계, 8건 제한, 한국도로공사 전용키 미설정 상태,
공식 데이터와 W.A.V.E 표시 모델 구분을 유지한다.
