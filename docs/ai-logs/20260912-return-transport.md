## 목적과 역할
Owner가 승인한 기능 후보를 기존 여행 화면에 통합한다. 저장된 공개 관광지 주변 정류장을 선택하고 같은 노선의 다음 두 차량·진행 방향과 일정의 다음 장소를 비교한다. 개인 GPS·이름·동행자 조건은 교통 조회에 전달하지 않는다. 전체 조작 감사, 회귀 분석/리팩토링, 제출 전 점검은 Owner 지시대로 후속 범위다.

## 구현
공식 KTO ID·경남 법정동 코드·좌표를 검증한 뒤 기존 TAGO 제공처 경계로 정류장/도착/노선을 조회한다. 공개 정보만 bounded warm cache에 보관하며 버튼을 누르기 전·백그라운드 API 호출은 없다. 단일 요청17.5초(클라이언트20초), 자동 재시도·신규 유료 서비스·ODsay 호출 없음. 원자료 오류/빈 응답/부분/노선 순서 중복은 미확인으로 남긴다. 첫차·막차는 기점 출발이며 선택 정류장의 마지막 차로 오인하지 않도록 표시한다.

## 검사와 제한
초안의 순수 모델4건과 실제 handler를 로드한 제공처 seam5건 PASS. 최종 화면/필수 CI/독립 QA/Production은 진행 중이다. 합성 검사는 API 실제 승인이나 지역별 버스 제공 범위의 증거가 아니다. 실제 보행 접근성·차량 탑승 가능·환승·귀가 시각을 추론하지 않는다. 추가 노선 API 승인은 실제 배포에서 별도 확인한다.
