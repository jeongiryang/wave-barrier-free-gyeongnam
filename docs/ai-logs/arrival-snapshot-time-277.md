- Official [TAGO bus arrivals](https://www.data.go.kr/data/15098530/openapi.do) documents `arrtime` as seconds until an arriving vehicle reaches a stop. It is not an absolute timetable. The app's successful `/api/route` response currently shares the 300-second browser / 1800-second edge cache. A displayed relative value therefore needs its original retrieval context.
- Stamp only the successful TAGO arrival retrieval at its existing server call; retain that timestamp in the response. This is W.A.V.E retrieval time, never provider update time. The model does not regenerate timestamps for cached or legacy snapshots; missing/invalid timestamps remain unknown. Missing arrival values and zero are preserved.
