## 목적

사용자가 다시 지정한 전체 목록을 구현한다. 9월 13일의 축약 소개를 최종 요구로 취급하지 않고, 설명 옆 풍경 사진을 유지하면서 기존 문구 구역과 02 여행 준비의 세 장면을 복원한다. 여행 설계의 직접 편집과 나루는 하나의 여행 상태를 사용한다. 사용자의 최신 지시에 따라 이전 로컬 전용 제한을 해제하고 최종 검증·배포까지 수행한다.

## 역할 구분

- 사람: 복원할 소개·Simple is Best·페르소나별 필요·기기 내 GPS·배포 실행을 지시했다.
- 구현: 화면·상태 소유·명령·관광 요청·도움말을 연결하고 실제 API와 DSW 모델 응답을 확인했다.
- 독립 QA: 소개/커뮤니티/GPS, 페르소나/음성, 관광 요청/캐시/취소를 서로 다른 범위로 검증했다. 제공처 응답을 모의한 회귀와 실제 제공처 확인을 구별한다.

## 검증

- 단위 1,239개 통과(추가 회귀 포함), 타입검사·ESLint 오류0, production 의존성 보안 감사 취약점0.
- `npm run build:vercel`, `npm run check:performance` 검증. 기존 CSS gzip70KiB 등 예산을 올리지 않고 퇴역 화면 CSS를 제거했다.
- 페르소나/음성 고유44개 desktop/mobile 합성 브라우저 회귀: 시간 변경·후속 마감·조회 실패·지연 응답·Undo·대본·읽기·단일 질문·검색 취소·음성 권한/정리.
- 소개·커뮤니티·GPS는 독립 브라우저 검증. 최종 전체 desktop/mobile×4 shard 및 sandbox-boundary는 PR `validate`에서 확인한다.
- 실제 로컬 관광 API: 창원 활동 미선택 검색 HTTP200, 약1.5초, 여행지12곳. 이전 429의 계정 한도 종류나 해제 시각은 추정하지 않았다.
- 소개/커뮤니티 고유102개, GPS 고유38개, 혼합 소개/푸터32개로 총172개 desktop/mobile 합성 브라우저 검증을 통과했다. 마지막 밝은 푸터의 GitHub 아이콘 대비 결함도 수정 후 통과했다.
- 실제 DSW 모델: 이동수단·출발시각·휴식·삭제 4건과 시설 비교·피로·귀가·수유·장소정보·문의 6건. `오늘 피곤해`가 미래 여행의 날짜를 오늘로 옮기는 응답을 발견해 날짜 보존을 보강했고, 실제 재검증957ms로 기간 필드가 제거된 정상 제안을 확인했다. 모델/GPU 증설이 필요한 병목은 확인되지 않았다.

## 결과와 제한

실제 생성 모델의 의도 분류, 합성 데이터 기반 브라우저 적용, 실제 관광 목록 응답은 서로 다른 증거다. 예약·전화·결제 완료나 시설 이용·이동 안전을 보장하지 않는다. 새 후보의 PR/CI/CD/Production 결과는 완료 뒤 연결 PR에 구체적 SHA와 실행 URL로 기록한다. 기존 배포 결과를 이번 후보의 결과로 재사용하지 않는다.
