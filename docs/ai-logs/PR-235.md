## 목적

첨부된 서비스 소개 화면 9장을 현재 랜딩과 대조해, 발표 슬라이드처럼 정적인 미리보기를 실제 제품 흐름이 보이는 동적 소개 화면으로 개편한다. 사용자가 첫 화면에서 W.A.V.E가 편의조건을 출발점으로 공식 근거, 일정, 이동, 상황 대응, 여행 기록까지 연결하는 서비스임을 이해하도록 한다.

## 역할 구분

- 사람: 기존 소개 화면 캡처 제공, 지역 이모지 제거·지도 현대화·기능별 동작 시연·공간 활용 개선 요청
- AI: 화면 전수 대조, 정보구조 재설계, 컴포넌트·SVG·CSS 모션 구현, 접근성·동작 감소·반응형 계약과 회귀검사 추가

## 구현

- 기능 소개 순서를 `여행 조건 → 추천 근거 → 하루 일정 → 이동 경로 → 상황 대응 → 여행 기록`으로 정리했다.
- 조건 선택, 근거 상태, 일정 순서, 자동차·보행 이동, 상황 변화, 로컬 여행 기록을 각 섹션 안에서 반복 시연한다.
- 가짜 버튼과 실제 게시글처럼 보이는 미리보기를 제거하고 비대화형 설명용 시각화와 명시적인 샘플 화면으로 교체했다.
- 지역 캐릭터·이모지와 외부 지도 이미지를 제거하고 18개 시·군 텍스트 표식과 자체 SVG 안내 지도를 적용했다.
- 영문 발표형 문구, 공모전 중심 문구, 반복되는 개발용 미리보기 안내를 사용자 가치 중심 한국어로 바꿨다.
- 1440px 이상 화면의 폭을 활용하고 960px·390px에서도 한 열 흐름과 44px 조작 영역을 유지한다.
- 화면 밖 모션을 정지하고 앱의 `효과 줄임` 설정과 OS `prefers-reduced-motion`에서 의미가 남는 정적 상태로 전환한다.

## 결과와 제한

- 소개 화면은 실데이터 조회 화면을 복제하지 않고 기능 작동 원리를 설명하는 데모임을 명확히 한다.
- 지역 지도는 위치 관계를 이해하기 위한 단순화 안내도이며 정확한 항법 지도가 아니다.
- 실제 브라우저 시각 회귀와 Production 반영 여부는 GitHub CI·Preview·배포 완료 뒤 확정한다.
