## 목적

`worker/index.ts`에 남은 관광 검색, 접근성 근거, 사진·집중률·확장 데이터 조립과
공유 일정의 공식 장소 복원 로직을 관광 도메인 handler로 이동한다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 모두 점진 분리하고 검증·병합·배포까지 완료하도록 위임
- AI: 관광 도메인 경계 이동, 회귀 테스트·문서 갱신과 PR 처리

## 구현

- `server/tourism/handler.ts`가 관광 plan, 사진, 집중률, enrichment action을 소유한다.
- 접근성 근거 계산과 공식 장소 변환, 공유 여행의 content ID 복원을 같은 관광 경계에 모았다.
- 지역·테마·프로필·다국어 catalog를 공유 일정 검증에서 재사용할 수 있게 명시적으로 공개했다.
- Worker는 관광 API를 `handleWaveApi`로 위임하며 910줄에서 142줄로 줄었다.
