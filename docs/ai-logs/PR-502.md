# PR #502 AI 작업 로그

사용자의 2026-09-12 최종 제품 고도화 지시와 추가 카드 잘림 수정을 구현한다. 상세 요구/검증은 [제품 기록](../product-upgrade-20260912.md), [시연](../demo-script.md), [나루 운영](../naru-service.md)에 정리했다.

- 사람: 제품 철학·전면 구조 변경·무료 로컬 모델·필요한 연구실 자원·위험에 맞는 검증과 CI 마지막 실행을 지시했다.
- Codex: 제품/저장/AI/지도/축제/계정/오디/문서/CI를 구현하고 실제 브라우저 및 제공처를 확인했다.
- 독립 QA: 제품 구현과 분리하여 순수 경계 검사와 데스크톱·모바일 E2E를 작성했다. 재검색 화면 이탈, 계정 여행의 오래된 입력 적용, 중복 접근성 이름, 홈 순서·버튼 문제를 발견하고 수정 후 검증했다.
- 이미지: Codex 내장 image_gen으로 WAVE 나루 캐릭터를 제작했다. 원본 프롬프트 설명과 자산 정보는 public/naru/README.md에 보존했다. 유료 외부 LLM API를 연결하지 않았다.

로컬 lint·typecheck·unit·build·성능·보안·actionlint 및 변경 관련 E2E를 실행한다. 실제 모델은 동일14범주로 평가했다. 합성 인증/실패와 실제 제공처 검증을 구분한다. 최종 CI·배포 실행과 Production 상태는 PR의 실행 결과로 확인하며 실패·대기 상태를 우회하지 않는다.

첫 hosted CI의 실패를 조사해 자동 경로와 직접 선택의 우선순위, 지도 인스턴스 유지, 좁은 화면 메뉴, 검색 초점과 새 여행 초기화를 수정했다. 기존 실제 경계 검사는 유지하면서 새로운 자동 조회·선택 사항 동선과 API fixture를 반영했다. 수정 후 단위 1,025개·타입·lint와 실패했던 데스크톱/모바일 경로를 다시 확인했다. CSS gzip66.91KiB, Planner 초기 JS215.24KiB로 기존 성능 예산을 통과했다. 실패 후보를 배포하지 않고 수정 후보의 전체 CI 성공을 기다린다.

수정본 CI에서 2·3번 desktop/mobile shard는 모두 통과했다. 남은 1·4번 실패는 실제 느린 로딩 중 자동 경로 조회가 앞쪽 UI 높이를 바꾸는 문제와, 저장 ID 재조회를 예전 API fixture에 연결해 둔 시설·누락 좌표 검사의 경합이었다. 자동 응답을 포인터를 누른 도중에 완료시켜 재현하고, 새 버튼 공간을 미리 확보했다. 시설·좌표 검사는 실제로 같은 ID의 같은 근거를 제공한 뒤 확인하도록 갱신했다. 별도로 오래된 ID 재조회가 새 검색의 checkedAt 근거를 덮지 않게 보강했으며 최신 실패·부재도 그대로 유지한다.

이 수정의 단위 1,027개·typecheck·lint·build·성능 검사와 시설 16개·저장 여행 6개·경로 안정성 반복 24개·관련 경로 38개가 통과했다. 최종 CSS gzip66.98KiB, 소개140.94KiB, Planner215.35KiB다. 편의근거는 최신 응답을 유지하면서, 그 응답에 좌표가 없을 때 같은 ID의 검증된 공개 좌표만 보충한다.

DB 스키마와 기존 사용자 데이터를 파괴하는 변경은 없다. 모델 게이트웨이는 WAVE 전용 DSW 서비스만 갱신했다. Vercel CD를 통해 배포하고 문제 시 이전 정상 배포로 복귀할 수 있다. 동작 실패 시 현재 여행을 보존하고 AI 없이 직접 편집을 제공한다.
