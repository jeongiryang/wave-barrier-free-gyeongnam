# PR-111 — 날씨 provider와 도메인 분리

## 목적

날씨 handler에 섞인 지역 좌표, 외부 요청, 응답 정규화, 사용자 여행 조언을 독립 경계로 분리한다.

## 변경

- 경남 지역 좌표와 입력 fallback을 weather catalog로 이동
- 기상 코드 라벨·준비 조언·응답 정규화를 순수 model로 이동
- Open-Meteo URL·timeout·응답 계약을 provider adapter로 이동
- handler는 method·입력 정리·provider/domain orchestration·HTTP 응답에 집중
- 서버 구조 회귀 테스트에 weather 경계를 추가

## 안전성

8초 timeout, 창원 fallback, 7일 조회, 사용자용 502 오류, 출처·조회 시각, 비·눈·자외선·기온
조언을 유지하며 가짜 날씨 값은 추가하지 않는다.

## 영향

Open-Meteo 교체, 지역 추가, 여행 조언 변경을 서로 독립적으로 수행하고 테스트할 수 있다.
