## 목적

`PlannerPage`가 화면 조율과 함께 공유 여행 저장, 클립보드 복사, 장소 피드백 전송 및
각 요청 상태까지 직접 소유했다. 사용자 참여 요청 lifecycle을 독립 controller로 이동한다.

## 역할 구분

- 사람: 남은 책임 혼합 영역의 전면적인 점진 분리 위임
- AI: 공유·피드백 경계 설계, API payload 보존, 회귀 검증과 PR 처리

## 구현

- `usePlannerParticipation`이 공유 링크 생성과 상태, 클립보드 복사를 소유한다.
- 장소 접근성 피드백 validation, 전송 상태와 입력 초기화를 같은 controller로 모았다.
- Planner page는 현재 plan·일정·장소 context를 전달하고 UI에 controller 결과만 표현한다.
- 여행 공유 payload와 피드백 payload의 기존 데이터 계약을 유지했다.
