PR #699 운영 검증에서 두 가지 후속 문제를 재현했다. 대산플라워랜드의 붙인 검색은 공식 ID2758443에 연결되나 공백 있는 검색은 관광공사 정상0건이었다. 기존 시간 예산 안에서 완전한0건/카카오 이름 정확일치에만 공백제거 재조회1회를 허용한다. 주소·좌표·유일후보 검증을 유지한다. 신규 unit13/13 통과.
