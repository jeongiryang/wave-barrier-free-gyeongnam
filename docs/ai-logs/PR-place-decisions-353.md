## 사용자 동작

여행지 검색 결과에서 2~3곳을 고르고 필요한 편의를 같은 행에서 비교한다. 확인됨·조건 불일치·미확인은 원래 근거대로 구분하고 출처와 조회 시각을 보여준다. 비교에서 바로 일정을 담거나 뺄 수 있다. 결과가 바뀌면 비교 선택을 다시 시작하고, 이전 조건의 결과로 새 장소를 담는 것은 차단한다.

장소의 이용 정보에는 방문 전 문의 카드가 있다. 운영·계단 없는 이동·화장실·주차·승강기·휴식·안내 질문을 직접 고르고 추가 문장을 작성한다. 큰 한국어 문장으로 보여주기, 복사, PNG 저장을 제공한다. 복사 권한이 없으면 선택 가능한 텍스트를 제공한다. 상대에게 메시지를 보내거나 별도 모델·유료 API를 호출하지 않는다. 사용 가이드에 진입과 이용 순서를 추가했다.

## 구현과 검증

- 기존 서버 검색/편의 근거와 저장 동작 재사용. 비교는 현재 결과 ID만 보유하며 새 시설 근거를 만들지 않는다.
- native dialog의 접근성·Escape·닫기 후 초점 복귀 재사용. 중첩 문의 dialog는 portal을 사용한다.
- PNG는 글자만 렌더링하므로 외부 이미지·지도·개인 위치를 넣지 않는다. 한국어 단어 경계를 우선해 줄을 나눈다.
