## 목적

PR #222 배포 뒤 실제 Production을 1363px 데스크톱으로 점검하던 중, 선언된
`position: sticky`가 상위 워크스페이스의 `overflow: hidden` 때문에 작동하지 않는
문제를 확인했다. 사용자가 긴 플래너를 읽는 동안 현재 단계와 다음 행동을 계속 볼 수
있도록 실제 스크롤 동작을 복구한다.

## 역할 구분

- 사람: 새 UI를 고수하지 않아도 되며 W.A.V.E에 맞는 UX 개선과 남은 작업 전체 처리를
  승인했다.
- AI: Production 재현, 원인 분석, 이슈 등록, CSS 수정, 실제 위치 회귀 테스트와
  CI·배포 검증을 수행한다.

## 구현

- `.planner-journey-workspace`의 `overflow: hidden`을 `overflow: clip`으로 변경해
  외곽 클리핑은 유지하고 불필요한 스크롤 컨테이너 생성을 제거한다.
- 1366px 데스크톱에서 문서를 1,000px 스크롤한 뒤 레일 내부의 top이 104px인지
  bounding rect로 검증한다.
- 390px 모바일 fixed 하단 탐색, 44px 조작 영역과 가로 오버플로 검사는 유지한다.
