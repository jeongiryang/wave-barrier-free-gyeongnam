## 목적

지도 기능이 많아지면서 가로 도구막대의 마지막 `전체보기` 버튼이 컨테이너 밖으로
잘리거나, 사용자가 도구 목록을 끝까지 스크롤해야만 보이는 문제를 해결한다.

## 원인 분석

지도 유형부터 전체보기까지 모든 조작부가 하나의 가로 스크롤 컨테이너 안에 있었다.
도구막대가 지도 제공자 배지와 우측 패널을 피해 폭을 줄이면 마지막 버튼이 곧바로
가시 영역 밖으로 밀려났다.

## 변경

- 스크롤 가능한 일반 지도 도구와 고정 `전체보기` 버튼을 분리
- 일반 도구만 `map-command-scroll`에서 가로 스크롤
- 전체보기 버튼은 모든 폭에서 오른쪽에 항상 표시
- 기존 큰 지도 열기·닫기, 모바일 터치 크기와 인쇄 숨김 동작 유지
- 구조와 오버플로 회귀 테스트 추가
