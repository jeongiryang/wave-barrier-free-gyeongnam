# 경남 지도 탐색 범위

- Issue: #442
- 사람: 경상남도 서비스에 맞게 카카오 지도가 일본·중국까지 축소되지 않도록 요청.
- AI: Kakao 및 대체 Leaflet의 이동·축소 범위를 경남과 남해 도서를 포함하는 사각 표시 범위로 제한.

화면 크기에 따라 축소 한계를 계산하고 지도 중심뿐 아니라 표시 영역도 범위 안으로 조정한다. 행정구역 밖 장소를 삭제하거나 저장한 경로 좌표를 바꾸지 않는다. 지도 맞춤 보기, 전체 화면, 날짜별 장소 표시와 일정 추가 동작을 유지한다.

## 필요한 검증
- 경남 18개 지역, 범위 밖 이동, 과도한 축소, Kakao SDK 이벤트 연결·종료 경계 단위 4개 PASS.
- 타입, 관련 lint, Vercel 빌드와 성능 예산 PASS.
- 실제 Leaflet 지도 렌더링의 날짜별 장소 맞춤 보기와 모바일, Kakao fixture 지도에서 일정 저장: 관련 브라우저 4개 PASS (19.2초).
- 실제 Kakao SDK는 4189 개발 주소에서 net::ERR_BLOCKED_BY_ORB로 거부되어 대체 지도로 전환됨. 실제 SDK 성공으로 주장하지 않는다. 코드 경계는 SDK 계약과 테스트로 확인하고 실제 등록 도메인의 지도를 배포 후 확인한다.
- API 키·원본 관광 응답은 증거 파일과 로그에 저장하지 않았다.

후속 진단: SDK가 거부된 이유는 4189 개발 주소의 미등록 Web 도메인(HTTP 401 domain mismatched)이었다. 운영 도메인을 출처로 한 SDK 응답은 HTTP 200 JavaScript다. 쿼터 부족으로 분류하지 않는다.

## Hosted CI 후속
첫 quality에서 4개 실패: 기존 지도 renderer harness가 새 viewport 모듈/SDK 메서드를 모르는 3개와 제품 화면에서 제거한 저장 설명을 찾는 1개. Harness가 실제 새 제한 함수를 실행하도록 연결하고 SDK adapter를 갱신했다. 데이터 저장 안내 검사는 유지된 개인정보 처리방침에서 확인하도록 이동했다. 제품 로직 변경 없음. 관련 지도/여행집 단위 21개 PASS.
