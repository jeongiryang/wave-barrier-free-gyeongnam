# W.A.V.E AI 작업 로그

이 폴더는 Pull Request별 AI 보조 사용 내역과 사람의 의사결정을 추적한다.
공모전 심사와 유지보수에서 변경의 출처를 설명하기 위한 기록이며, 원문 프롬프트,
인증키, 개인정보, 내부 추론은 기록하지 않는다.

## 작성 규칙

1. PR 하나당 `PR-<3자리 번호>.md` 파일 하나를 만든다.
2. PR을 열기 전에는 `TEMPLATE.md`를 복사하고, PR 번호가 정해지면 파일명을 확정한다.
3. AI가 한 일과 사람이 결정·승인한 일을 분리한다.
4. 실행한 검증과 결과를 적고, 실행하지 않은 검증은 성공으로 쓰지 않는다.
5. 과거 기록이 부족하면 추측하지 않고 `확인 불가`로 남긴다.
6. PR이 닫히거나 병합되면 최종 상태와 커밋을 갱신한다.

PR 번호가 없는 4, 5, 11은 GitHub Issue 번호이므로 이 목록에서 빠진다.
