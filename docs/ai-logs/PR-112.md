# PR-112 — 관광 응답 모델 분리

## 목적

하나의 관광 model 파일에 섞인 접근성 근거 계산, provider 상태·병합, 코스·행사·오디오 변환을
변경 이유가 다른 도메인 경계로 분리한다.

## 변경

- 공식 접근성 필드 판정과 장소 모델 생성을 `accessibility-model`로 이동
- provider 상태 표시와 검색 결과 병합을 `provider-model`로 이동
- 코스·부가 관광 콘텐츠·오디오 안내 변환을 `content-model`로 이동
- 호출부는 필요한 경계를 직접 import하고 기존 `models.ts`는 호환 facade로 축소
- 서버 구조 회귀 테스트에 새 경계를 추가

## 안전성

공식 필드가 없을 때 점수를 발명하지 않는 접근성 근거, HTTPS 이미지·오디오 정규화,
정보 없음·부정·확인 상태 구분과 결과 병합 순서를 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

추천 접근성 정책을 수정할 때 행사·오디오 변환이나 provider 상태 코드를 읽을 필요가 없다.
