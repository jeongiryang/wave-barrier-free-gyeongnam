## 데이터 경계와 미확인

최종 로컬 표시 확인에서 #conditions 진입 시 초기/popstate 위치 복원이 나루 열기를 닫는 충돌을 발견했다. 실제 hashchange 이동에만 닫기 동작을 한정하고, #conditions URL에서 도구/상세/붙여넣기를 수행하는 회귀 1개가 통과했다. 추가 타입 검사 및 해당 파일 ESLint 오류 0을 확인했다. Computer Use에서 최종 나루 상세 사진 카드가 화면에 표시되는 것을 확인하고 로컬 탭을 결과물로 남겼다.

시설 시연은 DEV+localhost에서만 표시하고 임의 위치/실제 정보 아님을 표시한다. 공식 편의 근거·계정 저장·공공 보고에는 넣지 않는다. 이용시간/시설 부재/휠체어 통행을 만들어내지 않는다. 상세 조회 실패 시 원래 장소와 미확인 경고를 유지하고 재시도를 제공한다. 붙여넣기는 전송하지 않으며 Clipboard 권한 실패는 Ctrl+V/파일 선택으로 복구한다.

독립 QA, 전체 CI, 성능 예산, 실제 로컬 모델 응답과 Production 검증은 UNVERIFIED다. PR 생성 시 CI 상태를 출시 성공으로 간주하지 않는다. 이슈는 열어 두고 병합·배포하지 않는다. PDF skill이 요구한 텍스트+시각 확인을 통해 이미지 첨부 요청과 일반 답변, 실제 근거와 임의 시설 시연의 범위를 구분했다.
