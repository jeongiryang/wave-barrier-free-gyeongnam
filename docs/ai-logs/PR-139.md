# PR 138 — 장소 선택 UI와 위치 검색 요청 분리

## 목적

- 출발·도착 선택 UI 상태와 외부 장소 검색 요청 수명주기를 독립적으로 관리한다.

## 변경

- `useLocationSearchRequest`: 검색어, 결과, 로딩, 요청 취소와 검색 결과 변환을 담당한다.
- `useLocationSearch`: 출발·도착 선택 모드와 검색 초기화를 조합한다.
- 경쟁 상태 테스트가 분리된 요청 모듈을 함께 검증한다.

## 안전성
