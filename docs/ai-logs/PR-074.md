## 목적

최상위 API entrypoint에 남은 Neon 연결, 공유 일정 CRUD와 접근성 제보 저장 책임을
독립 저장 도메인으로 이동해 Worker를 URL routing 전용으로 만든다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 모두 점진 분리하고 검증·병합·배포까지 완료하도록 위임
- AI: 저장 handler 책임 이동, 회귀 테스트·문서 갱신과 PR 처리

## 구현

- `server/trips/handler.ts`에 공유 일정 DB 초기화·조회·저장과 입력 정규화를 이동했다.
- 공유 일정은 관광 도메인의 공식 content ID 복원 계약만 호출한다.
- 접근성 제보 검증과 저장도 같은 W.A.V.E 사용자 생성 데이터 경계에 모았다.
- Worker는 여덟 API 경로를 각 도메인 handler로 연결하는 27줄 entrypoint가 됐다.
