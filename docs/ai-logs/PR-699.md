## 변경

공개 공유의 휴식 목적을 생성·기존 조회 모두 제외하고 개인 저장은 보존한다. 화장실 원본 30건의 주소 정규화 누락과 반경 제한을 수정한다. 정확한 이름·전체 주소·30m/고유 후보 조건으로 공식 장소 연결을 보완한다. 한글 수량과 자동차 여행 준비 발화를 처리하며, 과거 예보·빈 일정의 다음 행동을 명확히 한다.

편의 비교에서 항목을 직접 선택·조회하고 필수 조건을 바꾸지 않는다. 나루의 비교/캘린더 도구가 대상 화면을 연다. 축제 상세에 기존 방문일/일정 담기 동작을 연결한다. 직접 검색은 확정된 공식 사진을 사용한다. 두루누비 코스·중심/연관 통계 후보를 이름 검색으로 연결하되 통계 ID를 장소 ID로 승격하지 않는다. 통계 기준월·조회 지역·지수 단위를 표시하고 전국/동명 타 지역 혼입을 차단한다.

카카오 브랜드색, 소개 푸터 전폭/배경/경계, 섹션 여백을 정리한다. 이미 폐기된 compact-card CSS를 제거했다. 제출 PDF/PPT, DB 스키마, Secret, 인증 설정, LLM 서버, 예약 작업은 변경하지 않는다.

## 한계와 복구

합성 API 기반 브라우저 검사는 운영 DB 쓰기 또는 카카오 동의 성공과 다르다. 물리 GPS/화면낭독기/현장 이동은 이번 자동 검증으로 보증하지 않는다. 외부 자료의 미제공은 빈 상태로 유지한다. 배포 후 운영 실측을 별도 기록하며 롤백은 해당 squash commit revert로 한다.

## 최종 전체 브라우저 검사 보완

전체 CI에서 바뀐 기준월 제목·조회 건수·직접 검색 근거·화장실 범위 안내 및 복수 status를 예전 단언으로 찾는 실패가 확인됐다. 현행 사용자 계약에 맞춰 단언을 구체화했다. 비교창 테스트는 plan과 추가 공식 조회가 서로 다른 fixture를 사용하던 문제를 바로잡고, 비교 편의 선택/재조회 요청도 검사한다. 제품 기능을 끄거나 timeout을 늘리거나 검사 범위를 줄이지 않았다. 수정 대상 재검증: 핵심 여정 2, 직접 검색/건수 10, 공유 복사 4, 화장실/폭별 흐름 3(기존 중복 제외 1), 장소 비교 6건 통과. 전체 CI를 다시 실행한다.
