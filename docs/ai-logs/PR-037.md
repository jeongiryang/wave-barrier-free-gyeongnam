## 목적

백필 첫 실행에서 `v0.1.0` 생성 후 Git refs API가 403을 반환해 중단된 문제를
고치고, 향후 병합 PR에도 자동으로 시맨틱 버전이 이어지게 한다.

## 원인과 수정

- 원인: Actions `GITHUB_TOKEN`의 연속 Git refs 생성 요청이 통합 권한에서 차단됨
- 수정: Release API의 `target_commitish`가 태그를 함께 생성하도록 단일화
- 생성 직후 태그가 예상 커밋 SHA를 가리키는지 재검증
- PR #36을 고정 SHA `v0.7.1`, 이 PR을 `v0.7.2`로 추가
- 이후 `main` 병합은 Conventional Commit 유형에 따라 자동 버전 생성
