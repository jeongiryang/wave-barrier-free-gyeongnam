## 목적

운영 의존성에는 영향을 주지 않지만 CI·배포 빌드에 남아 있던 `image-size` High 2건과
`fflate` Moderate 1건을, 실제 운영 이력이 있는 `vinext@0.0.50` 조합을 유지하면서
해소한다.

## 역할 구분

- 사람: 구독 범위 밖 비용 금지, 강제 audit fix·vinext beta 전환 금지, 필수 리뷰와
  Production 승격의 최종 승인
- AI: 권고·의존성 경로·과거 Vercel 회귀 조사, 호환 대체안 선택, lockfile·테스트·운영
  문서 변경, 로컬 검사, Issue와 Draft PR 작성
- 사람이 추후 직접 확인: Vercel Preview 또는 병합 후보의 실제 함수 smoke, 필수 리뷰,
  Production 배포 여부

## 보안 판단

- 공식 `image-size@2.0.2`에는 GHSA-w3rx-r6r6-pgpr와 GHSA-5p2g-fcmc-qvqq의 수정
  릴리스가 없다.
- npm이 제시하는 vinext major/beta 전환은 PR #55 뒤 실제 Vercel 전 경로 500을 일으켜
  PR #56에서 복구한 이력이 있어 사용하지 않았다.
- 동일 API의 커뮤니티 포크 `image-size-next@2.1.1`은 해당 무한 반복 경계를 수정하고,
  설치 생명주기 스크립트와 런타임 의존성이 없다. 새 포크라는 공급망 위험은 exact pin,
  lockfile SHA-512, 정상·악성 입력 회귀 테스트와 실제 vinext 빌드로 제한한다.
- `fflate`는 현재 요구 범위와 호환되는 최소 패치 `0.7.5`로 고정했다.
