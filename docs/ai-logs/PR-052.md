# PR #52 · 도움말 투어 뷰포트 레이어 복구

## 발견

프로덕션 여행 설계 화면에서 도움말을 열면 모달의 실제 좌표가 화면 위쪽
`-325px`까지 벗어나는 문제를 재현했다. 도움말 컴포넌트가 스크롤에 따라
`transform`되는 고정 헤더 안에 있어, CSS `position: fixed`가 뷰포트가 아니라
해당 헤더를 기준으로 계산되는 것이 원인이었다.

## 변경

- 헤더에는 도움말 실행 버튼만 유지한다.
- shield, spotlight, 포인터와 dialog는 React portal로 `document.body`에 렌더링한다.
- 기존 단계별 스크롤, 포커스 트랩, Escape 닫기, 이전 포커스 복원,
  reduced-motion 동작은 그대로 유지한다.

## 검증

- 프로덕션에서 문제 좌표와 원인을 재현했다.
- portal 사용을 회귀 테스트에 추가했다.
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `git diff --check`

환경 변수와 외부 서비스 설정은 변경하지 않았다.
