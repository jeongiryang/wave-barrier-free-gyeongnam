## 목적과 기능 보존

사용자가 제공한 WAVE_기능설명서_제출확정본_2026-09-21.pdf의 나루 기능을 유지하면서 프론트 UI/UX만 개선한다. 특히 설명서 9–13쪽의 모바일 내부 스크롤, 대화·도구·저장 작업공간, 조건 입력, 일정 제안·적용·복구와 18–21쪽의 여행 도구 접근을 보존했다.

모바일 일반 열기에서 키보드를 자동으로 열지 않는다. 사용자가 예시 요청을 선택한 경우에는 입력창으로 연결하되, 같은 요청을 다시 열 때 불필요한 자동 초점을 반복하지 않는다. Visual Viewport의 높이와 상단 위치로 대화창을 맞추고 확대 중에는 브라우저의 확대·이동을 유지한다. 추천 질문과 빠른 도구를 펼칠 수 있게 정리하고 대화 스크롤 안으로 이동했다. 최신 답변 버튼은 다른 조작을 덮지 않으며 사진 첨부 미리보기는 높이를 제한한 키보드 접근 가능한 스크롤 영역이다.

백엔드, API, 모델, 여행 상태/저장 형식, 요청 데이터는 변경하지 않았다. 28개 여행 도구, 맞춤 도움, 음성, 사진, 실제 일정안의 검토·적용·되돌리기, 저장과 이어가기를 유지한다.

## 한계와 배포

가상 키보드는 브라우저에서 visualViewport 높이·offsetTop을 재현했다. 실제 iOS/Android 하드웨어 검증은 수행하지 않았다. 기능 회귀 검증의 모델·관광 응답은 합성 fixture이며 실 제공처 품질 검증으로 주장하지 않는다.

AGENTS.md의 기존 Owner 리뷰 대기 면제와 실제 ruleset(승인 수 0)을 확인했다. 최신 main 포함, 필수 validate 성공, squash/선형 이력을 유지한다. CI 실패 또는 대기는 우회하지 않는다. GitHub Actions CD와 Production UI 확인 후 실제 결과를 PR에 기록한다. 환경 변수·DB·CI/CD 설정 변경 없음. 되돌리기는 이 PR squash 커밋 revert로 가능하다.

### 마지막 수동 사용 경로 보강

- 로컬 UI에서 “어떤 것을 도와줄 수 있어?” 요청 후 열리는 별도 전체 도구 목록이 짧은 화면을 가리는 경로를 재현했다. 해당 목록도 대화 스크롤 내부의 펼치기로 옮겼다. 28개 도구와 기존 실행 핸들러를 유지한다.
- 이 경로를 포함한 키보드·사진·도움 모음 검사에서 기존 absolute 도구 스타일의 겹침까지 재현하여 static 배치로 수정했다. 최종 재검증 결과는 PR에 기록한다.
- 최종 수정 후 키보드·사진·도움 모음 16/16, 타입 검사, 변경 범위 lint(오류 0), 빌드와 성능 예산 통과.
