- AI 도구: Codex

## 목적

기능 설명서의 일정 수정·고정 시각·출발 점검·문의·저장 흐름을 데이터가 적은 심사 환경에서도 조작해 볼 수 있게 한다. 관광지·편의시설·축제·날씨·경로 등 제공처 조회 항목은 생성하지 않는다.

## 역할 구분

- 사람: 데모 데이터 추가와 API 응답 임의 생성 금지를 요청했다.
- AI: `/demo`를 방문 자리 A~D와 사용자 입력 값만 있는 다섯 시나리오로 구성하고, 일정 수정·되돌리기·시연 전용 저장·문의·점검을 구현했다. 일반 커뮤니티 데이터와 제공처 API 경로는 수정하지 않았다.

## 검증

- `npm run lint`: 오류 0건, 기존 경고 33건.
- `npm run typecheck`: 성공.
- `npm test`: 1,861건 성공. Windows Python 실행 경로를 번들 런타임으로 지정했다.
- `node --test tests/demo-schedule.test.mjs`: 3건 성공. 시연 시나리오의 제공처 필드 부재, 고정 시각, 자정 초과, 빈 날짜를 확인했다.
- `npm run build:vercel`, `npm run check:performance`: 성공. CSS gzip 108.12 KiB, 명시적 예산 108.5 KiB.
- 배포 빌드 로컬 미리보기 `/demo`: 1440px·390px에서 시나리오 변경, 적용·되돌리기, 브라우저 저장·복원, 자정 초과·빈 날짜, 가로 넘침과 콘솔 오류를 확인했다. 390px WCAG 2 A/AA axe 자동 검사 위반 0건. 시연 화면에서 `/api/*` 요청 0건.

## 결과와 제한

방문지는 실제 관광지 ID가 없는 자리다. 계산 시각에는 이동시간이 들어 있지 않으며, 실제 관광정보·나루 응답·제공처 상태·운영 배포는 이 로컬 검사로 검증되지 않았다. 기존 커뮤니티 `[시연]` 배치는 별도 Owner 운영 절차를 따른다.
