# PR-092 — 지도 공급자 렌더링 어댑터 분리

## 목적

카카오 지도와 OpenStreetMap fallback의 초기화·마커·경로 렌더링이 하나의
effect에 섞인 구조를 공급자별로 분리한다.

## 변경

- 카카오 SDK 초기화와 지도 표현을 `kakao-map-renderer`로 이동
- Leaflet/OpenStreetMap fallback을 `leaflet-map-renderer`로 이동
- 공통 refs, callbacks, state setters를 명시적인 renderer context로 정의
- 지도 클릭 목적지 생성을 공급자 공통 함수로 통일
- `useMapRenderer`는 구성 키 조회, 공급자 선택, fallback, cleanup만 담당
- 공급자별 구현 경계를 고정하는 회귀 테스트 보강

## 안전성

Kakao timeout/domain fallback, 지도 클릭, 마커·혼잡 원, 경로 선, 측정 도구,
OpenStreetMap attribution과 cleanup 동작을 유지한다.

## 영향

지도 공급자 한쪽을 변경할 때 다른 공급자나 플래너 비즈니스 로직을 읽거나
수정할 필요가 줄어든다. API와 환경변수 형식은 변하지 않는다.
