# PR 132 — 랜딩 제품 스토리 feature 경계 분리

## 목적

- 루트 컴포넌트 하나에 들어 있던 다섯 기능 프리뷰를 랜딩 feature 안의 제품 여정 단계로 분리한다.

## 변경

- `LandingDiscoveryStories`: 여행 조건과 접근성 추천 근거 프리뷰를 담당한다.
- `LandingJourneyStories`: 일정과 지도·교통 연결 프리뷰를 담당한다.
- `LandingAdaptStory`: 날씨·관광 집중 변화 대응 프리뷰를 담당한다.
- `LandingProductStories`는 세 스토리 영역을 조합한다.
- 랜딩 페이지가 feature 컴포넌트를 직접 사용하고 기존 루트 `LandingStories` 파일을 제거했다.
- 랜딩·커뮤니티 제품 테스트의 소스 경계를 갱신했다.
