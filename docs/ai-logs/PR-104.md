# PR-104 — 플래너 출발지·현재 위치 경계 분리

## 목적

경로 조회 hook에 함께 있던 출발지 선택, 현재 위치 권한, private-origin 안내 정책을
독립 controller로 분리한다.

## 변경

- 출발지 좌표·표시명·현재 위치 상태를 `useRouteOrigin`으로 이동
- geolocation 권한·실패 안내와 좌표 비전송 문구를 출발지 controller에 집중
- `useRoutePlanning`은 경로·혼잡 요청, transport 상태, stale request 취소에 집중
- private origin으로 전환할 때 기존 서버 경로를 비우는 동작 유지
- planner 구조 회귀 테스트에 새 경계 추가

## 안전성

현재 위치는 지도 안에서만 사용하고 경로 API·저장소로 전송하지 않는 기존 원칙,
권한 거부 fallback, preset 출발지, stale request abort 동작을 유지한다.
