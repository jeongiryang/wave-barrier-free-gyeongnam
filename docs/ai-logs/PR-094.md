# PR-094 — 공공데이터 정규화와 요청 클라이언트 분리

## 목적

하나의 공통 파일에 섞여 있던 provider 타입, JSON/XML 정규화, 관광 요청,
교통 요청과 상태 설명의 책임을 독립 모듈로 분리한다.

## 변경

- 공급자 결과·상태 타입을 `provider-types`로 이동
- 실패 격리를 `provider-attempt`로 이동
- JSON·XML·고속도로 응답 정규화를 `provider-normalizers`로 이동
- 한국관광공사 요청과 지역 결과 병합을 `tourism-provider`로 이동
- 공공교통 요청, 인증키 선택과 상태 설명을 `public-transport-provider`로 이동
- 기존 import 호환을 위해 `provider-data`는 명시적인 re-export facade로 유지
- 서버 모듈 경계 회귀 테스트 보강

## 안전성

9500ms timeout, 인증 오류 해석, JSON/XML 정규화, 지역 중복 제거와 provider
상태 의미를 유지한다. 인증키와 API 응답 형식은 변하지 않는다.

외부 API 또는 응답 형식 하나를 수정할 때 다른 공급자 계층에 미치는 영향이 줄어든다.
