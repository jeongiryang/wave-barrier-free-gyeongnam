파동 효과에 획이 많은 특수 기호가 다량 쓰여 잔상이 심하고 눈이 피로하다는

## 역할과 변경

- 사람(`syt83`): 인트로와 메인 화면의 파동 효과가 시각적으로 부담된다고 제보하고
  밀도·속도·불투명도 완화와 토글 옵션을 제안했다.
- Claude Code: 제안 1·2를 반영해 문자 계단, 색 계단, 너울 속도, 난류 세기,
  캔버스 불투명도를 조정했다.
- OpenAI Codex: 최신 `main`을 병합해 캐러셀 수정과 충돌을 해소하고, 가장 밝은
  문자도 단순한 선으로 바꿨다. 사용자 요청에 따라 마지막 W.A.V.E 워드마크를
  약 1초 더 보여 주되 바로 시작 버튼과 모션 감소 동작은 유지했다.

## 판단 근거

제보는 `enhancement` 라벨이지만 **접근성 결함으로 보고 우선 처리**했다.
무장애 이용자를 위한 서비스에서 화면 잔상과 시각 피로는 취향 문제가 아니라
이용을 막는 요소다.

잔상의 직접 원인은 두 가지로 보았다.

1. 획이 많은 글자(`#`, `@`, `x`, `X`)가 칸을 가득 채워 인접 칸과 경계가 사라짐
2. 물결이 빨라 같은 칸의 글자가 자주 바뀜

그래서 글자 계단을 점·선 위주로 바꾸고, 속도와 난류 세기를 함께 낮췄다.
불투명도만 낮추면 형상까지 흐려지므로 밀도와 속도를 먼저 손봤다.

제안 3(토글 옵션)은 동시에 열린 환경설정 저장 수정 PR #25와 같은 파일을
변경한다. 충돌과 설정 유실을 막기 위해 #25 병합 뒤 별도 작업 단위에서 처리한다.

## 검증

- 인트로 2.1초 시점과 랜딩 히어로를 1440px에서 렌더링해 비교 확인
- 파도 형상의 가독성이 유지되는지 확인(밀도를 낮추면 형상까지 흐려질 수 있음)
- 인트로 캔버스의 마지막 형상 종료(6.05초), CSS 퇴장(6.05~6.55초), React
  제거 시점(6.55초)이 어긋나지 않는지 회귀 테스트로 고정
- 최신 `main` 병합 후 `npm run lint`, `npm run typecheck`, `npm test`,
  `npm run build:vercel`, `git diff --check` 재실행

## 결과와 제한

`prefers-reduced-motion: reduce`는 이전부터 지원한다(애니메이션을 멈추고 한 프레임만
렌더링). 이번 변경은 그 설정을 쓰지 않는 이용자의 기본 화면을 완화한 것이다.

효과를 완전히 끄고 싶은 이용자를 위한 토글은 아직 없다. PR #25의 환경설정 저장
수정이 병합된 뒤 그 구조 위에서 후속 작업으로 구현한다.
