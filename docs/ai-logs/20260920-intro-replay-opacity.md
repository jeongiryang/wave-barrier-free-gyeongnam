# 인트로 다시 보기의 시작 투명도

운영 PR #617 확인 중 자동 종료 후 다시 보기를 누르면 종료 fade 상태가 남아 본문이 잠깐 비치는 현상을 발견했다. 사용자는 인트로 중 뒤쪽 서비스 화면의 선노출 방지를 요구했다.

dialog가 닫힌 뒤 leaving 상태를 초기화한다. 첫 노출, 자동 종료 fade, 건너뛰기, 모션 감소, timer/renderer 정리는 유지한다.

회귀 검사는 자동 종료 후 실제 다시 보기 버튼을 누르고 재생 시작 opacity가 즉시 1인지 확인한다. 수정 전 0.0100174로 실패했고 수정 후 PC·모바일 인트로/첫 방문 26개 검사가 통과했다. 이 opacity 검사는 fade 완료를 기다리는 재시도를 사용하지 않는다. 독립 QA에서 새 P0/P1이나 lifecycle 회귀를 발견하지 못했다.

심사 계정의 새 비밀번호 입력·최종 가입은 운영 가입 화면에서 사용자의 진행을 기다리고 있다. 계정이 만들어졌다고 간주하지 않는다.
