## 조사

- 저장소의 모든 외부 `fetch`, 환경 변수, 배포 Secret과 공개 API 경로를 대조했다.
- Vercel Production `/api/health`, 실제 경로·관광·확장·사진·날씨·장소·커뮤니티·인증
  응답과 한국어·7개 다국어 TourAPI 응답을 키 값 없이 확인했다.
- 필수 키와 KORAIL·TAGO 공통키 경로는 정상이며 `ODSAY_API_KEY`,
  `EXPRESSWAY_API_KEY`만 미등록임을 확인했다.

## 변경

- ODsay Web/URI 키가 Vercel에서도 도메인 인증을 통과하도록 Production `Referer`를
  서버 요청에 추가했다.
- ODsay 경로가 실제 표시될 때 공식 귀속 문구도 함께 노출한다.
- 한국도로공사 HTTP 200 오류 봉투를 빈 정상 결과와 구분한다.
- Production smoke가 등록된 선택 API의 실제 오류와 관광 제공처 오류를 실패로 판정한다.
- API·환경 변수별 기능, 상태, 사용자 등록 순서와 운영 설정을 문서화했다.
