# 심사 계정 `openapi` 시연 자료

사용자가 기존 심사위원 로그인 ID `openapi`를 지정해 계정 자료 삽입을 승인했다. 비밀번호를 요청하거나 저장하지 않는다.

`022_openapi_judge_account.sql`은 배포 후보의 운영 DB에서 `neon_auth."user".username = 'openapi'`가 정확히 한 명인지 검사한다. 계정이 없거나 모호하면 전체 마이그레이션을 롤백하고 Production 승격을 중단한다. 별도 인증 계정을 만들거나 수정하지 않는다.

처음 한 번만 아래 자료를 소유자 계정에 연결한다. `judge_account_seed_runs` 마커는 이후 배포에서 심사위원이 편집·삭제한 자료를 다시 만들지 않게 한다.

| 화면 | 계정 소유 자료 | 출처와 한계 |
| --- | --- | --- |
| `/my-trips` | `[시연]` 계획 5건, 날짜·방문 순서·체류·휴식·메모 | 공개 시연 일정의 작성자 선택과 검증된 공식 장소 ID만 사용. 장소명·주소·시설·이동 시간은 미저장. |
| 계정 편의 조건 | 기존 선택이 없으면 경로·화장실 선택 예시 1건 | 시연 계정의 선택 예시일 뿐 개별 장소의 시설 확인이 아님. 기존 선택은 유지. |
| `/community` | `[시연]` 계정 소유 글 2건·댓글 1건 | 게시글 수정·삭제와 댓글 관리를 확인할 내용. 방문 후기나 사용자 촬영 사진으로 표시하지 않음. |

사진 코스는 로컬 원본을 읽는 기능으로 계정 사진 저장 경로가 없다. 공개 AI 생성 예시 사진은 전 계정 공통이며, 원본을 계정의 사용자 업로드로 위장하지 않는다. 북마크와 기기 여행집도 로컬 저장이므로 운영 DB 계정 자료로 표시하지 않는다.

운영 배포 후 마이그레이션 성공과 계정 연결을 확인한다. 로그인 세션을 받지 못하면 `/my-trips` 실제 화면의 계정 소유 뷰는 미확인으로 남긴다.
