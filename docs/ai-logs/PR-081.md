## 목적

지도 경험의 지역 탐색·workspace·장소 도구·실시간 signal 스타일과 계정·커뮤니티 스타일이
각각 하나의 대형 파일에 섞여 있었다. selector cascade를 보존하며 feature 책임 경계를 명확히 한다.

## 역할 구분

- 사람: 남은 모든 의미 있는 분리 대상을 완료하도록 위임
- AI: CSS 경계 설계, 기계적 이동, cascade 회귀 검증과 PR 처리

## 구현

- 지역 지도 표현은 `map-experience.css`에 유지했다.
- 지도 workspace와 overlay는 `map-workspace.css`로 이동했다.
- 장소 선택·예매·skeleton·roadview는 `map-place-tools.css`로 이동했다.
- 혼잡·날씨·지점 비교 signal은 `map-live-signals.css`로 이동했다.
- 계정 화면과 커뮤니티 본문을 `account-auth.css`, `community.css`로 분리했다.
- 공통 dark mode·breakpoint 통합 규칙만 작은 `account-community.css`에 남겼다.

## 결과와 제한

- selector·declaration·media query와 import cascade는 변경하지 않았다.
- API, DB, 환경 변수 변경은 없다.
