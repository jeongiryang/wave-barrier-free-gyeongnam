## 제품 결정

- 랜딩의 주요 행동은 `여행 계획 만들기` 하나로 통일했다.
- 조건 입력은 `지역 → 필요한 편의 → 하고 싶은 활동 → 날짜` 네 질문으로 확정했다.
- `여행집`, `이 기기 일정`은 기본 메뉴에서 `내 일정`으로 통일하고, 저장 범위는 보조 문구 `이 기기에 저장돼요`로 정확히 알린다.
- Hero의 장식성 경로 모형, 포인터 조명, 챕터 레일과 데이터 원칙 중복 섹션은 기본 화면에서 제거했다. 공식 정보와 미확인 정보의 구분 원칙은 Hero 안내와 실제 결과 화면에서 유지한다.
- 경남 지역 선택을 기능 설명보다 앞에 두어 실제 콘텐츠와 시작 행동을 먼저 보이게 했다.
