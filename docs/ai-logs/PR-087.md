# PR-087 — RouteMap 상태·side-effect controller 분리

## 목적

지도 view가 SDK ref, 18개 UI 상태, 위치·로드뷰·측정·저장·공유 side-effect를
직접 소유하던 구조를 controller hook으로 분리한다.

## 변경

- `useRouteMapController`에 지도 도구 상태와 브라우저 side-effect 이동
- `RouteMapProps`를 routing 공통 타입으로 이동
- `RouteMap`을 패널과 canvas를 조합하는 표현 컴포넌트로 축소
- 개인정보·HTTPS·renderer 위임 테스트가 새 controller 경계를 직접 검증하도록 갱신

## 안전성

Kakao/Leaflet renderer hook, event listener cleanup, 요청 재시도, DOM class와 도구
표현은 유지한다. 현재 위치와 상세 경로 좌표는 저장하지 않는다.
