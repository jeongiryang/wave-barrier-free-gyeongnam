# PR-114 — 랜딩 커뮤니티 미리보기 분리

## 목적

정적 제품 스토리와 실시간 커뮤니티 글 조회·timeout 상태가 한 component에 섞인 구조를
Landing과 Community 기능 경계로 분리한다.

## 변경

- 실제 사용자 글 2건 조회 수명주기를 `useCommunityPreview`로 이동
- 기존 community client API를 재사용해 landing의 raw fetch 제거
- 커뮤니티 preview view를 Community feature component로 이동
- LandingStories는 제품 기능 설명만 담당하고 app route가 두 feature를 조합
- landing·community 회귀 테스트의 source 경계를 갱신

## 안전성

8초 timeout, unmount abort, 빈 상태에서 가짜 사용자·게시글을 만들지 않는 정책,
공식 데이터와 사용자 경험을 분리하는 문구와 accessible live region을 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`

- `git diff --check`

## 영향

커뮤니티 API·미리보기 상태 변경이 랜딩 제품 스토리 마크업에 번지지 않는다.
