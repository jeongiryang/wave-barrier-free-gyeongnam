- AI 도구: Codex

## 목적

`worker/index.ts`가 관광·교통 handler뿐 아니라 한국관광공사와 공공데이터포털의
인증키 선택, JSON·XML 정규화, timeout, 오류 변환과 지역 병합까지 직접 구현했다.
제공기관 통신의 공통 계약을 독립 client 경계로 옮긴다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 모두 점진 분리하고 검증·병합·배포까지 완료하도록 위임
- AI: 공공데이터 client 책임 식별·이동, 회귀 테스트·문서 갱신과 PR 처리

## 구현

- `server/shared/provider-data.ts`에 관광·교통 공공데이터 요청과 정규화를 모았다.
- JSON과 XML 응답, 제공기관 오류, 9.5초 timeout과 지역별 결과 병합을 한 경계로 관리한다.
- Worker는 기존 함수 이름 alias를 사용해 상위 관광·교통 로직과 응답 schema를 유지한다.
- 제공기관 client가 다시 entrypoint 안으로 들어오지 않도록 회귀 테스트를 추가했다.

## 결과와 제한

- API 경로, 제공기관 요청 parameter, timeout, 오류 메시지와 응답 schema는 변경하지 않는다.
- 후속 관광·교통 handler 분리가 공통 client를 재사용할 수 있는 기반을 만든다.
