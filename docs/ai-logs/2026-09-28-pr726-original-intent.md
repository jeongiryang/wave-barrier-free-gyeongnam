## 목적과 역할

Owner가 승인한 원안 `9c988cf`를 현재 디자인 기준으로 복원한다. 원안 검토 과정에서 추가한 시각·문구·인트로 생략 변경을 되돌리고, 재현 가능한 상태·연동 오류만 수정한다. Owner가 디자인과 작업 순서를 결정했고 AI는 Git 원본 대조·복원·회귀 검사·측정 검토를 수행했다. 새로운 디자인 후보를 선택할 권한으로 해석하지 않는다.

## 구현과 확인

[복원 기록](../pr726-original-intent-20260928.md)에 원본/배포 커밋, 동일하게 복원한 파일, 유지한 기능 수정, 검증 위치 및 실패의 해석을 기록했다. 로딩 표면을 실제 사진으로 오인한 검사 전제와 실제 사진 로딩 상태 경합도 분리했다. 인트로 및 실제 정보 위치에 대한 독립 검토와 원본 CSS 일치 확인을 수행했다.

단위·정적·빌드·성능과 핵심 브라우저 검증의 최종 결과는 이 PR의 실행 기록에 연결한다. 알려진 사진/히어로의 국소 대비 실패는 숨기지 않으며 전체 접근성·최종 제출 합격으로 표시하지 않는다. 원격 CI/CD 또는 실제 운영 검증을 실행하기 전 로컬 통과를 운영 완료로 주장하지 않는다.

## 작업 순서와 복구

먼저 #726 원안을 복원·검증한 뒤 ginaginaring의 다섯 PR을 판단한다. 이 복원에 후속 PR을 미리 섞거나 닫지 않았다. 원본·이전 배포·리뷰 커밋을 보존했으며 강제 push·브랜치 삭제·보호 규칙 변경은 하지 않았다.
