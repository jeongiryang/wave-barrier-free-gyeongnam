## 목적

Owner의 2026-09-11 지시에 따라 8번 지역 풍경 카드와 10번 글꼴·색·간격·플래너·커뮤니티를 기존 기능에 적용한다. 브랜드를 WAVE로 통일하고 상단에는 세 주요 메뉴와 저장 개수 북마크만 둔다. 로그인은 카드 한 장으로 정리하며 카카오·이메일·복구·가입·비회원 진입을 유지한다. 추가 지시에 따라 인트로의 우측 건너뛰기 버튼을 제거하고 자동 전환과 Esc를 유지한다.

## 역할 구분

- 사람: 시안·첨부 화면·범위 확정, 별도 화면 승인 대기 없이 병합 및 배포하도록 승인. 기존 Owner 승인 규칙에 따라 리뷰 3개 대기를 면제하되 필수 validate는 유지한다.
- AI: 최신 main/PR #464 확인, 미커밋 작업 백업·보존, 시안 원문과 실제 화면 비교, 구현, 로컬 시각·상호작용 검사, 테스트, PR 및 배포 확인.
- 독립 QA: 계정·게스트 복귀와 320px 입력 화면 및 헤더/스타일 경계 검토. 게스트가 보호된 return URL로 되돌아가는 문제를 /planner 진입으로 수정했다. 전체 기능 전수 검수는 후속 단계다.
- 후속 독립 QA: 본문 스트리밍이 5.2초보다 늦을 때 인트로 타이머가 먼저 끝나는 경로, 계정 메뉴 파일 로딩 실패를 재현했다. 타이머를 인트로 DOM 도착 후 시작하고 메뉴 파일 실패 시 실제 계정 링크를 제공하도록 수정했다. 데스크톱/모바일 재현 검사 4개가 통과했다.
- CI 실패분을 실제 회귀와 변경된 UI 계약으로 구분했다. 흰 카드/버튼의 글자 대비, 사진 밖으로 남던 장면 번호, 모바일 진행 표시와 하단 계정의 겹침, 창 크기 변경 시 날씨 버튼의 헤더 가림, 로그인 후 현재 경로 복귀를 수정했다. 날짜·북마크·설정·섹션 순서를 찾는 검사 위치도 새 UI로 바꾸되 기능·초점·대비·44px·API 경계 검사는 유지했다. 독립 QA는 새 버튼 대비 14.73:1, 계정 진입 52×44px 및 로딩 복구의 원인 해결을 확인했다.
- 전체 CI의 후속 확인에서 짧은 화면의 환경설정 패널을 실제 버튼 위에 고정하고, 개발용 어두운 화면에서도 하단 진행 숫자의 대비를 유지했다. 첫 인트로의 화면 검사에는 최종 프레임 이후 가상 시계를 정지해 CI 캡처 시간이 실제 5.2초 전환 기한을 소비하지 않게 했다. 자동 전환 시간 검사는 별도로 유지하며 해당 실패 경로 6개를 모바일에서 재검사해 통과했다.
