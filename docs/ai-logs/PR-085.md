# PR-085 — Planner navigation workspace 경계 분리

## 목적

통합 길찾기 화면에서 교통 데이터 해석과 지도·출발지 선택·경로 비교를 한
컴포넌트가 동시에 소유하던 구조를 기능 경계에 맞게 분리한다.

## 변경

- `NavigationWorkspace`를 route-level 조합 컴포넌트로 축소
- 교통수단·제공 범위·운행 결과를 `TransportDataOverview`로 분리
- 출발·도착 선택, 지도, 경로 대안 비교를 `RouteMapWorkspace`로 분리
- 제품 회귀 테스트가 새 위임 경계의 존재와 책임 격리를 확인하도록 보강

## 안전성

기존 hook과 public props를 그대로 전달하며 API, 상태 소유권, 사용자-visible
동작과 스타일 선택자는 변경하지 않는다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

DB, 환경변수, migration 변경은 없다. 지도 렌더러와 경로 계산 알고리즘은 기존
독립 모듈을 그대로 사용한다.
