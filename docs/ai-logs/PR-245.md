## 목적

다국어 TourAPI에 국문 콘텐츠 유형 코드가 전달되어 외국어 관광 결과가 비어 있던 문제를 수정한다. 국문 무장애 상세 근거는 그대로 유지하고, 사용자가 고른 테마를 각 서비스 계열의 공식 콘텐츠 유형 코드로 조회한다.

## 역할 구분

- 사람: 전체 마감 작업과 배포 승인, 외부 API 계정·Secret 제공
- AI: 운영 응답과 코드 대조, 원인 분석, 조회 파라미터 분리, 회귀 테스트 보강, 전체 품질 검사, PR·배포 처리

## 변경

- 다국어 서비스의 자연·문화·레포츠·음식 콘텐츠 유형 코드를 별도 카탈로그로 정의한다.
- 무장애 국문 조회와 선택 언어 조회가 각자 올바른 콘텐츠 유형을 사용하도록 파라미터를 분리한다.
- 다시 국문 코드를 공통 사용하지 못하도록 회귀 테스트를 갱신한다.
