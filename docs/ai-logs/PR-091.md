# PR-091 — 파동 캔버스 렌더링 수명주기 분리

## 목적

표현 컴포넌트가 픽셀 버퍼, 애니메이션 프레임, 가시성, 리사이즈와 포인터
상호작용까지 직접 소유하던 파동 효과의 책임 경계를 분리한다.

## 변경

- 캔버스 렌더링 엔진과 브라우저 수명주기를 `useWaveFieldRenderer`로 이동
- `WaveField`는 사용자 모션 설정과 캔버스 표현만 담당
- 기존 파동 모델과 인트로 마스크 모듈 경계를 유지
- 뷰 컴포넌트가 RAF·마스크 구현에 다시 결합되지 않도록 회귀 테스트 보강

## 안전성

픽셀 렌더링, 프레임 예산, 포인터 물결, Resize/Intersection Observer 정리,
reduced-motion 정지 화면 동작은 그대로 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test` (65/65)
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

사용자 화면 변화 없이 파동 렌더러만 독립적으로 변경·검증할 수 있다.
