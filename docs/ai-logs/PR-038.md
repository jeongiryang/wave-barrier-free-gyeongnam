# PR #38 AI 작업 로그

## 요청

- PR별 시맨틱 버전 태그와 GitHub Release를 과거부터 최신까지 생성한다.
- 릴리즈 자동화 과정의 누락과 오류를 검토하고 수정한다.

## 발견한 문제

- PR #37 병합 시 `Release Backfill`과 새 `Release` 워크플로가 같은 커밋에서 함께 실행됐다.
- 일반 릴리즈가 `v0.1.1`을 PR #37 병합 커밋에 먼저 만들었고, 백필은 원래 PR #3 커밋과의 SHA 불일치를 감지해 중단됐다.

## 변경

- 알려진 잘못된 `v0.1.1`만 버전·SHA·릴리즈 본문을 모두 대조한 뒤 제거하도록 제한적 교정 로직을 추가했다.
- 교정 직후 기존 백필 목록에 따라 `v0.1.1`을 원래 PR #3 커밋에 다시 생성하도록 유지했다.
- PR #37의 확정 병합 SHA를 기록하고 PR #38을 `v0.7.3`으로 추가했다.
- 일반 릴리즈 워크플로의 기존 경로 제외 정책에 맞춰 이번 PR은 백필 전용 파일만 변경해 두 워크플로가 다시 경합하지 않게 했다.
- 저장소 정책 테스트도 릴리즈 인프라 변경 경로로 분류하고, 교정 조건과 확정 SHA를 회귀 테스트로 고정했다.

## 안전 검토

- 임의 태그나 릴리즈를 삭제하지 않는다.
- 잘못 생성된 것으로 확인된 버전, 정확한 SHA, PR #37 본문 표식이 모두 일치할 때만 교정한다.
- 예상과 다른 태그가 있으면 기존처럼 실패해 수동 검토를 요구한다.
- Secret과 환경변수는 변경하지 않았다.
