# Spec 43 접근성 정보 게시판 AI 작업 로그

- 제목: 현장에서 확인한 접근성 정보 게시판
- 작성자: Codex
- 최종 상태: 구현·검증 완료, 사람의 운영정책 승인 전 기본 비활성
- AI 도구: Codex

## 목적

기존 커뮤니티 안에 `현장에서 확인한 정보` 유형을 추가한다. 선택한 공식 공개 관광지 ID, 확인 날짜, 본문만 구조화하고 여행자 경험을 공식 시설정보와 분리한다. 장애 인증이나 장애·건강·복지 정보, 현재 위치 좌표, 사진은 수집하지 않는다.

## 역할 구분

- 사람: 공개 읽기/로그인 작성 정책, 개인정보처리방침·약관 문구, 운영 활성화(`WAVE_FIELD_REPORT_BOARD=enabled`)와 최종 병합 승인
- AI: 기능 플래그, 작성·읽기·목록·상세·장소 연결 UI, 서버 검증, DB 마이그레이션, 정책 초안, 테스트와 PR 작성

## 결과와 제한

- 기능은 기본 꺼짐이며 플래그가 꺼지면 탭·작성·직접 목록 API·개별 글 API·장소 상세에서 숨긴다.
- 기존 공개 읽기/로그인 작성, 신고·숨김·삭제 정책을 재사용한다. 별도 장애 인증이나 새 신고 체계는 만들지 않았다.
- `018` 마이그레이션의 최종 category 제약은 선행 작업의 `travel-talk`와 이번 `field-report`를 함께 보존한다. spec 29의 `017` 뒤에 병합해야 한다.
- 정책 문구와 공개/로그인 경계는 사람 검토가 끝난 뒤에만 운영 환경에서 기능 플래그를 켜야 한다.
- 병합·배포는 수행하지 않는다.
