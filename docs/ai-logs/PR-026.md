## 목적

이슈 #21의 세 번째 제안인 효과 토글 옵션을 구현한다.

## 역할과 변경

- 사람(`syt83`): 파동 효과를 켜고 끌 수 있는 선택권을 제안했다.
- Claude Code: `SitePreferences`에 `motion` 설정을 추가하고 토글 UI, 캔버스 정지,
  인트로 건너뛰기를 연결했다.
- OpenAI Codex: PR #25와 #24가 병합된 최신 `main`을 반영하고 충돌을 해소했다.
  저장소 접근 차단 예외 처리를 모션 설정에도 유지하고, 토글의 접근 가능한 이름을
  지원하는 8개 언어로 제공하도록 보완했다.

## 판단 근거

별도 설정 화면을 만들지 않고 기존 `SitePreferences`에 넣었다. 언어·테마와 성격이
같은 표시 설정이고 이미 헤더 어디서나 닿을 수 있으므로, 새 화면을 늘릴 이유가 없다.

저장된 선택이 없을 때 운영체제의 `prefers-reduced-motion`을 따르도록 했다.
동작 줄이기를 이미 켜 둔 이용자가 다시 설정을 찾아 끄게 만들 이유가 없다.

`calm`에서 캔버스를 완전히 제거하지 않고 정지 화면 한 장을 남긴 것은, 히어로
레이아웃이 캔버스 자리를 전제로 짜여 있어 제거하면 여백이 무너지기 때문이다.
배경으로만 쓰이는 히어로 캔버스는 CSS에서 감춘다.

## 검증

브라우저 자동 검증으로 다음을 확인했다.

- 초기 `data-motion=full`, 토글 클릭 후 `calm`, `aria-pressed`와 `localStorage` 동기화
- `calm`에서 인트로가 뜨지 않고 히어로 캔버스가 `display: none`
- `full`로 되돌린 뒤 다음 새 방문에서는 기존 6.55초 인트로가 정상 재생됨
- 최신 `main` 병합 후 `npm run lint`, `npm run typecheck`, `npm test`,
  `npm run build:vercel`, `git diff --check` 재실행

이슈 #21의 세 제안은 이것으로 모두 반영된다(밀도·속도는 #24, 토글은 이 PR).
