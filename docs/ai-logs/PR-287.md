  초기 설정 복원과 OS 설정 변경을 `startTransition`으로 처리해 DOM을 유지한다.
  조건부 focus 복원 코드는 제거하고 실제 버튼 동일성·양방향 motion 변경·다른 링크로

- 이동수단: 날짜별 장소 2곳과 전체 2구간 및 combobox는 실제로 렌더링되어 있었다.

  `aria-labelledby`로 명시해 기존 정확한 label assertion을 그대로 유지했다.

## 의사결정과 안전

- 전체 일정의 날짜별 이동 구간 조회·선택 수단별 확인 수·지도 출발점 일치·단계별 수동 확인을 추가했다. private GPS 출발은 조회에서 제외한다. 범위·순서 변경 시 이전 결과는 완료 판단에 사용하지 않는다.
- CI #643은 229 통과·2 실패·1 skipped. 두 실패는 OS 동작 감소 설정 변경 때의 포커스 유지로, 새 사용자 초점을 덮어쓰지 않는 조건부 복원과 진단 기록을 추가했다.
- CI #642: 224 통과·2 실패·1 flaky·1 skipped. 옛 백분율 기대값 갱신, 캔버스 DOM 보존 재생, 캡처에서 드러난 고정 헤더 겹침 수정과 좌표 검사 추가.
- 날씨 재검색/사용자 확인 기반 대안 교체를 실제 상태 변경에 연결했다. 제공처별 요청 예산으로 빠른 성공 결과를 보존하고 선택 부가 API가 핵심 장소·상세 조회를 가로막지 않게 했다.
- API 키·개인 GPS·KTO 원본 전체를 저장하지 않는다. 공개 관광지 좌표만 장소 스냅숏에 보관한다.
- 코드로 증명할 수 없는 실제 지원 부문·신고·참가자 이력·당사자 검증은 외부 확인으로 남긴다.
- 문서의 '②-2 확정' 단정을 철회하고 #11에 불일치 위험을 반영했다.
- 미완료 P0/P1 이슈를 자동으로 닫지 않는다. 초안 PR 상태로 보존한다.
