## 사용자 요청

기존 런칭 개선 작업을 유지하고 인수인계의 P0/P1을 현 코드와 운영 서비스에서 재현한 뒤
수정·테스트·브라우저·배포 루프를 계속한다. 지원 부문·자격·위치정보 법적 요건 등은 추정하지 않는다.

## 수행한 변경

[런칭 점검 기록](../launch-audit-2026-09-05.md)에 원인, 변경, 확인되지 않은 항목을 기록했다.
정밀 현재 위치의 경로 API 차단은 기존 동작을 유지하고, 지도 SDK의 외부 처리 범위를
정확하게 안내한다. 미래 방문 후기는 거부하며 기존 해당 행을 삭제하지 않고 검토 대기로 돌린다.
기본 장애 유형을 가정하던 추천을 명시적 선택으로 바꾸고 날짜별 일정·지도 기준을 맞춘다.

- CI #642: 224 통과·2 실패·1 flaky·1 skipped. 옛 백분율 기대값 갱신, 캔버스 DOM 보존 재생, 캡처에서 드러난 고정 헤더 겹침 수정과 좌표 검사 추가.
