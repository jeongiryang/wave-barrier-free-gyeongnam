## 유지하는 제품 계약

- 걷기·휴식·동행은 편의창 안에서 접힌 상태로 시작하고 별도 계획 경로와 같은 설정을 사용한다.
- 기기 내 조건 저장·불러오기와 여행 열기는 비로그인 이용 가능하다. 계정 저장에만 로그인을 요구한다.
- 검색→담기→일정→검색, 날짜 초안, 새 여행과 이전 기록 보관을 유지한다.
- 조회 API, 페이지 계산, 여행 저장 형식, 확인되지 않은 편의를 필수 편의로 인정하지 않는 기준을 바꾸지 않는다.
- 사진은 기존 밝기를 유지한다. 하단 사진 제거 외 사진 음영에 손대지 않는다.

## 검증 및 원본 정리 기준

회귀 분류와 수정 근거는 [CI 분류 기록](unified-ci-triage.md)에 기록한다. 기존 성능 한도를 높이거나 테스트를 삭제해서 통과시키지 않는다. 바뀐 화면의 테스트는 동작·접근성 목적을 유지하면서 현재 계약으로 갱신한다.

최종 커밋의 단위·타입·린트·빌드·성능·보안 및 전체 PR CI 통과 후 동일 커밋을 로컬 실행한다. 원본 다섯 PR은 이 검증과 로컬 확인이 끝난 뒤에만 통합 PR 링크와 반영 내역을 남기고 병합 없이 닫는다. 통합 PR은 열린 상태로 유지한다.
