## 목적

기존 도움말의 정적인 목록을 현재 화면의 실제 섹션을 차례로 보여 주는 커스텀
가이드로 바꾼다. 사용자는 설명과 화면의 위치를 직접 연결해 이해할 수 있어야 한다.

## 사람의 요청과 AI의 역할

- 사람: 도움말 버튼을 누르면 커스텀 모달이 열리고, 화면과 안내 포인터가 각 섹션으로
  이동하면서 테두리와 설명을 보여 달라고 요청했다.
- OpenAI Codex: 랜딩 5단계와 플래너 6단계의 대상·설명을 설계하고 스크롤 추적,
  스포트라이트, 안내 포인터, 단계 이동, 모바일·키보드 접근성을 구현했다.

## 구현 판단

웹 페이지가 실제 운영체제 마우스 포인터를 강제로 움직이는 것은 불가능하며 사용자
제어권도 침해할 수 있다. 따라서 실제 포인터 대신 화면 위의 안내 포인터가 강조
영역으로 이동하게 했다. 스크롤 중에는 대상의 현재 위치를 매 프레임 다시 계산해
테두리와 포인터가 섹션을 놓치지 않도록 했다.

모달은 `Escape`, 포커스 순환, 닫은 뒤 원래 버튼으로 포커스 복귀를 지원한다.
모션 감소 설정에서는 부드러운 스크롤과 위치 전환을 즉시 이동으로 바꾼다. 기존에
980px 아래에서 숨기던 도움말 버튼도 44px 아이콘 버튼으로 유지한다.
