# PR 123 — 경로 요청과 위치·표시 상태 분리

## 목적

- 경로 컨트롤러에 함께 있던 위치 개인정보 처리, 네트워크 요청, 경로 표시 상태의 변경 경계를 분명히 한다.

## 변경

- `useRouteRequest`가 자동차·교통 경로, 목적지 관광 집중 정보, 공급 범위, 요청 취소와 초기화를 담당한다.
- `useRouteOrigin`은 기기 위치와 출발지 정책을 계속 독립 관리한다.
- `useRouteView`는 정렬, 교통수단 필터, 활성 경로 선택만 담당한다.
- `useRoutePlanning`은 세 기능을 연결하고 기존 화면 계약을 제공하는 파사드로 축소했다.
- 구조·경쟁 상태 테스트가 요청 모듈을 포함해 검증하도록 갱신했다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test` — 66/66 통과
- `git diff --check`

## 안전성

- 기기 현재 위치는 서버 경로 요청으로 보내지 않는 기존 정책을 유지했다.
- 경로 요청은 교체·unmount 시 취소하며 오래된 응답을 무시한다.
