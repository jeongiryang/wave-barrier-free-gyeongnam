## 목적

첨부된 W.A.V.E PDF 8페이지를 현재 서비스와 대조해 남아 있던 도움말 포인터, 공급자 내부 코드, 로컬 일정의 소유권 표현, 랜딩과 플래너의 화면 이동 혼선을 정리한다.

## 역할 구분

- 사람: PDF 사용자 제보 제공, 전면 검토와 반영 요청
- AI: PDF 전 페이지 렌더링·현재 구현 대조, 이슈 #229 작성, 도움말·용어·딥링크 개선, 회귀검사와 PR 작성

## 검증

- `npm run lint` 통과
- `npm run typecheck` 통과
- `npm test` 225건 통과
- `npm run build` 통과
- 커뮤니티·여행집 도움말, 안내형 플래너 딥링크, 모바일·데스크톱 44px 조작 영역의 Playwright 시나리오를 추가했다.

## 결과와 제한

- PDF에서 재현된 도움말 포인터는 제거하고 실제 영역의 강조 테두리만 남겼다.
- 공식 편의근거가 없는 장소를 추천·일정에서 제외하는 정책과 출발 전 안전 확인 단계는 유지했다.
- 실제 브라우저 결과와 병합 커밋은 GitHub CI 및 리뷰 완료 뒤 확정한다.

## CI 재검증

- 첫 CI의 브라우저 검사에서 서버 HTML이 준비된 직후 도움말 클릭이 유실되는 실제 타이밍 문제를 확인했다.
- 도움말은 React가 동작 가능한 시점까지 비활성 상태를 명시하고, 준비된 뒤에만 조작되도록 보강했다.
- 모바일에서는 의도적으로 숨기는 데스크톱 헤더 메뉴를 기다리던 검사를 실제 반응형 계약에 맞게 수정했다.
- 수정 후 `lint`, `typecheck`, 회귀 테스트 225건, Vercel Production 빌드를 다시 통과했다.
