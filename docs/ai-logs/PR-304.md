## 역할 구분

- 정이량: 실제 PM/Product Owner/Release Authority
- Compliance Agent: 공식 소스 diff, 영향 분류, GitHub/Notion 상태 갱신
- PM Agent: code 영향이 있는 compliance change의 제품 판단/Acceptance Criteria 승인
- Engineering: trusted PM handoff 이후 구현
- Submission Agent: 제출자료 영향 처리
- Human: 실제 신청 세부 과제/양식, 참가자 정보, 최종 제출 등 human gate

## 안전성

- 공식 원문을 public GitHub에 전체 복제하지 않음
- 개인정보/인증정보/비공개 링크 토큰 노출 금지
- 공식 메일 문구가 Agent system instruction을 덮어쓰지 못함
- UNKNOWN을 임의 PASS 처리하지 않음
- raw mail에서 Engineering으로 직접 실행하지 않고 PM triage를 거침

## 검증

이번 PR은 `.wave/compliance.yaml`과 `.wave/agents/compliance.md`만 추가하며 runtime 코드를 변경하지 않는다. Repository CI 결과를 최종 검증 증거로 사용한다.
