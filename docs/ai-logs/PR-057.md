# PR #57 · 접근성 근거 우선 추천

## 발견

프로덕션에서 휠체어 이용 조건으로 검색했을 때 공식 편의정보가 전혀 없는 장소가
첫 추천, 자동 길찾기 목적지, 첫 일정 지점으로 선택됐다. 공식 편의정보가 확인된
장소들이 뒤에 있어 서비스의 핵심 가치인 무장애 근거 우선 원칙과 맞지 않았다.
데이터 출처 카드의 두 자리 번호도 10번째부터 `010`처럼 표시됐다.

## 구현

- 선택한 편의조건의 공식 근거 유무, 일치율, 확인된 필드 수 순으로 추천한다.
- 공식 근거가 없는 후보는 삭제하지 않고 검증된 후보 뒤에서 한계를 알린다.
- 일정 근거 표시를 `편의근거 확인`, `방문 전 확인`, `추천 맥락`으로 구분한다.
- 데이터 출처 카드 번호를 항상 올바른 두 자리 형식으로 표시한다.
- 위 규칙이 회귀하지 않도록 테스트를 추가했다.

나오고 일정·경로가 같은 후보를 가리키는지 다시 확인한다.
