# 커뮤니티 시연 데이터 정렬 다양화

Owner 요청: 최신순·인기순·댓글순을 선택했을 때 차이가 뚜렷하게 보이도록 커뮤니티 시연 데이터를 다양화한다.

## 변경

- 기존 게시글 360개·댓글 720개 및 ID 유지. 18개 지역별 글 20개와 6개 카테고리 유지.
- 작성일을 지역별로 섞고 댓글 수를 글별 0·1·2·3·5·8개로 재분배한다. 추가 답글은 해당 글의 가상 상황에 대한 의견이다.
- 시연 좋아요를 글별 0~48개로 추가한다. 전용 ID만 사용하고 실제 계정을 만들지 않는다. 기존 좋아요의 수정·삭제 없이 중복 키는 건너뛴다.
- 목록·상세에 ‘반응 수 시연 포함’을 표시한다. 공식 관광 정보·시설·좌표·사진·방문 증거는 생성하지 않는다.
- 신고 이력이 있는 댓글을 다른 글로 옮기려 하면 전체 트랜잭션을 중단한다. 신고 대상과 원래 글 연결을 보존한다.

## 검증

- 독립 QA에서 발견한 댓글 이동 시 신고 연결 불일치 위험을 위의 원자적 검사로 보완했다.
- PGlite에 실제 migration과 운영 repository SQL을 실행: 기존 2댓글/글 데이터 갱신, 실제 반응 보존, 정렬 내림차순, 첫 글 3개 구분, 재적용 중복 방지, 숨김/복구, 신고 댓글 이동 차단 통과.
- 생성 데이터의 각 정렬 첫 12개에서 지역 6개 이상, 정렬 간 겹치는 글 최대 3개를 확인한다.
- lint, typecheck, 전체 테스트 1,655개, build:vercel, 성능 예산 통과.
- 운영 사전 점검: 글 360개·댓글 720개 활성, 좋아요/신고 0, 비시연 행 4개는 이미 숨김 상태. 운영 적용은 PR 배포 이후 별도 수행한다.

CI·배포 및 운영 적용 결과는 PR의 후속 기록으로 남긴다.
