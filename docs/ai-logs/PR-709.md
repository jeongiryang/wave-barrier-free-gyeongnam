## 목적과 사람의 결정

사용자가 #688·#701·#703·#706·#707을 한 PR로 통합하는 계획을 직접 승인했다. 소개 하단은 단색·자동 높이로 마무리 문구와 일반 링크를 유지한다. 검색 12개와 반응형 카드, 비로그인 기기 저장과 여행 열기, 편의창 안의 걷기·휴식·동행 설정을 유지한다. 사진 음영을 변경하지 않는다.

AI는 원본 diff·설명·CI를 대조하고 코드·테스트·문서를 통합했다. 원본별 매핑은 [의도 대조표](unified-pr-intent-map.md), 실패 원인과 회귀 수정은 [CI 분류](unified-ci-triage.md)를 참조한다.

## 전달 조건

최종 CI 전체 통과와 동일 커밋의 로컬 화면 확인 후에만 원본 PR을 대체 링크와 함께 병합 없이 닫는다. 통합 PR은 열린 상태로 유지한다. 외부 제공처의 실제 응답과 브라우저 테스트 fixture는 구분해 기록한다.
