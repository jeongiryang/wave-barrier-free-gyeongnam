# 서비스 소개 모션·카드 구성 및 나루 드래그

- 작성자: jeongiryang
- AI 도구: Codex, 구현과 분리한 QA 에이전트
- 승인: 사용자가 지목한 미반영 6개 UI 요구의 구현·검증·배포. AGENTS의 Owner 리뷰 대기 면제를 적용하며 필수 validate 성공은 유지한다.

## 변경

1. 푸터의 일반 링크 display 규칙이 GitHub 아이콘 정렬을 덮던 충돌을 수정했다.
2. 첫 화면 바탕과 야간 화면의 로딩 스켈레톤 색을 통일했다. 나루 지연 로딩은 화면 전체의 밝은 줄 대신 닫을 수 있는 작은 어두운 패널을 사용한다.
3. 나루 헤더를 마우스로 끌어 이동한다. 버튼은 제외하며 화면 밖 이동을 제한한다. 크기 변경·닫기·모바일 전환 때 기본 위치로 복구한다. 이동 안내 문구는 추가하지 않았다.
4. 대표 문구를 총 4개로 구성해 6초마다 등장 모션으로 바꾼다. 일시정지·마우스 올림·키보드 초점·배경 탭·화면 밖·인트로 중에는 전환을 멈춘다. 모션 감소 설정과 스크린리더의 고정 제목을 보존한다.
5. 축제 미리보기는 사진 전체 위에 이름·기간·지역을 겹쳐 표시하고 어두운 그라데이션으로 글자 대비를 확보한다.
6. 하단의 커뮤니티·축제·여행 정보는 세로로 순서대로 읽도록 배치하고 기존 스크롤 진입 효과를 적용한다. 강제 스크롤이나 빈 화면 높이는 추가하지 않았다.

## 역할과 검증

- 사람: 6개 요구 및 디자인 방향 결정.
- AI: 구현, 독립 QA, 로컬 검사, PR·CI·CD 및 실제 운영 화면 확인.
- 독립 QA가 대표 문구의 닫힌 인트로 감지와 hover/focus 해제 충돌을 발견했고 수정했다.
- 단위 검사 1,678개 통과. 타입 검사 성공, lint 오류 0개(기존 경고 25개).
- 기존 브라우저 회귀 30개, 새 실패 경계 검사 8개 통과. 새 검사는 문구 4개 순환과 중지, 드래그 경계·복구·버튼 제외, 세로 배치·사진 내 텍스트·아이콘 중심, 지연 로딩 취소 후 자동 재개 방지를 확인한다.
- 기존 회귀에는 320/390/960/1366/2560/3840px 화면과 접근성 검사가 포함된다. 수동 화면 확인에서 QHD GitHub 아이콘 중심 오차 0px 및 나루 실제 마우스 이동을 확인했다.
- 브라우저의 축제 데이터·연결 상태는 합성 fixture 검사와 실제 운영 확인을 구분한다. 로컬 제공처 미설정은 운영 장애로 해석하지 않는다.

## 배포 및 제한

- 환경변수·DB·LLM·인증 및 제출 자료를 변경하지 않는다.
- 최종 CI/CD 및 운영 확인의 결과는 PR에 기록한다. 병합만으로 배포 완료를 주장하지 않는다.
- 되돌리기는 이 변경의 squash 커밋을 revert하는 PR로 수행할 수 있다.
