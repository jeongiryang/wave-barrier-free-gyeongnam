# PR #59 · 여행 상황 변화 대응과 플래너 흐름 개선

## 발견

프로덕션 플래너가 공식 날씨·관광 집중률을 보여 주고 있었지만 현재 일정에 미치는
영향과 실행 가능한 대안으로 연결하지 못했다. 또한 CSS `order`가 DOM 순서와 달라
화면의 섹션 순서와 키보드 초점 순서가 어긋났고, 예보 범위 밖 여행일에 첫 예보를
해당 날짜 정보처럼 사용할 수 있었다.

## 구현

- 공식 여행일 예보와 한국관광공사 관광 집중률을 일정 영향 신호로 해석한다.
- 비·눈·폭염과 관광 집중률 상승 시 실제 재검색 또는 다음 공식 추천지 경로 비교를 제공한다.
- 예측 집중률을 정확한 실시간 방문자 수와 구분하고, 조회 중·실패·정보 없음 출처 상태를 표시한다.
- 플래너의 DOM·시각·키보드 순서를 조건 → 추천 → 상황 → 이동 → 일정 → 근거로 통일한다.
- 예보 범위 밖 날짜는 현재 날씨만 참고한다고 명시하고 다른 날짜의 예보를 대체하지 않는다.
- 상황 판단 로직과 접근성·출처·섹션 순서를 고정하는 회귀 테스트를 추가한다.
- README의 기능 흐름과 로컬 개발 주소, 공모전 정합성 문서를 실제 구현과 맞춘다.
