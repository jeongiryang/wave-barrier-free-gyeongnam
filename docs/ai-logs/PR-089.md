# PR-089 — 관광 인사이트 공급자 경계 분리

## 목적

관광 집중, 방문자·수요, 축제·숙박·테마 공급자 호출과 응답 조립이 한 파일에
있던 인사이트 모듈을 데이터 성격별로 분리한다.

## 변경

- 관광 집중도·연관 관광지 조회를 `concentration`으로 분리
- DataLab 방문자와 관광 수요 조회를 `visitor-demand`로 분리
- 캠핑·반려동물·웰니스·의료·수변·휴게소·행사·숙박 orchestration 분리
- 날짜 정규화를 공통 `date-utils`로 이동
- `insights`는 query validation, source 호출, provenance-aware 응답 조립에 집중
- 운영 데이터 및 서버 아키텍처 회귀 테스트 갱신

## 안전성

공식 API 실시간 조회 원칙, provider timeout, 광역 fallback, 데이터 출처와 상태
표현을 유지한다. 결과가 없는 공급자의 데이터를 생성하지 않는다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

API 응답 형식, DB, 인증, 환경변수, migration 변경은 없다.
