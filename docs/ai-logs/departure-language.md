## 근본 원인과 변경

1. 카드·상태 계산 결과·캘린더 설명이 한국어로 고정돼 있었습니다. locale을 전달하고 상태/날짜/근거 판정은 그대로 유지합니다. 원문은 영어로 지어내지 않고 별도 언어를 표시합니다. 같은 일정의 ICS UID, KST 날짜/시간, 장소명, 공유 URL은 보존합니다.
2. 준비 중 버튼의 native disabled가 키보드 포커스를 제거했습니다. 실행 중에는 aria-disabled/aria-busy와 중복 실행 가드를 사용하고, 빈 일정·지난 일정 등 실제 사용할 수 없는 조건의 disabled는 유지합니다.
3. 넓은 화면에서는 포커스가 잡힌 뒤 늦게 로드된 일정 영역 때문에 출발 버튼이 화면 밖으로 밀려났습니다. 진단에서 버튼 y=571(화면 내) → 2253(900px 화면 밖)을 확인했습니다. 출발 카드에서 현재 포커스와 작업 영역 크기 변화를 관찰해 필요한 경우만 즉시 화면 안으로 이동합니다. 휠·터치·pointerdown·blur·unmount 후에는 중단합니다. 다른 요소에 focus를 호출하지 않습니다.
4. 긴 카드의 요소 캡처는 고정 헤더/하단 메뉴를 중간에 합성할 수 있으므로, 별도 실제 viewport 캡처와 Tab 이동 중 elementFromPoint 검사도 추가했습니다. overflow CSS를 바꾼 진단은 효과가 없어 최종 변경에 포함하지 않았습니다.
