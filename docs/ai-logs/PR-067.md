# PR #67 · 공통 스타일 책임 경계 분리

- AI 도구: Codex

## 목적

205KB가 넘는 `app/globals.css`의 마지막 공통 보정 블록을 cascade 순서를 바꾸지 않고 분리해, 디자인 시스템과 접근성·모바일 경험 규칙의 책임을 명확히 한다.

## 역할 구분

- 사람: W.A.V.E 전체 품질 개선과 안전한 점진 분리, 검증·PR·병합·배포 권한 위임
- AI: 기존 스타일 순서 감사, 경계 설계, 코드·테스트·문서 변경, 로컬 검사, PR 작성과 배포 확인

## 구현

- 공통 간격·모서리·그림자·모션 토큰과 반복 패턴을 `app/styles/design-system.css`로 분리했다.
- 모션 감소, 도움말 투어, 터치 영역, 안전 영역과 반응형 최종 보정을 `app/styles/experience-accessibility.css`로 분리했다.
- `app/layout.tsx`에서 기존 cascade와 같은 순서로 두 파일을 불러오도록 했다.
- 스타일 회귀 테스트가 특정 단일 파일이 아니라 실제 공통 스타일 묶음을 검증하도록 갱신하고, import 순서 회귀 검사를 추가했다.
- 디자인 시스템 문서의 토큰·접근성 스타일 위치를 실제 구현과 일치시켰다.

## 검증

- 분리 전 `app/globals.css`와 분리 후 세 파일을 import 순서대로 합친 결과가 바이트 단위로 동일함
- `npm run lint`: 성공
- `npm run typecheck`: 성공
- `npm test`: 60/60 성공
- `npm run build:vercel`: 성공 (`nodejs22.x`, CSS 산출물 해시 유지)
- `npm audit --omit=dev --audit-level=high`: 취약점 0건
- `git diff --check`: 성공

## 결과와 제한

- CSS 선언과 cascade가 동일하므로 의도된 시각·동작 변경은 없다.
- `app/globals.css`는 205,845바이트에서 191,247바이트로 줄었다. 플래너·지도 스타일은 과거 버전별 override가 서로 얽혀 있어 이번 단위에 섞지 않고 다음 점진 분리 대상으로 남긴다.
