## 목적

단계별 도움말을 실행할 때 강조 테두리가 화면 전체를 덮거나 부드러운 스크롤을
뒤늦게 따라가며 흔들리고, 작은 화면에서는 도움말 모달과 강조 영역이 겹치는
문제를 해결한다.

## 원인 분석

기존 구현은 높이가 여러 화면에 걸치는 섹션 전체를 강조 대상으로 사용했다.
또한 스크롤 이벤트마다 바뀌는 테두리 좌표에 0.45초 CSS 전환을 다시 적용해,
현재 위치보다 이전 위치를 따라가는 것처럼 보였다. 모달이 차지하는 영역도
강조 사각형 계산에서 제외하지 않았다.

## 변경

- 이동 기준 섹션과 강조할 핵심 제목·요약 영역을 분리
- 단계 전환 시 이전 강조 영역을 즉시 숨긴 뒤 새 영역 표시
- 강조 영역을 뷰포트 안으로 제한하고 최대 높이를 화면 높이의 46%로 제한
- 도움말 모달과 가로로 겹치면 모달 위까지만 강조
- 스크롤 중 위치 지연을 만들던 좌표 CSS 전환 제거
- 대상 크기가 바뀌면 `ResizeObserver`로 테두리 재계산
- 작은 화면·동적 콘텐츠 회귀 테스트 보강
