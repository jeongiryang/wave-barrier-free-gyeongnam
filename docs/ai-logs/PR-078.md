## 목적

전역 token과 route 상태, 인트로·헤더, 랜딩 탐색, 경로·데이터, 장소 dialog 스타일이
`app/globals.css` 한 파일에 함께 있어 변경 영향 범위를 파악하기 어려웠다.

## 역할 구분

- 사람: 남아 있는 책임 혼합 영역을 모두 점진 분리하도록 위임
- AI: cascade를 보존하는 스타일 경계 설계, 기계적 이동, 회귀 검증과 PR 처리

## 구현

- `globals.css`에는 Leaflet import, 전역 token·reset·route 상태·공통 접근성 primitive만 남겼다.
- 인트로와 공통 헤더는 `site-shell.css`로 이동했다.
- 랜딩 Hero·조건·장소 영역은 `landing-explorer.css`로 이동했다.
- 경로·공식 데이터 영역은 `landing-route-data.css`로 이동했다.
- 종료 CTA·장소 결정 dialog·footer·반응형 규칙은 `place-dialog.css`로 이동했다.
- `layout.tsx` import 순서를 기존 selector cascade와 동일하게 유지했다.

## 검증

- 원본 CSS와 분리 파일 연결 결과 byte 단위 비교
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 결과와 제한

- selector·declaration·media query는 수정하지 않았고 파일 경계만 이동했다.
- API, DB, 환경 변수 변경은 없다.
