# PR 131 — 장소 판단 근거와 여행자 참여 화면 분리

## 목적

- 장소 상세 대화상자에 섞인 공식 접근성 판단과 사용자 후기·제보·보관 행동을 명확히 구분한다.

## 변경

- `PlaceEvidenceSummary`: 잘 맞는 이유, 추가 확인 항목, 공식 출처·확인 시각·정보 확인률을 표시한다.
- `PlaceParticipationActions`: 외부 최신 후기, W.A.V.E 여행자 이야기, 보관함과 현장 정보 제보를 담당한다.
- `PlaceDecisionDialog`은 접근 가능한 대화상자 껍질과 두 정보 영역을 조합한다.
- 커뮤니티 연결 테스트가 분리된 화면을 함께 검증한다.
