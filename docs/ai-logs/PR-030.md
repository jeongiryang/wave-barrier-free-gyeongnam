## 목적

첫 화면의 추천 여행지 카드에서 진해해양공원·통영케이블카·진주성 사진이
표시되지 않고 회색 대체 배경만 보이는 문제를 해결한다. 임의 외부 이미지나
생성 이미지를 넣지 않고 한국관광공사 OpenAPI의 공식 관광사진만 사용한다.

## 원인 분석

프로덕션 `spot-photo` API를 장소별로 직접 확인한 결과 세 장소 모두 공식 사진
URL을 정상 반환했다. 그러나 추천 여행지 카드는 사진 URL이 비어 있을 때 이 API를
호출하는 `SmartSpotImage`를 사용하지 않았고, 초기 미리보기 데이터의 빈 `image`
값을 CSS 배경으로 그대로 렌더링했다.

또한 기존 사진 선택 로직은 장소명 일치도를 비교하지 않고 관광사진 API의 첫
결과를 우선해, `진주성` 검색에서 `진주 남강유등축제` 사진을 고를 수 있었다.

## 변경

- 추천 여행지 카드에도 `SmartSpotImage` 적용
- 선택 지역이 아니라 각 카드의 실제 시·군으로 사진 검색
- 실제 관광 콘텐츠 ID가 있으면 `detailCommon2`로 정확한 사진을 먼저 조회
- 검색 후보의 장소명 일치도를 계산해 정확한 관광정보 사진 우선
- 키워드를 순차 조회해 여러 카드가 열릴 때 공공데이터 API를 한꺼번에 과호출하지 않도록 제한
- 공식 사진이 없거나 실패하면 기존 스켈레톤·브랜드 대체 화면 유지
- 추천 카드 사진 경로 회귀 테스트 보강

## 데이터·저작권

사진은 한국관광공사 국문 관광정보 및 관광사진 OpenAPI의 HTTPS URL만 사용한다.
사진 원본을 저장소나 Neon DB에 복제하지 않으며, API가 사진을 제공하지 않으면
오해를 부르는 임의 장소 사진 대신 W.A.V.E 대체 화면을 표시한다.
