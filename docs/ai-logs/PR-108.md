# PR-108 — 커뮤니티 편집 controller 분리

## 목적

글쓰기·수정 화면이 session, URL 관광지 연결, 기존 글 조회, 저장 HTTP와 form JSX를
함께 소유하던 구조를 feature controller와 view로 분리한다.

## 변경

- 새 글 URL 초기값, 수정 글 소유권 확인, 저장·로그인 복귀를 `useCommunityEditor`로 이동
- 글 생성·수정 HTTP 계약을 기존 community client API 경계에 추가
- 편집 view를 `features/community/components`로 이동
- 신규·수정 page import와 커뮤니티 구조 회귀 테스트 갱신

## 안전성

서버 소유권 검증에 더해 수정 화면의 owner 확인, 401 로그인 후 복귀, request abort,
입력 길이·개인정보 안내, 관광지 연결·해제와 접근 가능한 loading/error 상태를 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

Community 작성 화면 마크업과 session·저장 수명주기를 독립적으로 변경하고 테스트할 수 있다.
