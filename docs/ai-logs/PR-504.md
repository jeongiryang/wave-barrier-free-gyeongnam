## 목적

PR #502 운영 시연에서 자동차 이동수단 유실, 창원 출발 저부담 당일 여행의 먼 지역 기본 추천, 이미 실내인 여행의 실패처럼 보이는 안내를 재현했다. 저장·복원에서 같은 여행 상태를 유지하고 요청에 맞는 검색 기본값과 변경 불필요 안내를 제공한다. 대화의 되돌리기와 소개 예시 일시정지 버튼에도 같은 조작 크기와 스타일을 적용했다.

## 역할 구분

- 사람: 사용성·접근성 중심의 전면 개선, 무료 로컬 모델, 실제 브라우저 점검, 필요한 수정·PR·배포를 지시했다.
- AI: 운영에서 직접 재현하고 허용 이동수단의 단일 상태·직렬화, 좁은 출발 지역 기본값, 공식 실내 근거 기반 변경 불필요 결과를 구현했다. 저장 실패·오래된 응답·기존 형식·나루 되돌리기를 검사하고 독립 리뷰했다.

- 전체 단위1,103 PASS, 타입 PASS, ESLint 오류0·기존 경고12.
- 이동수단 신규14 및 기존 복원·여행집·경로18·나루18, 고유50 브라우저 PASS, 재시도0. 실행 중 HMR이 개입한 기존2개는 trace로 확인하고 소스 동결 뒤 별도로 PASS했다.
- 근접 당일 검색 관련84개, 변경 불필요·제공처 실패 경계23개 단위/함수 검사를 수행했다. 이 수는 전체 단위와 중복된 범위이며 합산하지 않는다.
- 변경 불필요 관련 desktop/mobile16개 PASS. 위50개와 기존 나루 검사가 일부 겹치며 합산하지 않는다. 현재 일정·편의 저장 호출0, 기존 미적용 안과 되돌리기 보존, 취소·오래된 응답을 확인했다.
- 실제 모델은 정확한 부모님·창원 출발 당일 요청에 창원 지역과 두 장소, 각60분방문·20분휴식을 제안했다. 실제 아트센터 우천 대비 조회도 변경 불필요로 안내하고 장소·날짜·휴식·이동수단을 보존했다. 미리보기 경로 인증키가 없는 구간은 실제 이동시간 성공으로 기록하지 않는다.
- 빌드·성능 예산 PASS: CSS gzip67.13KiB, 소개 초기JS140.99KiB, Planner 초기JS217.81KiB.
- 이동수단 소스의 독립 읽기 검토에서 추가 P0/P1 없음. 실제 제공처·모델 재확인과 hosted CI 결과는 PR의 최종 기록으로 구분한다.

첫 전체 CI `34704357303`은 단위1,103개·브라우저1,422개가 통과하고, 출발 준비의 영어 데스크톱2개·모바일1개가 같은 새로고침 검사에서 실패했다. 중복 화면 크기 검사1개는 기존 설정대로 생략했다. 원본과 재시도 trace에서 복원한 자동차 모드의 새 API 요청과 성공 응답을 확인했다. 제품이 경로 근거를 저장해 재사용한 문제가 아니라, 예전 검사가 이동수단 초기화를 전제한 문제였다. 해당 검사만 새 응답을 보류하는 동안0·미확인, 해제 후2·확인으로 확인하도록 수정했다. 8개 언어·테마·기기 변형과 이동수단14개, 합계22개가 재시도 없이 통과했다.

두 번째 전체 CI `34705266405`는 단위1,103개·브라우저1,424개가 통과했지만 혼잡도 바로가기 검사1개가 첫 실행에서 실패하고 재시도에서 통과해 필수 검증이 실패했다. Trace에는 초기 plan·crowd 요청이 각각1회뿐이었다. 초기 목적지 응답을 기다리지 않고 요청 수를0으로 읽던 검사 경합을 고쳤다. 첫 장소의 실제 응답 완료 뒤 요청이 각각1회임을 확인하고, 바로가기·키보드·뒤로/앞으로 이동 후에도 늘지 않는지 검사한다. 복원 후 새 검색 금지 검사는 유지했다. 데스크톱·모바일을 각3회 반복한18개가 재시도 없이 통과했고 타입·diff 검사도 통과했다. 두 CI 후속 변경은 테스트와 작업 기록에 한정되며 제품 코드·재시도·시간 제한·CI 성공 기준은 변경하지 않았다.

## 결과와 제한

DB 스키마·환경변수·모델·GPU·결제·배포 경로를 변경하지 않는다. 기존 JSON 일정에 허용 이동수단을 추가하며 없거나 잘못된 값은 대중교통으로 읽는다. 관광 원본 응답·경로 응답·GPS 좌표·자격 증명을 새로 저장하지 않는다. 기존 형식과 함께 읽을 수 있고 문제 발생 시 이 PR을 되돌려 GitHub CD로 배포한다.

가까운 지역 우선은 실제 이동시간이나 접근 가능한 통행의 보장이 아니다. 제공처 미확인·실패를 보존한다. 실제 사용자 계정 로그인이 없는 환경에서 합성 인증 검사를 실제 계정 성공으로 표시하지 않는다. 필수 CI 성공 이전에는 병합하거나 배포 완료라고 하지 않는다.
