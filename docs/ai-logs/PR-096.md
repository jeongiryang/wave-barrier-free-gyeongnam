# PR-096 — 여행 상황·인사이트 UI 경계 분리

## 목적

날씨, 상황 변화 대응, 지역 방문·수요 인사이트와 테마 탐색을 한 컴포넌트가
모두 렌더링하던 여행 신호 영역을 사용자 과업별 섹션으로 분리한다.

## 변경

- 현재·7일 날씨와 실패 상태를 `WeatherBoard`로 이동
- 날씨·관광 집중이 일정에 미치는 영향과 행동을 `SituationImpactPanel`로 이동
- 방문 유형과 관광 수요 맥락을 `RegionalInsights`로 이동
- 테마 탭·공공데이터 결과·경로 연결을 `ThemeExplorer`로 이동
- `TravelSignalsPanel`은 섹션 조립과 입력 전달에 집중
- 기능별 UI 경계 회귀 테스트 추가

## 안전성

loading/empty/partial-data 상태, 데이터 출처, 집중률 과장 방지 문구, 일정 변경
행동과 지도 연결을 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test` (66/66)
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

사용자 화면과 상태 계약은 유지되며 날씨·상황 대응·테마 UI를 독립적으로 변경할 수 있다.
