## 목적과 역할

Owner가 승인한 공모전S2의 2026-09-10 23:09–23:36 합의에 따라 운영 기능을 보존하며 사용 화면을 통합한다. Owner가 제공한 원문과 별도 사진/영상 답장 분석을 실제 8번·10번 사이트와 대조했다. 네이티브 카카오톡 UI를 직접 추가 확인했다고 주장하지 않으며 메시지는 보내지 않았다.

사람은 디자인 방향과 병합 권한을 승인했다. AI는 10번의 밝은 구성에 8번의 네 단계 진행, 기존 달력/조건/검색/지도/일정/계정·카카오·동행 진입을 연결하고 커뮤니티 카드·목록, 공통 헤더, 내 여행·사진 코스·사용법 표현을 적용했다. 로그인 전면 재설계와 새 백엔드 기능은 이 단위의 범위가 아니다.

## 기능 보존

[요구사항·기능 대응표](../design/eight-ten-integration-20260911.md)를 따른다. API·데이터 모델·권한·동의·외부 서비스 설정을 변경하지 않았다. 지역 18곳과 사진별 실제 출처를 보존한다. 커뮤니티 카드 표지는 실제 게시물의 지역/분류를 표현하며 가짜 게시물이나 관광 사진을 추가하지 않았다. 조건 변경, 이전 여행 복원, 오류 재시도, 날짜 재배치, 지도, 공유/보관, 내 여행 저장과 도움말은 기존 동작을 유지한다.
