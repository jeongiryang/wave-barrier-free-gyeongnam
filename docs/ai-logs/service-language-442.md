# 여행을 중심으로 저장 문구 정리

- Issue: #442
- 사람: 저장 위치·제작 설명성 문구를 제품 화면에서 제거하도록 요청.
- AI: 여행집, 편의 조건, 일정, 소개, 사진 코스, 관련 안내와 기존 테스트 기대 문구를 정리.

저장 버튼과 상태는 사용자가 한 행동을 간결하게 설명한다. 여행집 요약의 저장 위치 대신 갈 여행 수를 표시한다. 사진 파일 처리·저장 코드와 개인정보 처리방침의 실제 데이터 처리 고지는 유지한다. 계정 동기화나 서버 보관을 구현한 것으로 표현하지 않는다.

단순 문구 변경에 신규 테스트는 추가하지 않았다. 지도 범위와 같은 MVP PR에서 기존 저장·복원·편의·사진 흐름을 확인한 뒤 검증 기록을 보완한다. 별도 버그 수정이나 대규모 회귀 확장은 포함하지 않는다.

## 통합 확인
- 관련 브라우저 24개 중 20 PASS, 4 FAIL은 교체 전 문구를 찾는 여행집 기대값이었다. 기대 문구를 실제 제품과 맞춤.
- 여행집·편의 저장·사진 코스 12개 중 10 PASS, 2 FAIL도 저장 실패의 이전 문구였다. 해당 기대값 수정 후 2/2 PASS (3.7초).
- 최종 관련 계정·사진·지도 단위 21개 PASS. lint 오류 0, 타입·빌드·성능 예산 PASS.
- 실제 저장/복원, 메모, 삭제 확인, 손상/차단 저장소, 사진 EXIF→일정 연결을 기존 검사로 확인. 1440/960/390px 여행집과 960px 사진 코스 렌더링을 직접 검토했고 가로 넘침 없음.
- 단순 문구 변경 후에는 같은 전체 회귀를 반복하지 않았음. 필수 hosted CI 및 Production 확인은 PR에서 별도 추적.
