## 역할과 변경

- 사람: Vercel 단일 운영을 유지하고 실제 서비스 수준의 개인정보처리방침·이용약관·운영규정 작성을 요청했다.
- Codex: 최근 실패한 GitHub Actions 로그와 Render 잔재를 대조하고, 공개 정책 허브·상세 방침·푸터 탐색·보관 만료 동작을 구현했다.
- 기준: 개인정보보호위원회 2026 개인정보 처리방침 작성지침과 현행 개인정보 보호법·시행령의 공개 항목을 확인하되, 저장소에서 증명되는 데이터 흐름만 문구에 반영했다.

## 판단 근거

- Render는 PR #3 이후 활성 배포와 환경 검사에서 제외되어 있으며 CI는 Vercel 빌드만 검사한다.
- 최근 CI 실패는 비밀번호 재설정 E2E, DOM 교체 중 표식 접근, 랜딩 선택자·대비, 잠금 파일 누락으로 확인되어 Render 제거와 인과가 없다.
- 로그인 없이 작성하는 장소 편의 제보는 자유 입력을 포함하므로 무기한 보관하지 않고 작성 1년 뒤 상한을 둔 예약 삭제에 포함했다.
- 인증 제공처가 자동 탈퇴를 지원하지 않을 수 있는 현재 상태를 성공처럼 쓰지 않고 운영 문의를 통한 수동 삭제 경로를 공개했다.
