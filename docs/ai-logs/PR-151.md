# PR-151 — 모바일 제공 형태 결정 기록 (Refs #4)

## 목적

이슈 #4의 모바일 앱 스택 조사를 저장소 안의 결정 기록으로 옮긴다.

## 이슈와 다르게 구현한 부분

이슈 #4는 "Kotlin + Jetpack Compose로 1차 앱을 시작한다"는 결론과 선행 PoC를
요구한다. 이번 PR은 **앱을 시작하지 않는다는 결정**을 기록했다.

이슈 #11에서 제출 형태가 `②-2 웹·앱 구현 부문 / 웹`으로 확정됐기 때문이다.
두 이슈가 같은 시기에 열렸고 #11이 나중에 결론 났으므로, #4의 순위표는 유효하지만
"지금 시작한다"는 전제는 더 이상 맞지 않는다. 조사 결과를 버리지 않고 **앱을
다시 검토할 조건**과 함께 남겨, 조건이 성립할 때 순위표를 그대로 쓸 수 있게 했다.

## 변경

- `docs/mobile-app-decision.md` — 결정, 근거, 재검토 조건, 그때 고를 순서,
  앱을 만들 때 지킬 UX 원칙, 지금 웹에서 대신 하고 있는 것.
- README `관련 문서`에 연결.
- `tests/mobile-decision.test.mjs` — 이 문서의 결정과 공모전 정합성 문서의
  제출 형태가 어긋나지 않는지 고정.

## 설계 판단

**결정을 이슈에만 두지 않았다.** 이슈는 닫히면 찾기 어렵고 저장소를 클론한
사람에게 보이지 않는다. 이 저장소는 이미 운영 정책·데이터 정책·공모전 정합성을
`docs/`에 두고 있으므로 같은 자리에 둔다.

**재검토 조건을 함께 적었다.** 조건 없이 "웹으로 간다"만 남기면 나중에 근거 없이
뒤집히거나, 반대로 필요할 때도 못 바꾼다.
