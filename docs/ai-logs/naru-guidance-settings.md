# 나루 안내 설정을 대화 안에서 변경

- 사용자 요청: 이해하기 어려운 안내 방식 메뉴와, 바꾸기를 누르면 채팅창이 닫히는 흐름 개선. 프론트만 수정하고 PR까지만 작성하며 병합하지 않는다.
- 사람: 개선 범위와 병합 금지 결정.
- AI: 코드 조사, 프론트 구현, 회귀 검사, 독립 QA 및 PR 작성.

## 변경
- 모호한 기본 방식/바꾸기를 나루 안내 설정/안내 설정 열기로 바꾼다.
- 기존 다섯 안내 선호를 쉬운 제목·설명과 체크박스로 편집한다. 소리가 자동으로 재생되지 않음을 설명한다.
- 취소·Esc·닫기는 변경을 버리고 채팅을 유지한다. 적용은 기존 안내 저장/전달 경로를 사용하며 기존 여행 조건과 입력 중 질문을 보존한다.
- 화면 폭 변경 중에도 설정 창이 부모 채팅창 앞에 남도록 한다.
- 편의시설 조건을 안내 선호 요약과 섞지 않는다. 기존 맞춤 도움과 여행 도구는 유지한다.

## 검증
- 관련 모바일/PC 브라우저 회귀 검사 30개 통과: 설정 저장/취소/해제, 요청 context, 기존 조건과 입력 유지, 재접속, 음성 안내, 실시간 크기 변경.
- 1440/960/390px 및390x390 작은 화면에서 영역·44px 조작 대상·키보드·axe 확인. PC와 모바일 스크린샷 직접 확인.
- 전체 단위1674개, lint오류0(기존경고25), typecheck, 빌드, 성능예산, 보안감사 통과. 최종 UI 보완 후 lint/typecheck/build/performance 재확인 진행.
- 독립 QA에서 확인한 resize 문제 수정 및 회귀 검사 통과.
- 필수 PR CI의 최종 결과는 PR에 기록한다. 사용자 지시로 병합·배포하지 않는다.
