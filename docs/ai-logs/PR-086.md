# PR-086 — RouteMap 사용자 도구 경계 분리

## 목적

지도 SDK 생명주기와 여러 사용자 도구 패널의 렌더링이 결합되어 있던
`RouteMap`을 사용자 행동 단위로 분리한다.

## 변경

- 지도 command bar와 provider 상태 배지를 `MapCommandBar`로 분리
- 주변 장소, 출발·도착, 장소 상세, 레이어·측정, 이미지 내보내기 패널 분리
- 로드뷰 선택·혼잡·loading·로드뷰 상태 overlay를 전용 컴포넌트로 분리
- 회귀 테스트가 새 UI 경계와 모바일 command bar를 합성 소스로 확인하도록 갱신

## 안전성

지도 SDK와 renderer hook의 상태 소유권, 이벤트 순서, DOM class, 접근성 레이블은
유지한다. 위치정보와 경로 좌표를 저장하지 않는 기존 개인정보 정책도 그대로다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

API, DB, 인증, 환경변수, migration 변경은 없다.
