## 적용

1. 8번 `/eight/#intro`의 `PLACES TO BEGIN`을 다시 확인했다. Hero 직후 지역 영역은 큰 사진 카드 두 장과 다음 카드 일부가 보이는 가로 탐색, 모바일은 한 장과 다음 카드 일부다. 18개 지역, 지역당 복수 사진, 저작자/원본 링크, 여행 시작, 자동 재생 정지/수동 선택을 보존했다.
2. 내 여행에 비대칭 실제 사진 두 장, 큰 제목, 가로 요약, 계획/사진/계정 여행 진입을 구성했다. 실제 보관 일정의 날짜·편의·메모·방문 상태·삭제 확인·복원·계정 저장은 유지했다.
3. 예시 글은 WAVE 명의의 여행노트 3편과 독립 본문 URL로 반영했다. 바다 여행, 동행 전 준비, 사진 코스 기록을 안내한다. 가상 회원/방문 경험/좋아요 수를 만들거나 DB에 게시하지 않았다. 기존 회원 글 검색·장소 필터·페이지 이동은 그대로다.
4. 320/390/960/1440px에서 소개·여행 설계·커뮤니티·내 여행을 렌더링했다. 사진 로딩 후 캡처, 가로 넘침 0, 런타임 오류 0. 실제 KTO/Commons 사진으로 확인했다.
5. 좁은 화면에서 커뮤니티/내 여행 메뉴가 열려도 내부 nav가 숨는 CSS 충돌을 수정했다. Hero 사진 출처가 기존 story-media 박스 스타일을 상속해 하단 안내와 가까워지던 문제를 제거했다. 내 여행 도움말 강조 위치를 새 링크 영역으로 연결했다.
6. 공통 헤더는 청색 배경과 하단 선으로 연결하고 Hero 위에는 반투명 짙은 배경을 쓴다. 여행 설계에 공통 모바일 메뉴를 연결하고 메뉴 순서를 통일했다. 사진 코스의 헤더 배경도 연결했다.
