# PR 129 — 커뮤니티 소개·필터·목록 화면 분리

## 목적

- 커뮤니티 페이지에 섞인 브랜드 소개, 검색 조건, 목록 상태와 페이지 이동을 독립 화면 단위로 나눈다.

## 변경

- `CommunityHero`: 커뮤니티 목적과 공식 정보·사용자 경험의 경계를 설명한다.
- `CommunityBoardToolbar`: 글쓰기, 장소 연결, 카테고리와 검색 조건을 담당한다.
- `CommunityPostList`: 로딩·오류·빈 상태, 게시글 카드와 페이지 이동을 담당한다.
- `CommunityBoard`는 공통 헤더와 세 화면을 조합하는 페이지 경계가 됐다.
- 커뮤니티 제품 테스트가 분리된 화면을 함께 검증한다.
