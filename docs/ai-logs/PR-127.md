# PR 126 — 교통수단·제공 범위·운행 결과 화면 분리

## 목적

- 교통정보 한 컴포넌트에 섞인 수단 선택, 데이터 출처, 공식 예매, 상세 운행 결과를 독립적으로 유지한다.

## 변경

- `TransportModeSelector`: 교통수단 필터와 핵심 운행 요약을 표시한다.
- `TransportProviderDetails`: 사용자 친화적인 제공 범위와 공식 예매 이동을 표시한다.
- `TransportDatasetPanel`: 선택된 정류장·도착·열차·터미널 데이터의 로딩·빈·성공 상태를 표시한다.
- `TransportDataOverview`는 세 영역을 조합하는 파사드로 축소했다.
- 제품·구조 테스트가 분리된 화면을 함께 검증한다.

- `npm run lint`

## 안전성

- 공급자 일부 실패 시 사용 가능한 데이터는 계속 표시하는 기존 부분 실패 정책을 유지했다.
- 공식 예매는 기존 외부 링크와 개인정보 비저장 동작을 유지했다.
