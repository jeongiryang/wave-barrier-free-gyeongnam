# PR 130 — 커뮤니티 게시글과 댓글 대화 화면 분리

## 목적

- 게시글 본문·공감·소유자 동작과 댓글 작성·수정·삭제 화면을 독립적으로 유지한다.

## 변경

- `CommunityPostArticle`: 게시글 메타데이터, 연결 여행지, 본문, 공감과 소유자 동작을 담당한다.
- `CommunityComments`: 댓글 입력, 빈 상태, 목록, 본인 댓글 수정·삭제를 담당한다.
- `CommunityDetail`은 조회 상태를 처리한 뒤 두 화면을 조합한다.
- 커뮤니티 제품 테스트가 분리된 화면을 함께 검증한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test` — 66/66 통과
- `git diff --check`

## 안전성

- 권한은 계속 서버 API에서 검증하며 UI의 소유자 표시는 서버 응답만 사용한다.
- 댓글 입력 레이블, 상태 안내와 오류 역할을 유지했다.
