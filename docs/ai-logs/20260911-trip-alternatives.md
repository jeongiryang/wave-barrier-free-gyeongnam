- 작성자: jeongiryang
- 최종 상태: 구현 및 변경 기능 검증 중
- AI 도구: Codex, 독립 QA 에이전트, Playwright

## 목적

후보 3/10/11/12/21을 하나의 비교·선택 흐름으로 연결한다. 사용자는 일정을 통째로 재작성하지 않고 한 장소의 이유별 대안을 보고 적용하거나 취소할 수 있다. 교체 즉시 원래 장소의 날짜·체류·휴식·목적을 되돌릴 수 있으며 이후 수정은 덮지 않는다.

## 역할 구분

- 사람: 모든 기능 후보 구현, 변경 기능 확인, 병합·배포 승인. 전수 조작 검수·회귀 분석/리팩토링·제출 전 점검은 다음 작업으로 유보.
- AI: 기존 데이터 경계 보존, 코드/안내/시험 작성, 공식 관광 집중률 명세 조사, 독립 검수, CI와 배포 확인.

## 구현과 데이터 근거

- 원안과 최대 세 후보를 확인/불일치/미확인 편의, 출처, 거리 기반 이동 추정과 체류 시간으로 비교한다. 기본은 필요한 편의를 모두 확인한 후보다. 실제 운영의 미확인 자료를 처리하도록 명시 opt-in에서만 미확인 후보를 비교하며 해당 항목을 그대로 표시한다. 확인된 후보가 먼저 나오고 negative는 항상 제외한다. 실제 이동 편의 개선이나 한적함을 추정으로 단정하지 않는다.
- 멀어서/방문 경험/짧은 체류/실내/새로운 곳 이유별로 후보를 고른다. 새로운 곳은 살펴본 후보와 보관함에서 방문한 여행의 장소를 제외하며 인기 순위로 위장하지 않는다. 선택한 지역·활동 출처를 표시한다.
- 선택한 경남 지역을 기존 plan 경계로 명시 조회한다. 취소·조건 변경·닫기 시 요청을 중단하며 늦은 결과가 원래 일정과 필터를 바꾸지 않는다. 실내 탐색은 역사·문화 요청임을 표시한다.
- 실내 공간은 공식 overview의 긍정적 명시 문장만 인정한다. 분류/장소 이름으로 추정하지 않으며 부정·휴관·조건부 문장은 제외한다. 이용시간 정보의 기존 요청과 캐시를 재사용한다.
- crowd-calendar는 공개 관광 ID로 공식 장소 이름/경남 법정동을 확인한 뒤 해당 시군·장소에 한정한 예측을 조회한다. 날짜 매개변수를 발명하지 않는다. KST 오늘~30일의 정확한 장소 행만 보존하고 0%는 유효, 누락/중복 충돌은 미확인으로 남긴다.
- 날짜 변경은 다른 장소의 암묵적 첫날을 먼저 명시하여 보호한다. 최대 7일 안에서 기간을 넓히며 새 날짜 끝에 옮긴다. 고정 장소와 뒤에 고정한 순서를 침범하지 않는다.
- 날짜/장소 변경은 기존 보관·계정·공유 경로를 사용한다. 후보 열람 기록은 최대 200개 공개 ID를 브라우저에 보관하며 개인 동행/계정/공개 공유 데이터에 추가하지 않는다.

## 검증

- 변경 기능 E2E 6개: 교체/취소/되돌리기/이후 수정 보호, 공식 실내 확인, 새로운 후보/다른 시군, 실제 예측 날짜/0/미확인/7일 경계, 저장 복원, 1440/960/390/320px. PASS.
- 기존 날씨/혼잡 진입 E2E 16개: 새 명시 비교 단계, 일정 보존·초점·뒤로 가기, 국문/기존 영문. PASS. 기존 검증 의도를 유지하고 사라진 자동 교체/자동 전역 검색 동작을 새 선택 흐름으로 바꾸었다.
- 독립 QA가 320px 마지막 열과 고정 열의 겹침을 재현했다. 기존 편의 비교와 동일한 열 폭 기준으로 수정. 날짜 표 최소 너비도 330px로 보정했다. 독립 320/390px 겹침0·버튼 조작·axe0 재확인 PASS.
- 필수 typecheck/lint/unit844/build 모두 PASS. CSS69.99/70KiB, Planner182.79/270KiB. 두 표 및 비수치 cnctrRate 거부 수정 후 필수 전체 재실행 PASS. 필수 CI와 Production은 별도 증거로 기록한다.

## 결과와 제한

실제 provider 한도나 운영 장애는 UI fixture 성공으로 대신하지 않는다. 공식 개발 트래픽과 계정별 승인 상태는 API 감사 문서에 구분했다. ODsay 보류 #454를 다시 호출하지 않는다. 개인 계정·공유·메시지 쓰기는 시험 데이터로만 확인한다. 이번 변경 외의 대규모 회귀 분석은 유보 범위다.

- 독립 상태 확인: 조건 변경/취소/늦은 응답, 선택 적용·되돌리기, 고정 순서/7일 날짜 경계, 원 검색에 없는 다른 시군 후보의 reload·계정 owner/member·public 표시 PASS. 별도 숫자 guard는 false/true/배열/hex 거부 및 0/문자열0 보존 시험을 추가했다.

- 운영 데이터의 실제 미확인 시설 범위를 확인한 뒤 명시 opt-in을 보완했다. default off·unknown 공개·negative 제외·확인 우선·해제 선택 초기화에 대한 unit/E2E 및 독립 좁은 재검수 수행. 기존 계정/날짜 데이터 경계 변경은 없다.
