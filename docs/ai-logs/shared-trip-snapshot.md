## 수정

- POST 본문의 plan·조건·날짜·순서·출발지 표기를 스냅샷 식별자로 사용한다. 현재 본문과 다른 URL·상태는
  즉시 숨기고 새 요청을 허용한다. 동일 스냅샷의 진행 중 요청만 합치며 이미 발행한 링크는 그대로 둔다.
- 커밋된 스냅샷 세대가 바뀌면 오래된 응답을 거부한다. 링크 표시·복사·달력 생성에 이전 결과를 돌려주지 않고,
  이전 요청의 정리 코드가 새 요청을 지우지 않도록 Promise 동일성도 확인한다.
- 클립보드 미지원/실패는 복사 성공으로 표시하지 않는다. 만든 링크는 보존하고 직접 복사·재시도를 안내한다.
- 저장 중 native disabled가 포커스를 잃게 하는 문제를 재현했다. 기존 버튼을 유지하고 aria-disabled/busy와
  실행 가드로 중복 입력을 차단한다. 계획이 없는 경우의 native disabled는 유지한다.
- 새 오류 상태 검사에서 dark 링크 2.47:1·안내 1.76:1 대비 결함도 발견해 배경/글자색을 수정했다.
