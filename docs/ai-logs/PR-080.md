- AI 도구: Codex

## 목적

관광 API handler가 지역 catalog, 사진 검색, 접근성 모델 변환, 방문·축제·숙박 확장 데이터,
공유 여행 복원과 HTTP routing을 한 파일에서 처리했다. provider 변경 영향 범위를 domain service로 제한한다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 전부 분리하도록 위임
- AI: 관광 domain 경계 설계, 기존 요청·응답 계약 보존, 회귀 검증과 PR 처리

## 구현

- 지역 코드·언어·테마·접근성 field를 `catalog.ts`로 이동했다.
- 관광사진과 장소 사진 조회·정규화를 `photos.ts`로 이동했다.
- 접근성 근거, 장소·코스·오디오 모델 변환을 `models.ts`로 이동했다.
- 방문·수요·캠핑·축제·숙박 등 확장 조회를 `insights.ts`로 이동했다.
- `handler.ts`는 plan·공유 복원·action routing 조율에 집중한다.
- 여행 저장 handler는 catalog를 직접 참조해 HTTP handler와의 결합을 제거했다.
