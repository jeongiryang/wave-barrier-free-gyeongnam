# 팀 제안 통합 C: 현장 의사소통과 방문 지원

원본 PR #533, #534, #538, #540, #596, #600을 통합했다. #538 계열의 주차장 문의 후속(#545)도 포함한다. 본문·후속 요구와 기존 기능을 함께 유지하는 방향으로 충돌을 해결했다.

- 문의 카드 안에서 직원과 양방향 화면 대화, 쉬운 당일 진행, 주차장 문의·문자중계 안내, 공중화장실 후보와 확인 후 일정 추가, 도움 요청, 대여기관 안내 틀.
- 앞선 묶음의 접근로 원문·음식점·숙소·진동 설정을 유지했다. 현장 화면의 직접 진동 호출은 공통 설정을 따르도록 바꿨다.
- 기능 추가로 CSS gzip이 70.77 KiB가 되었다. 현재 TS/TSX/JS 소스에서 사용하지 않는 구형 조건·날짜·장소 카드·일정 편집 클래스에 한정해 landing-explorer.css의 10,579 bytes를 제거했다. 공통 및 현재 사용 중인 travel-profile 스타일은 유지했다. 예산을 올리지 않았으며 수정 후 69.32 KiB다.

- 타입 검사 통과, lint 오류 0 / 기존 경고 14.
- 단위 1,406개 통과. 초기 공통 진동 경계 실패를 구현 수정으로 해결했다.
- 현장·주차장·화장실·GPS 비전송·도움·진동 관련 브라우저 68개 통과.
- CSS 정리 뒤 핵심 여행/동행 조건 22개, 쉬운 당일 보기 포함 당일 도구 10개 통과.
- 빌드·성능 예산 통과. 랜딩 초기 JS gzip 137.82 KiB, 플래너 214.81 KiB.

## 실제 제공 범위

검사는 합성 제공처와 로컬 저장소 실패를 포함한다. 문자중계 실제 통화나 실시간 주차 빈자리를 확인한 결과가 아니다. 공중화장실 원본 및 지오코딩 범위는 동봉 manifest의 30행·5시군으로 제한되며 경남 전체 실시간 시설을 뜻하지 않는다. 대여기관 및 도움 연락처 배열은 확인된 항목이 없어 비어 있다. 확인되지 않은 연락처를 만들지 않았다. 이 상태를 실제 대여기관 검색 완성으로 설명하지 않는다.
