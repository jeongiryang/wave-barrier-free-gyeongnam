## 적용

- 순수 함수 `sceneryCondition`/`sceneryHint`가 비·눈, 맑음, 그 밖을 구분하고 명세의 세 조합만 반환한다. 점수·순위·추천 판단은 없다.
- 일정 날씨 화면과 장소 결과 카드에 같은 한 줄 안내와 `Open-Meteo 예보 · 관광정보 설명 기준` 출처를 표시한다. 예보 실패, 날짜 불일치, 장소 근거 미확인은 빈 자리 없이 숨긴다.
- 장소 응답이 이미 가진 목록 또는 상세 설명에 기존 `indoorEvidence`를 적용한다. 이 판별 규칙은 확장하지 않았고 콘텐츠 유형이나 장소 이름으로 실외를 추측하지 않는다.
- 새 action, 환경 변수, 제공처 호출, 위치 호출, 저장 필드는 없다. 날씨는 기존 일정 지역 이름으로만 조회하고 안내는 일정·순서를 바꾸지 않는다.
- 나루 안전 문장에 날씨와 설명을 근거로 경치가 좋다고 단정하거나 장소 변경을 권하지 않도록 추가했다.

## 실제 표본

- 2026-09-20 공개 서비스의 창원 관광지 10곳을 기존 `plan`과 `visit-info` 계약으로 확인했다. 모든 응답은 HTTP 200 `available`이었다.
- 공식 설명에서 실내 근거가 확인된 곳은 창원의 집, 주남저수지 생태학습관, 경남도립미술관 3곳이며 나머지 7곳은 미확인이다.
- 같은 시각 창원 Open-Meteo 예보는 code 1, 강수확률 0%인 `대체로 맑음`이었다. 기존 판별은 실외 근거를 만들지 않으므로 표시 0/10이다. 이는 데이터 부족을 추측으로 채우지 않은 결과다. 합성 비 예보와 공식 실내 설명 조합은 화면 검사에서 표시됨을 확인했다.

## 제한

- 기존 `indoorEvidence`는 확인된 실내 근거 또는 미확인만 반환한다. 공식 실외 근거 계약이 없으므로 맑음·실외와 비·눈·실외 문구는 순수 함수 계약에는 있지만 현재 제공처 응답에서 임의로 활성화하지 않는다.
