# PR 139 — 플래너 헤더와 신뢰 푸터 분리

## 목적

- 내비게이션·계정 행동과 출처·독립성 고지를 서로 다른 셸 책임으로 분리한다.

## 변경

- `PlannerHeader`는 상단 탐색과 보관함 진입만 담당한다.
- `PlannerFooter`는 브랜드, 독립 서비스 고지, 출처와 저장소 링크를 담당한다.
- 플래너 route가 두 셸을 각각 조합하며 제품 테스트도 양쪽을 포함한다.
