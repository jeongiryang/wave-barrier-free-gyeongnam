# PR-084 — Product CSS feature layer 분리

## 목적

랜딩·플래너·지역 탐색·테마·인트로·반응형 보정이 섞여 있던 대형 CSS 파일을
실제 제품 feature와 cascade 단계에 맞춰 분리한다.

## 변경

- foundation: landing / planner / regional explorer / theme-itinerary
- workspace: planner / landing motion / responsive integration
- refinement: situation-identity / ocean intro / ocean landing / ocean planner / ocean responsive
- `app/layout.tsx`의 import 순서를 명시적인 cascade 계약으로 갱신
- design-system 문서와 style 회귀 테스트 갱신

## 안전성

분리 파일을 기존 import 순서대로 결합한 결과가 세 원본 파일과 byte-for-byte
동일함을 확인했다. 선택자, 선언, media query 순서는 바뀌지 않는다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

API, DB, 환경변수, migration과 사용자-visible 스타일 결과는 바뀌지 않는다.
