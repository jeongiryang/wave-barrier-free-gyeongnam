# PR-110 — 관광사진 수명주기 분리

## 목적

관광사진 component에 URL 보안 정책, API 요청, timeout·retry 상태, view가 함께 있던 구조를
tourism feature의 순수 정책·client·controller·표현 경계로 분리한다.

## 변경

- HTTPS 관광사진 URL 정규화를 순수 `image-url` 모듈로 이동
- 공식 관광사진 조회 계약을 tourism client data layer로 이동
- 초기 사진, slow image fallback, retry·abort 수명주기를 `useOfficialSpotImage`로 이동
- SmartSpotImage를 tourism component로 이동하고 planner import·회귀 테스트 갱신

## 안전성

HTTPS 외 URL 차단, 공식 API만 사용하는 fallback, 8.5초 slow image 전환, 12초 request timeout,
unmount cleanup, accessible loading·fallback 문구를 유지한다.

## 영향

사진 URL 정책, 네트워크 계약, UI 수명주기를 서로 독립적으로 테스트하고 교체할 수 있다.
