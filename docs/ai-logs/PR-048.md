# PR #48 AI 작업 로그

## 발견

- 공개 랜딩과 여행 설계 화면의 푸터에 저장소로 이동하는 링크가 없어 구현 근거와 협업 기록을 찾기 어려웠다.
- 공유 여행 화면에는 공통 푸터 자체가 없었다.

## 변경

- 실제 저장소 주소를 단일 컴포넌트로 관리하는 GitHub 푸터 링크를 추가한다.
- 랜딩·여행 설계·공유 여행 화면의 맨 아래에서 같은 링크를 제공한다.
- 아이콘은 작게 보이되 터치 영역은 44px로 확보하고, 마우스 hover와 키보드 focus 모두에서 `GitHub` 말풍선을 표시한다.
- 스크린 리더에는 링크 목적을 `W.A.V.E GitHub 저장소 열기`로 제공한다.

## 검증

- 세 사용자 화면의 링크 노출, 정확한 저장소 URL, 접근 가능한 이름, 44px 터치 영역 회귀 테스트
- lint, typecheck, test, Vercel production build
