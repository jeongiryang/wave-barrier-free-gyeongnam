## 목적

1440~1920px 이상의 화면에서 콘텐츠가 1240px 안에 고정되어 좌우에 큰 빈 공간이
남는 문제를 줄이고, 랜딩·플래너·지도·데이터 화면이 사용 가능한 폭을 활용하게 한다.

## 설계

- 공통 최대 레이아웃 폭을 1840px로 확장
- 데스크톱 거터를 12~28px 범위의 유동값으로 축소
- 랜딩 헤더와 모든 소개 섹션, 서비스 상단, 공유 화면, 푸터의 정렬선 통일
- 플래너 기능 카드와 지도·교통·데이터 작업영역의 중복 최대폭 제한 해제
- 긴 문단의 기존 읽기 폭은 그대로 두어 과도한 행 길이를 방지
- 1100px 이하 태블릿·모바일 레이아웃과 안전영역 규칙은 유지
