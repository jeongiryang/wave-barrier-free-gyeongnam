# PR #54 · 라우트 수준 복구 상태 추가

## 발견

기능 내부에는 loading·empty·error 상태가 있지만 App Router 자체에서 렌더링
오류가 발생하거나 존재하지 않는 주소로 접근했을 때 사용할 서비스 전용 복구
화면이 없었다. 프레임워크 기본 화면은 사용자에게 다음 행동과 공유 링크 만료
가능성을 설명하지 못한다.

## 구현

- 라우트 전환 중 브랜드 loading 상태와 screen-reader live region을 추가했다.
- 렌더링 오류 시 같은 화면 재시도와 여행 설계 복귀를 제공한다.
- 404에서는 잘못된 주소와 30일이 지난 공유 링크 가능성을 설명한다.
- 안전영역, 48px 조작 영역, 다크 모드와 reduced motion을 지원한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `git diff --check`

환경 변수와 API 동작은 변경하지 않았다.
