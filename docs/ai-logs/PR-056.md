# PR #56 · Vercel 런타임 긴급 복구

## 발견

PR #55의 `vinext 1.0.0-beta.7` 조합은 로컬 Vercel 빌드와 CI를 통과했지만 실제
Vercel 서버리스 함수에서 홈, 플래너, API, 메타데이터 경로가 모두 500으로
응답했다. 빌드 성공만으로 런타임 호환성을 보장할 수 없는 회귀였다.

## 구현

- Vercel에서 실제 운영 이력이 있는 `vinext 0.0.50`, Vite 8.0.16 조합으로
  런타임 도구를 되돌렸다.
- React와 React Server Components 보안 수정 버전 19.2.8은 유지했다.
- Babel, YAML, glob 간접 의존성 보안 업데이트도 유지했다.
- PR #55 로그에 배포 후 회귀와 후속 조치를 기록했다.

## 보안 판단

안정 버전 vinext의 개발 전용 `image-size 2.0.2` 권고는 upstream에 수정된 안정
버전이 없어 일시적으로 남는다. 이 패키지는 프로덕션 의존성에 포함되지 않고,
W.A.V.E 빌드는 사용자가 업로드한 ICNS/JXL/HEIF 파일을 처리하지 않는다.
`npm audit --omit=dev --audit-level=high`는 취약점 0개다.

## 검증

- `npm ci`
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

병합 후 프로덕션의 홈, 플래너, 헬스 API, robots, sitemap, manifest를 다시
직접 확인한다.
