## 목적

축제 카드의 공용 감각지도 대신 축제 전용 편의 지도를 팝업으로 제공한다. 소리·혼잡·휠체어 이동·빛과 현장 제보 하단 영역을 축제 화면에서 제거하고, 실제 OpenStreetMap 위에 쉬는 곳과 화장실 예시 마커를 표시한다. 축제 포스터나 제목을 누르면 포스터와 기본 정보를 나란히 보여 주는 상세 팝업도 제공한다.

## 역할 구분

- 사람: 축제 화면으로 범위 제한, 실제 지도와 예시 마커 사용, 지도 아래 영역 제거 및 안내 문구 확정, 상세 정보와 현장 정보의 팝업 전환 요청
- AI: 기존 구현 조사, 축제 전용 Leaflet 지도와 두 반응형 팝업 작성, 브라우저·접근성·회귀 검사, PR 및 배포 확인
