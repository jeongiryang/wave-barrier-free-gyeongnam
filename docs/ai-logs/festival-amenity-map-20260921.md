## 목적

축제 카드의 공용 감각지도 대신 축제 전용 편의 지도를 제공한다. 소리·혼잡·휠체어 이동·빛과 현장 제보 하단 영역을 축제 화면에서 제거하고, 실제 OpenStreetMap 위에 쉬는 곳과 화장실 예시 마커를 표시한다.

## 역할 구분

- 사람: 축제 화면으로 범위 제한, 실제 지도와 예시 마커 사용, 지도 아래 영역 제거 및 안내 문구 확정
- AI: 기존 구현 조사, 축제 전용 Leaflet 지도와 반응형 스타일 작성, 브라우저·접근성·회귀 검사, PR 및 배포 확인

## 검증

- `npm run typecheck`: 통과
- `npm run test:e2e -- e2e/festival-trip-upgrade.spec.ts`: desktop/mobile 14개 통과
- 축제 카드에서 쉬는 곳·화장실 레이어 전환, 빨간 마커, 안내 문구, 제거 대상 UI 부재를 실제 렌더링으로 확인
- 390px·960px·1440px 가로 넘침과 축제 편의 지도 axe 위반 없음 확인

- 예시 마커는 축제 공개 좌표 주변에 결정적으로 생성되며 서버 전송이나 저장을 하지 않는다.
