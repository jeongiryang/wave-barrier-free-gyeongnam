## 목적

360·390·430px 모바일 화면과 짧은 가로 화면에서 고정 헤더, 도움말 모달,
입력 폼과 지도·캐러셀 조작부가 화면 밖으로 밀리거나 손가락으로 누르기 어려운
문제를 정적 레이아웃 감사로 확인하고 보정한다.

## 조사와 판단

랜딩·플래너·공유 여행의 반응형 CSS와 주요 상호작용 컴포넌트를 최신 `main`
기준으로 대조했다. 모바일 고정 헤더에 환경설정과 도움말 버튼이 함께 놓이면서
좁은 화면에서 브랜드 문구까지 유지하기 어려웠고, 일부 보조 버튼은 44px보다
작았다. 16px 미만 입력 글꼴은 iOS Safari에서 자동 확대를 유발할 수 있었으며,
노치와 홈 표시줄 및 낮은 가로 화면을 고려한 모달 높이 제한도 부족했다.

## 변경

- 모바일 헤더에서 로고 마크는 유지하고 긴 브랜드 문구만 숨겨 폭 확보
- 노치·홈 표시줄 안전 영역과 `viewport-fit=cover` 적용
- 입력 요소 글꼴 16px, 주요 터치 조작 영역 최소 44px 보장
- 도움말·계정·관광지 모달에 동적 뷰포트 높이와 내부 스크롤 적용
- 380px 이하 및 짧은 가로 화면 전용 보정
- 가로형 카드·날씨·지도 조작 레일의 터치 스크롤 보강
- 모바일 회귀 테스트 추가
