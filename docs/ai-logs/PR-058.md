# PR #58 · 첫 진입 접근성과 관광사진 복구 강화

## 발견

첫 진입 인트로가 `aria-modal`을 선언하고 시작 버튼에 초점을 주고 있었지만 Tab 키를
가두지 않아 키보드 사용자가 보이지 않는 배경 인터랙션으로 이동할 수 있었다. 또한
지역 관광사진 요청에는 timeout이 없었고 일시적 실패를 요청 완료로 고정해 같은 세션에서
재시도할 수 없었다. 추천 카드의 외부 관광사진 URL도 페이지 보안 맥락에 맞춘 HTTPS
정규화가 없었다.

## 구현

- 인트로가 열려 있는 동안 Tab 포커스를 시작 버튼에 유지하고 배경 스크롤을 잠근다.
- Escape·자동 종료·직접 시작 뒤 기존 스크롤 상태와 이전 포커스를 복원한다.
- 지역 관광사진 조회에 10초 제한을 두고 네트워크 실패 시 다음 상호작용에서 재시도한다.
- 외부 관광사진 URL은 HTTP를 HTTPS로 올리고 HTTPS 외 스킴은 렌더링하지 않는다.
- 위 동작을 고정하는 별도 production hardening 회귀 테스트를 추가했다.
