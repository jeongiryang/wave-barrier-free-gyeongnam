# PR-101 — 관광 사진 검색 정책 분리

## 목적

서로 다른 정확도·fallback 정책을 쓰는 지역 대표 사진과 개별 장소 사진 검색을
독립 모듈로 분리한다.

## 변경

- 지역별 키워드 fallback과 대표 사진 정규화를 `region-photo.ts`로 이동
- content ID 우선 조회, 장소명 후보 점수화와 순차 검색을 `spot-photo.ts`로 이동
- 기존 `photos.ts`는 안정적인 외부 import를 유지하는 facade로 축소
- 두 검색 정책이 다시 결합되지 않도록 구조 회귀 테스트 갱신

## 안전성

한국관광공사 실시간 조회, HTTPS 이미지 정규화, 공공데이터 호출 제한을 고려한
순차 검색, 빈 결과와 제공기관 장애 구분을 그대로 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

지역 랜딩 사진 정책과 추천 장소 카드 사진 정확도 정책을 서로 독립적으로 변경하고
테스트할 수 있다.
