## 목적

`RouteMap`이 사용자 도구와 패널 UI뿐 아니라 Kakao SDK 수명주기, marker·경로 overlay,
Leaflet fallback과 cleanup까지 직접 소유했다. provider rendering effect를 독립 hook으로
옮겨 지도 제공자 변경과 사용자 조작 UI의 영향 범위를 분리한다.

## 역할 구분

- 사람: 남은 대형 책임 경계를 모두 점진 분리하고 검증·병합·배포까지 완료하도록 위임
- AI: 지도 provider 수명주기 이동, 안정화, 회귀 테스트와 PR 처리

## 구현

- `features/routing/useMapRenderer.ts`가 Kakao 설정 조회·SDK 초기화와 12초 timeout을 소유한다.
- Kakao marker·polyline·접근성/집중도 overlay와 Leaflet fallback을 같은 provider 경계에 모았다.
- provider 전환 시 map·drawing manager·category marker cleanup을 hook이 보장한다.
- `RouteMap`은 로드뷰·검색·측정·공유 같은 사용자 조작과 패널 표현에 집중한다.
