# PR-105 — 관광 확장 데이터 provider 경계 분리

## 목적

확장 관광 데이터 orchestrator에 섞여 있던 수변 여행, 고속도로 휴게소, 지역
축제·숙박·캠핑 provider 정책을 출처별 모듈로 분리한다.

## 변경

- 물과 여행 API의 XML·JSON 응답 정규화를 `water-travel.ts`로 이동
- 고속도로 테마휴게소 조회를 `expressway-rests.ts`로 이동
- GoCamping과 도내→도 전체 fallback 축제·숙박 조회를 `regional-enrichment.ts`로 이동
- `enrichment-sources.ts`는 여러 출처의 병렬 orchestration에 집중
- provider URL과 fallback이 orchestrator로 되돌아오지 않도록 회귀 테스트 보강

## 안전성

실시간 공식 API 조회, 9.5초 timeout, 지역 결과 우선·경남 전체 fallback, XML·JSON
양쪽 정규화, 키 누락과 provider 장애 상태를 그대로 유지한다.

## 영향

한 확장 데이터 제공기관의 schema·인증·fallback을 수정할 때 다른 provider와 전체
tourism handler를 읽거나 변경할 필요가 줄어든다.
