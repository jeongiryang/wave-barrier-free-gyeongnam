# PR 121 — 여행 보관함·일정·방문 순서 책임 분리

## 목적

- `useTripSelection`에 섞인 기기 저장, 날짜 배정, 방문 순서 계산을 독립적으로 변경·검증할 수 있게 한다.

## 변경

- `useSavedPlaceIds`: 브라우저 보관함 복원·저장과 장소 ID 토글을 담당한다.
- `useTripSchedule`: 여행 기간, 날짜 목록, 장소별 날짜 배정을 담당한다.
- `useOptimizedTripOrder`: 선택된 장소의 방문 순서와 설명을 계산한다.
- 기존 `useTripSelection`은 세 기능을 조정하는 얇은 파사드로 유지했다.
- 저장소 구조 테스트가 각 책임과 개인정보 저장 경계를 직접 확인한다.
