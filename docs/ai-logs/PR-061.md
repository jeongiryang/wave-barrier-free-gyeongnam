# PR #61 · 계정 화면 W.A.V.E 모션 카피

## 발견

정식 로그인·회원가입 화면은 서비스의 브랜드와 핵심 가치를 설명하고 있었지만,
왼쪽 제목이 정적인 문장에 머물러 장소 선택에서 맞춤 여행, 이동, 여행자 경험으로
이어지는 W.A.V.E의 제품 흐름을 짧은 시간 안에 체감하기 어려웠다.

## 구현

- 고정된 시작 문장과 결론 사이에서 맞춤 하루, 편한 이동, 여행자 이야기가 순서대로 전환되는 전용 헤드라인을 추가했다.
- 전환은 두 번 뒤 마지막 문장에 정착하게 해 로그인 폼과 시선 경쟁을 줄였다.
- 파동형 밑줄과 짧은 수평 흐름을 기존 W.A.V.E 색상으로 표현하고 새 애니메이션 의존성은 추가하지 않았다.
- 가장 긴 문구를 기준으로 높이를 예약하고 모바일 글자 크기를 별도로 제한해 레이아웃 이동과 잘림을 방지했다.
- 시각 모션은 스크린리더에서 숨기고 완성된 제목 하나만 제공했으며 `aria-live`를 사용하지 않았다.
- 사이트 모션 설정과 `prefers-reduced-motion`에서는 완성된 정적 카피로 표시한다.

## 역할 구분

- 사람: 읽기 쉬운 W.A.V.E 브랜드 모션, 접근성·모바일·성능 기준과 배포 권한 위임
- 도구: 구현, 회귀 테스트, 로컬 화면 경로 확인, CI·병합·배포 및 Production 재검증
