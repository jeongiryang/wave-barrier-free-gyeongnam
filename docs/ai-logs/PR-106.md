# PR-106 — 플래너 장소 adapter 분리

## 목적

사용자 action hook에 섞여 있던 지도 장소·확장 관광지의 플래너 domain 변환을 순수
adapter로 분리한다.

## 변경

- `RichSpot → Place` 변환을 `place-adapters.ts`로 이동
- `MapPlace → Place` 변환을 같은 순수 domain adapter에 집중
- `usePlannerActions`는 장소 선택·경로 이동·상황 대응·예약 경로 복사 action에 집중
- 변환 로직이 action hook에 다시 섞이지 않도록 구조 회귀 테스트 갱신

## 안전성

공식·지도 직접 선택 출처 표기, 좌표·이미지·접근성 점수 보존, 사용자용 fallback
주소·요약과 경로 조회 동작을 그대로 유지한다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

장소 schema 변환을 UI action이나 route side effect 없이 독립적으로 변경·테스트할 수 있다.
