# 2026-09-27 운영 검증 후속 수정

도구: Codex. 사용자 요청은 9월 30일을 기준으로 남은 기능·사용성·연동 검증을 마무리하는 것이다. 현재 실제 휴대전화는 사용할 수 없다고 확인했다. 기존 제출용 테스트 계정의 한정된 검증 및 테스트 글 게시 후 삭제 권한을 적용했다.

## 발견과 변경

- 운영 주차 대안 조회가 502를 반환했다. 공식 요청 명세의 최대 1,000건과 실제 코드의 30,000건 요청이 어긋났고, 불완전한 목록이 정상 목록으로 인정되거나 안전한 제공처 실패 원인이 소실되는 문제도 확인했다. 공식 장애인전용구역 필터와 페이지 완전성·전체 기한·동시 요청 상한을 적용하고, 완료된 목록만 공유 캐시로 사용한다. 키·요금제 변경은 하지 않는다.
- 나루 저장 도구에 인증 확인 중 진입하면 저장 버튼 활성화 후 키보드 초점을 받지 못했다. 변경 전 회귀에서 실패를 재현하고 비활성 요소의 초점 시도를 생략하며 `disabled` 변경을 관찰하도록 수정했다. 기존 관찰 종료 기한은 유지한다.
- 반려동물·웰니스 후보의 주소가 원문 설명을 가리던 표시를 개선하고, 같은 공식 장소 ID로 이용시간·연락처를 펼쳐 확인하도록 연결한다. 자료에 없는 동반조건·치료효과·접근성은 추정하지 않는다.

## 검토 범위

API 담당, 상태·비동기 회귀 담당, 심사·시각 담당에게 겹치지 않는 bounded 작업을 맡겼다. 각 구현자의 자기 검증과 루트의 코드 검토를 구분한다. 화면 변경에는 React 품질 스킬의 지연 조회·독립 상태·기존 컴포넌트 재사용 기준을 적용했다.

이전 배포 b493e1b의 단위 1,707개 및 브라우저 2,302개 통과를 후속 변경의 검증으로 재사용하지 않는다. 이 커밋의 관련 회귀와 필수 CI, 최종 main의 Release Audit·CD·운영 결과는 PR에 기록한다. 실제 나루 성공 응답, 합성 오류 복구, 실제 계정 저장/삭제, 외부 제공처의 빈 결과는 서로 다른 근거로 남긴다.

## 배포와 롤백

DB 마이그레이션·환경 변수·권한·유료 서비스 변경은 없다. GitHub Actions CD로 배포하며 문제가 있으면 이 후속 커밋을 revert하고 필수 CI/CD를 통과시킨다. 최초 CI/하네스 재구축 전 백업은 그대로 유지한다. 실제 제공처 권한이나 데이터 부재가 남으면 코드 통과와 구분해 기록한다.
