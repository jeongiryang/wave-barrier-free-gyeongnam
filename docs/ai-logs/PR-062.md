# PR #62 · 첫 방문 인트로와 환경설정 구조 개선

## 발견

랜딩 인트로가 `true`로 먼저 렌더링된 뒤 `sessionStorage`와 모션 설정을 확인해
사라지는 구조여서, 이미 본 사용자에게도 한 프레임 이상 노출될 수 있었다.
또한 언어·테마·모션 저장과 번역 사전, 헤더 UI가 한 컴포넌트에 모여 있었고
모션 버튼이 주요 내비게이션에 직접 노출돼 제품보다 데모 제어판처럼 보였다.

## 구현

- 인트로를 `checking`·`show`·`hidden` 상태로 나누고 저장소와 모션 판정이 끝난 뒤에만 마운트한다.
- 같은 세션에서 이미 본 사용자와 `prefers-reduced-motion`, W.A.V.E `calm` 사용자는 인트로를 처음부터 건너뛴다.
- 첫 방문 인트로의 자동 종료, 건너뛰기, 포커스 트랩과 스크롤 복원은 유지한다.
- 환경설정을 번역, 타입, 저장소, 컨텍스트, UI 모듈로 분리하고 hydration 완료 상태를 명시적으로 제공한다.
- 헤더의 개별 모션 버튼을 제거하고 언어·화면 색상·동작 효과를 하나의 환경설정 패널 안에 배치한다.
- 환경설정 전용 스타일을 `app/styles/preferences.css`로 옮겨 전역 스타일의 기능 책임을 줄였다.
- 작은 화면에서는 설정 패널을 안전 영역 안의 전체 폭 패널로 전환하고 모든 조작 대상을 44px 이상 유지한다.

## 역할 구분

- 사람: 인트로 깜빡임의 재현 조건, 헤더 단순화와 모듈화·접근성 기준 및 배포 권한 위임
- 도구: 원인 추적, 구현, 회귀 테스트, CI·병합·Production 재검증
