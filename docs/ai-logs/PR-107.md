# PR-107 — 커뮤니티 client API 경계 분리

## 목적

커뮤니티 controller hooks에 남아 있던 endpoint, HTTP method, JSON parsing 계약을
전용 client data layer로 분리한다.

## 변경

- 목록·상세 조회를 `features/community/client/api.ts`로 이동
- 좋아요, 글 삭제, 댓글 작성·수정·삭제 요청을 같은 client API 경계에 집중
- hooks는 loading·error·인증 복귀·편집 상태 등 사용자 수명주기에 집중
- view/controller에 raw `fetch`가 다시 들어오지 않도록 회귀 테스트 보강

## 안전성

same-origin 상대 경로, JSON content type, 401 로그인 복귀, 사용자용 오류 문구,
목록 request abort와 12초 timeout을 유지한다. 서버 session·소유권 검증은 변경하지 않는다.

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

Community API contract와 사용자 상태 관리를 독립적으로 변경·테스트할 수 있다.
