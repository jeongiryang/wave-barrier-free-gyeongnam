# 제출 전 여행 완성 흐름과 모바일 정리

- PR: https://github.com/jeongiryang/wave-barrier-free-gyeongnam/pull/668
- 작성자: jeongiryang / Codex
- 상태: 최종 검증 및 배포 준비

## 목적과 역할

사용자가 승인한 PR #667 인트로를 실제 서비스에 통합하고, #654 및 #656–662의 사용자 흐름 결함을 보완한다. 자동 Actions 실패 이슈는 제품 요구에 포함하지 않는다. 사람은 시안·인트로 선택과 출시를 승인했으며, Codex는 구현·독립 QA·제출 자료 준비를 수행했다. 인증정보 입력·최종 공모전 제출은 수행하지 않았다.

## 변경

- PR #667의 입자·셰이더·장면 시간표를 복구했다. 기존 세션 노출과 Esc, 초점 복원, 동작 감소를 유지하고 일시정지·이전·다음 및 로딩 실패 복구를 제공한다. 원본 경계 자료의 MIT 출처를 보존했다.
- 나루의 부담 완화 요청은 담은 장소를 유지하여 날짜를 나누고 순서·휴식을 제안한다. 고정 방문·체류 시간·축제 기간을 보존하고 적용·되돌리기를 같은 여행 상태에 연결한다. 28개 도구를 생활어로 검색하며 최신 답변 및 대기 중인 일정안으로 이동한다.
- 자정 초과·고정 방문 지각·빈 날짜·기간 밖 배정을 시간표 상단에 안내한다. 기기/계정 저장 및 공개 공유 전에 검토하도록 하고 새 경고가 생긴 자동 저장은 사용자의 확인을 기다린다. 기존 저장 소유권과 늦은 응답 보호를 유지한다.
- 직접 장소 검색은 이름·주소·좌표로 공식 관광지를 식별하여 같은 ID의 편의정보를 연결한다. 불확실한 대조와 제공처 실패를 구분하며 임의 시설 좌표를 제거했다.
- 실제 커뮤니티 저장 자료만 표시하고 샘플 계정·반응·지역 숫자와 기능 없는 상세를 제거했다. 공개 링크는 사용자가 생성 버튼을 선택할 때만 발급하고 실제 저장 지역을 사용한다.
- 인증 확인 중 중립 상태, 계정 로그아웃, 960px 상세·축제 날짜, 축제 중복 담기 설명과 날짜 변경 확인, 현재 시간표·나루와 일치하는 도움말을 반영했다.
- 모바일 Design B 화면을 구성하고 기존 기능·출처·접근성을 유지했다. 사용하지 않는 CSS와 이전 인트로 모듈을 정리하여 기존 성능 예산을 유지했다.

## 검증 근거

- 독립 회귀: 모바일/960px 및 데스크톱·QHD·UHD 36개, 저장·계정 복구 38개, 새 시간 경고 및 공유 40개, 카카오 공유 4개 통과.
- 나루 도구 검색·장소 보존·적용·되돌리기 16개, 공식 장소 동일성 및 커뮤니티의 개별 회귀 통과.
- 최신 원본 입자 인트로의 키보드·정지/이동·세션·실패 복구를 desktop/mobile에서 검증했다. 운영 빌드와 최종 CI 결과는 연결 PR에 기록한다.
- 최종 후보 단위 1,614/1,614, 타입, 린트(오류 0, 기존 경고 25), 의존성 감사(취약점 0), 배포 빌드와 성능 검사를 통과했다. CSS 84.94/85KiB, 최초 랜딩 JS 145.75/155KiB, Planner JS 264.19/270KiB, 개별 청크 gzip 67.33/110KiB이다. 제한은 늘리지 않았다.
- 실제 배포 빌드에서 Three 분할 청크의 Vector3/Quaternion 초기화 순서 오류를 재현하고 Rolldown strictExecutionOrder로 수정했다. 같은 배포 빌드의 재생·일시정지·7단계 이동·건너뛰기·동작 감소 및 모듈 실패 복구 10/10을 통과했다.
- 이용 안내·환경설정·축제 필터의 native details 내부에서 실제 브라우저 접근성 이름 소실을 재현하고 controlled button/panel로 복구했다. 새 키보드 4개 및 기존 도움말·환경설정 22개를 통과했고 Codex 브라우저 AX에서도 링크/버튼/라디오의 실제 이름과 상태가 전달됨을 확인했다. OS NVDA 검증과는 구분한다.
- 실측 운영 나루의 공개 질문: GET available:true, POST source:local-llm, HTTP200. 특정 모델 버전·모든 사진 입력의 정상 동작을 이 한 번의 측정으로 주장하지 않는다.

## 자료와 제한

- 추가 CI 회귀에서 조건부 환경설정 메뉴가 일회성 설치 이벤트를 놓치는 결함을 수정했다. 설치 상태와 이벤트를 공통 루트에서 유지하고 메뉴를 닫았다 다시 열어도 설치 버튼이 작동하는 실제 이벤트 순서 4개 검사를 통과했다.
- 모바일 320px 활동 버튼 줄바꿈, 커뮤니티 카드/목록 선택, 태그 대비, 검색 결과를 가리던 나루 힌트, 가로 탭의 키보드 접근, 직접 검색창의 접근 가능한 이름을 복구했다. 해당 27개 브라우저 회귀가 통과했다.
- 이전 화면 계약에 묶여 있던 27개 E2E 파일과 공통 helper를 현재 승인된 인트로, 명시적 저장·공유 확인, 모바일 홈/저장 메뉴 구조에 맞췄다. 일시정지 시계와 중첩 메뉴의 Esc 순서를 바로잡았으며 기존 검사를 건너뛰거나 성공 기대를 완화하지 않았다. 독립 QA 담당 182개 검사 및 남은 모바일·음성 9개 suite의 실패 재검 16개가 통과했다.
- 승인된 인트로 의존성 잠금 파일을 검토한 뒤 immutable bootstrap 배포본과 workflow SHA를 함께 교체했다. 후보 코드가 bootstrap에서 실행되지 않는 경계 및 나머지 고정 파일의 검증은 그대로이며 공격/계약 검사 5개가 통과했다. 세부 근거는 `docs/ci-validation.md`에 기록했다.

- 공식 Notion 및 36개 첨부 원본을 다시 확인했다. 모두 SHA-256 동일. 새 기능설명서는 공식 양식의 필수 항목과 핵심 기능 5개 묶음을 유지하여 별도 작성한다.
- 공사 API 16종의 실제 호출 경로·운영 응답을 확인했다. 의료관광은 해당 조건에서 정상 빈 결과이고, 오디는 선택 장소와 일치하는 음원이 없는 경우를 구분한다. 방문자·수요·집중률 자료는 집계 기간과 예측 기준을 유지한다.
- Windows UIA/NVDA 실제 환경 검증은 아직 별도 확인이 필요하다. DOM/Chromium Axe 결과를 플랫폼 화면낭독기 실측으로 대체하지 않는다. #654는 이 범위를 구분하여 추적한다.
- 심사용 계정의 최종 가입·로그인 및 최초 신청 계정으로 제출하는 단계는 실제 계정에서 확인해야 한다. 인증키나 비밀번호를 이 기록·기능설명서에 싣지 않는다.

## 최종 감사 후 보완

- 커뮤니티의 빠진 저장 동작을 복구했다. 공개 글 ID만 이 기기에 최대 50개 보관하고 목록·상세 상태를 동기화한다. 저장 목록은 최신 공개 내용을 10개씩 다시 조회하며, 삭제·비공개와 조회 오류를 구분한다. 계정 동기화로 표현하지 않는다. 단위 3개, 신규/기존 브라우저 16개 통과.
- 기존에 조회한 유효 운영정보를 시간표와 저장·공유 확인에 연결했다. 명확한 개장 전·폐장 후·입장 마감·휴무 등의 충돌만 기존 파서로 판단하고 미조회·만료·모호한 시간은 추론하지 않는다. 확인 중 근거가 바뀌면 재확인을 요구한다. 새 제공처 호출 없이 단위 13개와 브라우저 20개를 통과했다.
- 출발 지도 핀과 사진 없는 장소 핀의 실제 테마 대비를 교정했다. 기존 전체 동선·지도 접근성 검사 6개가 통과했다. 도움말의 데스크톱 나란히/좁은 화면 전환 설명과 미확인 시설의 문구를 현재 UI에 맞췄다.
- CI의 느린 소프트웨어 WebGL에서 매 프레임을 합성하던 긴 가상 시간 이동을 경계 이동으로 바꾸고, 장면 제어 검사는 실제 이전 버튼으로 1/7을 확인한 뒤 시작한다. 승인된 연출·종료 시각·검사 기대·제한은 유지한다. 42개 중 41개 통과 후 링크 이동 비재현 1개를 두 프로젝트에서 재검 통과했고 장면 제어도 2개 통과했다.
- 나루 장문 스트리밍의 자동 따라가기, 실제 휠로 이전 내용 읽기, 새 청크 동안 위치 유지, 최신 답변 복귀를 합성 NDJSON 응답으로 검증했다. 해당 전체 suite 10개 통과이며 운영 LLM 실측과 구분한다.
- native 인증 경로에 누락된 username 로그인만 복구했다. 실제 route exports를 실행하여 동일 출처·크기 제한·미지원 경로·private no-store 경계를 포함한 인증 13개가 통과했다. 운영 가입 오류의 직접 원인으로 단정하지 않는다.
- 이 보완까지 포함한 후보는 단위 1,625/1,625, 타입, 린트(오류 0/기존 경고 25), 배포 빌드·성능을 통과했다. CSS 84.94/85KiB, 랜딩 JS 145.77/155KiB, Planner JS 264.20/270KiB. 최종 CI와 Actions CD는 연결 PR의 최신 SHA 결과를 따른다.
