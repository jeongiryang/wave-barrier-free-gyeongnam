## 목적과 구현

전체보기에서 여행비 도구를 펼쳐 인원, 목표 예산, 입장·이용요금과 식사·숙박 등 추가 비용을 입력한다. 인당/전체 기준과 날짜별 합계, 알려진 금액 대비 잔액·초과액, 미확인 항목 수를 구분한다. 0원은 명시적 입력 또는 확인된 경로 요금일 때만 알려진 금액으로 취급한다.

현재 일정의 두 끝점·교통수단이 일치하는 기존 조회 경로를 재사용한다. 대중교통 요금은 인원수를 곱하고 자동차 통행료는 차량1대 기준으로 표시한다. 연료·주차·나이/할인 등 미포함 조건을 안내하며 미확인을 무료로 만들지 않는다. 장소별 공식 요금 안내는 명시적인 버튼에서 기존 visit-info 서비스를 사용하고 조건별 요금 문장을 자동으로 단일 금액으로 바꾸지 않는다.

최대20개 여행의 예산을 날짜와 공개 장소 ID 집합으로 구분해 저장한다. 동일 여행 복원/재접속 시 불러오고 원래 일정·체류·휴식·계정·공유 데이터는 수정하지 않는다. 도구를 접어도 입력은 유지한다. 동시 변경을 감지하면 저장을 막고 최신 값을 명시적으로 불러온다. 읽기 실패로 기존 기록을 덮지 않으며 저장 실패 시 입력과 현재 요약 파일 기능을 유지한다.

현재 입력은 TXT로 내보내고, 저장된 예산은 선택적으로 기존 오프라인 HTML/TXT 여행 요약에 포함한다. 없는 예산이나 읽기 실패를 성공으로 표시하지 않는다. 도움말에 진입 위치와 사용 순서를 추가했다. 신규 유료 서비스, 의존성, 외부 계정 설정 변경 없음.

## 검증

- 단위: 미확인/0원/잘못된 금액, 인원/전체/요금 종류 계산, 기간·장소 범위와 저장 개수, 저장 읽기 오류 보호.
- 대상 브라우저: 금액·잔액·초과액, 접기/저장/취소/재접속, 공식요금 오류, 금액 검증, 저장 실패 후 TXT, 동시 변경 보존, 저장예산 실제HTML 포함. 초기 harness의 중첩 label 조회는 native combobox 역할로 바로잡았고 검증 조건은 유지했다.
- 직접 렌더1440/960/390/320 확인 후 새 패널 여백과 제목 계층을 기존 테마에 맞췄다. 최종 local gates와 독립 QA/CI/Production 결과는 PR 코멘트 및 상태 파일에 연결한다.
- 최종 로컬 typecheck PASS, lint0오류/기존12경고, unit851/851 PASS, build:vercel 및 성능 예산 PASS(CSS69.99/70KiB, Planner182.85/270KiB). 대상 budget와 변경된 day-tools 브라우저12검사 PASS. 기간 밖 장소는 제외 안내 및 저장/내보내기 차단으로 부분 합계를 완전한 여행비처럼 저장하지 않는다.

## 제한

확인한 비용의 합계이며 가격 보장이나 결제 기능이 아니다. 저장 당시 요약과 조회 시점의 경로 요금은 실제 방문일 요금과 다를 수 있다. 현재 사진·여행 경험 또는 개인 계정의 쓰기 검증은 수행하지 않는다. ODsay hold #454 및 제출 GO는 별도다.
