## 목적

여행의 예약·숙소·꼭 갈 곳을 남기면서 나머지 일정을 편집한다. 고정 장소는 같은 날의 위치, 방문 날짜, ID를 재추천·자동 정렬·교체·제거 동작에서 보존하며 고정을 해제하면 다시 변경할 수 있다. 별도로 시각을 지정하면 대기 시간을 반영하고 늦은 도착을 표시한다. 실제 예약을 생성하지 않는다.

날짜별 귀가·약속 마감과 마지막 장소부터의 이동분·추가 여유를 입력해 계획상 남는 시간 또는 초과분을 계산한다. 모르는 귀가 이동은 빈칸/미확인으로 유지한다. 실제 구간 조회와 직선거리 기반 추정을 구분하며 교통편 변동을 보장하지 않는다.

## 구현

`trip-time-constraints`의 bounded allowlist, 기존 일정 시간 모델, 방문 순서 pin과 편집 guard에 연결한다. Horizon 공통 disclosure/form 스타일을 재사용해 화면 길이와 CSS 증가를 줄인다. 기본 일정·전체 일정·계정 여행 및 공유 화면에 함께 표시하며, 명시적 저장/공유에 사용자 설정만 포함한다. API 원문·주소·GPS·예약번호 추가 저장이나 제공처 호출은 없다.

장소의 날짜가 여행 기간 밖으로 나가더라도 임의 이동하지 않는다. 상세 일정에서 고정을 해제하거나 여행 기간을 되돌릴 수 있다. 명시적으로 '새 여행'을 시작할 때는 다른 일정 상태와 함께 초기화한다.
