# 나루 게이트웨이 메시지 제한 준수와 연결 실패 시 검색 조건 보존

## 문제와 변경

#607 운영 배포 후 실제 브라우저에서 `통영 여행지를 3곳만 추천해줘. 창원이나 거제는 제외해줘.`를 입력했다. 모델 요청이 실패해 간편 명령으로 전환되자 기존 창원 후보 12곳이 표시됐다. 연결된 모델 경로만 검증했던 #532 B1의 누락이다.

간편 명령도 기존 `groundAssistantProposal`과 허용 목록 검증을 거쳐 현재 발화의 목적지·제외 지역·개수를 적용한다. 지역 목록에서 먼저 발견되는 창원을 선택하지 않는다. 목적지 없이 제외 지역만 말한 경우에는 그 지역으로 검색하거나 범위를 몰래 넓히지 않는다. 기존 필요한 편의는 검색 적용 단계에서 유지한다.

## 검증

- 단위 1,501개 통과, 타입·변경 파일 lint 통과.
- HTTP 503 / 네트워크 중단을 강제한 PC·모바일 검사에서 창원 대화 다음 통영 3곳만 표시, API 요청 지역과 승강기 조건 보존을 확인했다. 관련 브라우저 24개 통과.
- Vercel 빌드·성능 예산 통과, CSS gzip 69.21 KiB. 예산·재시도·timeout을 늘리지 않았다.
- 최종 CI/main/CD 및 배포 후 실제 조회 결과는 PR 댓글에 추가한다.

## 게이트웨이 제한과 실제 모델 확인

운영 POST가 503인데 준비 상태는 true인 현상을 재현했다. 통합된 기본 시스템 지시문은 실제 확장 시 표준말 6,223자·경남 말투 6,288자이며 게이트웨이의 메시지당 6,000자 제한을 넘는다. 신뢰된 시스템 지시문을 문단 경계에서 나누어 순서·안전 규칙·말투를 모두 보존한다. 사용자 대화의 역할과 길이, 게이트웨이 제한, 모델 제공처는 바꾸지 않는다.

실제 핸들러가 보내는 요청을 검사해 두 말투와 최대 6개 대화 이력에서 메시지당 6,000자 이하, 전체 10개 이하, 요청 36,000바이트 이하를 확인했다. 스트리밍에서도 모든 안전 문장과 추가 형식 지시가 보존되고 같은 제한을 지킨다. 관련 37개 검사와 전체 1,501개 단위 검사, 타입·lint·빌드·성능 예산이 통과했다. 이전 fallback 코드의 전체 CI 35454851020도 성공했지만, 이 서버 수정이 포함된 새 HEAD의 전체 CI를 다시 통과한 뒤 병합한다.

이 원인이 운영 장애를 해결했는지는 새 배포 후 실제 대화로 확인한다. 준비 상태만으로 해결 판정하지 않으며 #610에 결과를 남긴다. 유료 모델로 전환하지 않았다.
