# 나루 연결 실패 시 검색 조건 보존

## 문제와 변경

#607 운영 배포 후 실제 브라우저에서 `통영 여행지를 3곳만 추천해줘. 창원이나 거제는 제외해줘.`를 입력했다. 모델 요청이 실패해 간편 명령으로 전환되자 기존 창원 후보 12곳이 표시됐다. 연결된 모델 경로만 검증했던 #532 B1의 누락이다.

간편 명령도 기존 `groundAssistantProposal`과 허용 목록 검증을 거쳐 현재 발화의 목적지·제외 지역·개수를 적용한다. 지역 목록에서 먼저 발견되는 창원을 선택하지 않는다. 목적지 없이 제외 지역만 말한 경우에는 그 지역으로 검색하거나 범위를 몰래 넓히지 않는다. 기존 필요한 편의는 검색 적용 단계에서 유지한다.

## 검증

- 단위 1,500개 통과, 타입·변경 파일 lint 통과.
- HTTP 503 / 네트워크 중단을 강제한 PC·모바일 검사에서 창원 대화 다음 통영 3곳만 표시, API 요청 지역과 승강기 조건 보존을 확인했다. 관련 브라우저 24개 통과.
- Vercel 빌드·성능 예산 통과, CSS gzip 69.21 KiB. 예산·재시도·timeout을 늘리지 않았다.
- 최종 CI/main/CD 및 배포 후 실제 조회 결과는 PR 댓글에 추가한다.

## 실제 모델 제약

2026-09-20 01:18 KST 이후 운영 브라우저와 별도 공개 API 호출에서 `AI_UNAVAILABLE` 503이 관찰됐다(단일 API 호출 약 3.8초). GET 준비 상태 true는 실제 대화 성공을 보장하지 않는다. 이 변경은 간편 명령의 잘못된 추천을 고치는 것이며 실제 LLM 연결 장애를 해결했다고 주장하지 않는다. 이 세션의 Vercel 연결은 접근 가능한 팀을 반환하지 않았고, 현재 작업 환경에 WAVE 모델 접속 환경이나 SSH 설정이 없어 게이트웨이 내부 원인은 확인하지 못했다. 유료 모델로 전환하지 않았다.
