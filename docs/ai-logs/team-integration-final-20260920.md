# 팀 제안 최종 통합: 현장 지원·나루·여행 근거·화면 개선

## 반영 범위

시설 통합 #605 이후, 원본 PR #533 #534 #538 #540 #596 #600 (현장 지원), #561 #563 #588 #589 #592 #594 #598 (나루), #525 #526 #536 #542 (여행 근거·동행), #523 #548 (발견·화면)를 함께 검증한다. #538 계열의 #545 주차장 문의 후속도 포함한다. 동일 기능을 원본 PR마다 재검사·재배포하지 않고 최종 합쳐진 상태에 전체 CI를 실행한다.

- 사진의 장소·날짜를 공공데이터와 대조하고 확인된 항목으로 일정안을 만드는 기능, 선정 근거, 동행자 공통 조건, 휴무·피로·비 가정 점검, 현장 관찰 재확인, 감각지도·공간음향·여행 여권을 통합했다.
- 스트림 답변과 확정 제안을 분리하고, 과도하거나 잘린 응답에서는 완료 동작을 내보내지 않는다. 서로 다른 POST 요청 및 단일 소비자 스트림의 응답을 공유하지 않는다.
- #532의 통영 3곳/창원·거제 제외는 모델 지역 보정 단위 검사와 혼합 지역 검색 결과를 넣은 실제 UI 검사로 고정했다. 필요한 편의는 유지한다.
- #523의 레저스포츠 명칭, 편의 더보기, 명시적 검색 범위 확대, 일정의 미확인 편의 표시와 바로 교체를 반영했다. 걷기·휴식·동행 입력 및 아이 동반 축제 필터 삭제는 채택하지 않고 유지했다. 바로 교체 후 되돌리기는 접힌 여행 도구 밖에서 보인다.
- #548의 색상·사진·캐릭터·문구 개선을 반영했다. 기존 상태 도형, 날짜 키보드 조작, 글자 확대, 한 손 닫기, 진동 설정을 유지했다.
- CSS 예산 70 KiB를 올리지 않았다. TS/TSX/JS에서 사용하지 않는 구형 navigation/carousel/condition/itinerary 클래스의 양의 선택자만 제거했다. 부정 선택자는 보수적으로 유지했다.

- 타입 검사 통과, lint 오류 0 / 기존 경고 13, 단위 1,497개 통과.

- 결합 후 여행·축제·조건·화면 브라우저 82개 중 75개 통과, 실패 원인 수정 후 영향 20개 전부 통과. 문구 기대값을 현재 카피에 맞추고 숨겨진 되돌리기를 실제 UI에서 복구했다. 랜딩 전체 캡처 1건의 로컬 Chromium 종료는 단일 worker 재검증에서 통과했다.

- 빌드 및 성능 예산 통과. CSS gzip 69.21 KiB (최종 Actions 수치는 해당 실행 참조).
- 최종 GitHub 전체 CI와 운영 배포/실제 서비스 검증 결과는 PR/Actions 기록으로 추가한다. 로컬 합성 제공처 검사를 실제 모델·실제 관광시설 검증으로 주장하지 않는다.

## 실제 제공 제약

- 경남 말투 UI는 기존 개발용 공개 조건을 유지한다. 실제 모델 20사례 품질 비교 없이 운영 기본으로 활성화하지 않는다.
- 스트리밍은 WAVE_AI_STREAM 설정이 켜진 제공 환경에서만 동작한다. 이 코드 통합만으로 운영 모델이 스트리밍 중이라고 주장하지 않는다.
- 공중화장실은 검증한 30행·5시군 범위다. 보조기기 대여 및 도움 연락처에는 확인되지 않은 기관을 채워 넣지 않았다. 현장 관찰은 여행자 제보이며 공식 확인과 구별한다.
- 동행 일정 API는 작성자 인증, 초대 토큰 해시, 역할별 허용 동작, revision 충돌, 만료·취소를 검사하며 기록 보관/탈퇴 삭제에 연결한다. 실제 참가자 계정의 작성·공유 완료를 대신 주장하지 않는다.
- 상위 이슈는 남은 본문 요구까지 일괄 완료 처리하지 않는다. 운영 한도, 실제 계정·기기·모델 검증은 별도 추적한다.
