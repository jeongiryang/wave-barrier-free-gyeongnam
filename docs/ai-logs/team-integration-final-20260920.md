## 실제 제공 제약

- 경남 말투 UI는 기존 개발용 공개 조건을 유지한다. 실제 모델 20사례 품질 비교 없이 운영 기본으로 활성화하지 않는다.
- 스트리밍은 WAVE_AI_STREAM 설정이 켜진 제공 환경에서만 동작한다. 이 코드 통합만으로 운영 모델이 스트리밍 중이라고 주장하지 않는다.
- 공중화장실은 검증한 30행·5시군 범위다. 보조기기 대여 및 도움 연락처에는 확인되지 않은 기관을 채워 넣지 않았다. 현장 관찰은 여행자 제보이며 공식 확인과 구별한다.
- 동행 일정 API는 작성자 인증, 초대 토큰 해시, 역할별 허용 동작, revision 충돌, 만료·취소를 검사하며 기록 보관/탈퇴 삭제에 연결한다. 실제 참가자 계정의 작성·공유 완료를 대신 주장하지 않는다.
- 상위 이슈는 남은 본문 요구까지 일괄 완료 처리하지 않는다. 운영 한도, 실제 계정·기기·모델 검증은 별도 추적한다.

- 첫 전체 CI 35451774158의 quality와 sandbox-boundary는 통과했지만 브라우저 검사가 실패했다. 실패를 우회하지 않고 원인별 수정했다.
- 밝은 표면을 고정한 랜딩 새 CSS가 어두운 테마 글자를 읽기 어렵게 만들었다. 어두운 테마에서는 기존 paper/surface 토큰을 사용한다. 대비·axe 기준은 유지했다.
