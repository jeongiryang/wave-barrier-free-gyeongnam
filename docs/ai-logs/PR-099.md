# PR-099 — 지도 도구 controller 경계 분리

## 목적

지도 controller가 주변 장소, 지도 종류·레이어, 측정 도형과 로드뷰 상태·SDK
호출까지 직접 소유하던 구조를 도구별 controller hook으로 분리한다.

## 변경

- 기본지도·교통/지형 레이어를 `useMapLayers`로 이동
- 거리·반경·면적 측정 상태와 Kakao drawing 동작을 `useMapDrawingTools`로 이동
- 주변 장소 검색·marker cleanup·Kakao 장소 정규화를 `useNearbyPlaces`로 이동
- 로드뷰 선택·조회·preview 상태를 `useRoadviewController`로 이동
- 상위 `useRouteMapController`는 지도 핵심 선택, 현재 위치, 저장·공유·fullscreen과 renderer 조립에 집중
- 도구 SDK 구현이 상위 controller에 다시 섞이지 않도록 회귀 테스트 보강

## 안전성

HTTPS 장소 링크, 위치 미저장 원칙, marker cleanup, Escape 취소, 로드뷰 fallback,
측정 도형 삭제와 지도 resize 동작을 유지한다.
