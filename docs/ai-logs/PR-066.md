# PR #66 · WaveField 수학과 인트로 마스크 분리

## 발견

`components/WaveField.tsx`가 React canvas lifecycle뿐 아니라 파형 룩업 테이블,
팔레트, 파동 모델, 인트로 타이밍과 파도·무장애·워드마크 도형 래스터화까지 직접
관리하고 있었다. 파형 또는 인트로 형상을 바꾸려면 event/observer/frame buffer까지
함께 읽고 수정해야 했다.

## 구현

- `features/motion/wave-model.ts`: 낮은 밀도 문자 ramp, deep/light 팔레트, 4096단계
  sin lookup, 진행파 상수, 인트로 stage 계산과 ripple 타입을 분리했다.
- `features/motion/intro-masks.ts`: 파도, 무장애 심볼, W.A.V.E 워드마크를 0~1 마스크로
  만드는 offscreen canvas 래스터화를 분리했다.
- `WaveField.tsx`는 canvas 크기 조정, frame buffer, observer, 포인터 상호작용과
  requestAnimationFrame orchestration에 집중한다.
- 본체는 512줄/약 23KB에서 360줄/약 16KB로 줄었다.
- 기존 glyph 밀도, 1.96초 stage, reduced-motion과 새 모듈 경계를 검증하는 회귀
  테스트를 갱신했다.

## 역할 구분

- 사람: W.A.V.E 모션을 유지하면서 렌더링 lifecycle과 독립 계산 책임을 분리하라는 기준 위임
- 도구: WaveField 책임 감사, 모듈 분리, 회귀·빌드·배포 검증

## 배포 영향과 제한

- 출력 문자, 색상, 파형 상수, 인트로 도형·타이밍과 사용자 motion preference는
  변경하지 않는다.
- 새 dependency, 환경 변수, API 또는 DB 변경은 없다.
- 고성능 frame buffer 복사와 viewport/document visibility 기반 animation 정지는
  기존 canvas component에 그대로 유지한다.
