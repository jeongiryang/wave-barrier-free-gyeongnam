# PR 124 — 일정 결과·오디오·추천 근거 화면 분리

## 목적

- 하나의 결과 컴포넌트에 섞인 일정, 오디오, 공유, 추천 근거 화면을 사용자가 이해하는 영역과 같은 단위로 나눈다.

## 변경

- `PlannerRouteOverview`: 추천 일정, 이동 요약, 공유와 걷기 코스를 표시한다.
- `AudioGuidePlayer`: 오디오 재생 상태와 접근 가능한 대본 UI를 표시한다.
- `PlannerEvidencePanel`: 데이터 상태와 추천 생성 근거를 표시한다.
- `PlannerResultsPanel`은 두 결과 영역을 조합하는 화면 경계로 축소했다.
- 제품 소스 테스트가 분리된 화면까지 포함하도록 갱신했다.
