# PR-082 — Planner 파생 모델과 UI lifecycle 분리

## 목적

`app/planner/page.tsx`에 남아 있던 교통 준비 상태 계산, 상황 영향 파생값,
장소 대화상자 focus trap, 조건 변경 자동 갱신, 사용자 액션을 feature 경계로 이동한다.

## 변경

- `features/planner/view-model.ts`
  - 제공기관 fallback 상태와 화면 파생값을 순수 계산 모듈로 이동
  - 날씨·관광 집중률 기반 일정 영향 모델 조립을 UI에서 분리
- `features/planner/hooks/usePlannerActions.ts`
  - 출발/도착 선택, 부가 장소 경로, 상황 대안, 공식 예약 경로 복사를 묶음
- `usePlaceDialogFocus`, `usePlannerAutoRefresh`
  - 키보드 focus lifecycle과 조건 변경 debounce/abort를 독립 hook으로 이동
- `RichMode`, `DestinationCrowd`를 planner 공통 type으로 승격
- architecture 회귀 테스트 추가

## 검증

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `npm audit --omit=dev --audit-level=high`
- `git diff --check`

## 영향

API, DB, 환경변수와 사용자-visible 동작은 바뀌지 않는다. Planner route는 화면
구성과 feature wiring에 더 집중하며, 파생 계산과 browser lifecycle은 독립적으로
변경·검증할 수 있다.
