# 나루 후속 일정안 안정화

- 작성자: jeongiryang / Codex
- 목적: 운영 검증에서 재현된 후속 일정안의 잘못된 만료와 편의 비교표의 원문 줄바꿈 태그 노출 수정.

첫 일정 적용이 시작한 관광 검색이 후속 AI 요청 도중 완료되면 검색 상태와 조회 시각이 변경되어, 여행 자체가 같아도 일정안이 만료됐다. 일정안에는 여행 조건·일정·교통의 변경 검사를 적용하고 검색 결과를 사용하는 일반 명령의 기존 검사는 유지했다. 실제 편집 이후 도착한 오래된 제안은 계속 차단한다.

편의 비교에서는 제공처의 br 줄바꿈만 일반 공백으로 정리한다. 원문 객체와 확인·부재·미확인 상태는 보존하며 HTML을 실행하지 않는다.

## 검증

- 실제 운영 로컬 LLM 2회 성공, 첫 일정 적용 성공, 후속 조정안의 즉시 만료를 관찰.
- 동일 비동기 순서의 합성 재현은 수정 전 실패, 수정 후 성공.
- 나루 관련 데스크톱·모바일 36/36 및 변경안 이동 2/2 통과.
- 전체 단위 검사 1626/1626, 타입 검사 통과, lint 오류 0 / 기존 경고 25.
- 운영 빌드 및 기존 성능 예산 통과. 예산·테스트 보호 조건은 변경하지 않음.
- 사용자는 심사용 계정 가입을 완료했고, 실제 ID 로그인과 계정 여행 저장을 확인함. 인증정보는 기록하지 않음.

## 역할과 후속

사용자가 기능 완성·배포를 승인했다. Codex가 구현·독립 회귀 검증을 수행했다. 최종 CI와 Actions 배포 후 실제 모델 후속 조정 흐름을 다시 확인한다. 최종 공모전 제출은 별도 사용자 작업이다.
