# 운영 응답과 연락처 후속 진단

사용자가 남은 기능·사용성 검증을 모두 진행하도록 요청했고, 실제 기기 사용은 현재 불가능하다고 확인했다. 전문 API 하네스로 운영 502를 좁히고 독립 QA가 공개 응답과 로그의 민감정보 경계를 확인했다.

실제 관광정보의 기관명 포함 연락처를 전화 링크로 사용할 수 없어, 제공 문구를 그대로 보존하면서 완전한 번호만 각각 연결한다. 내선·범위·팩스·URL 표기는 연결하지 않는다. 독립 검토에서 추가로 발견한 팩스 레이블 변형도 회귀에 포함했다.

주차는 전체 페이지 검증을 유지한 채 고정된 거절 사유와 안전한 숫자만 서버 로그에 추가한다. 운영 자격 증명은 Sensitive 상태여서 로컬로 가져오지 않았고, 이를 바꾸거나 새 키를 만들지 않았다. 원문·키·URL·레코드 값은 기록하지 않는다. 배포 후 제한된 한 요청의 서버 로그로 실제 원인을 확인할 계획이며, 이 변경 자체를 주차 복구로 표시하지 않는다.

독립 검증은 주차 관련 45개, 연락처·운영시간 11개 통과. 전체 단위 1,744개와 빌드·성능 검사 통과. 반려동물/웰니스 브라우저 4개에서 세 화면 폭과 접근성을 확인했다. 이전 전체 감사의 경로 비교 시간 초과 1건은 별도 원인 분석 중이며 최종 후보 전체 감사를 대신하지 않는다.

커밋은 PR 필수 CI 성공 후 squash하고 Actions CD로만 배포한다. DB·권한·요금제 변경은 없으며 코드 문제는 해당 squash를 revert하는 PR로 복원한다. 실제 계정 검증 데이터는 이미 삭제 확인했고 최초 하네스 백업은 유지한다.

## 40d537a 이후 실제 실패 후속

공식 진주성 해설 2건을 확보했지만 실제 음원은 운영 CSP에 차단됐다. 보안 정책을 제거하지 않고 확인된 Odii CDN 한 origin을 media/connect에 추가한다. 독립 QA는 배포 정책을 실제 브라우저에 적용해 공식 origin의 합성 음원 재생·공간음향 디코딩과 다른 origin 차단을 검사한다. 실제 음원은 새 배포에서 별도로 확인한다.

주차 첫 페이지는 JSON 파싱 뒤 envelope 거절까지 좁혀졌다. 공식 문서에는 래퍼 샘플이 없어 고정된 알려진 위치의 타입과 허용 목록 코드만 추가 진단한다. 실제 원문은 기록하지 않으며 응답을 추측해 수락하지 않는다.

전체 감사의 경로 비교 실패 trace에서 버튼과 경로 선택은 유지됐다. 여러 boundingBox 프로토콜 호출을 한 DOM 크기 평가로 바꾸되 필수 조작 수·선택·로딩 종료 확인을 더하고 기존 6폭/44px/axe/45초 한도를 유지했다. 원본 실패를 보존했고 네 조합과 실패 조합 세 번 반복을 통과했다.
