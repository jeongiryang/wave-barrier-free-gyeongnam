# PR-109 — 인증 feature 경계 분리

## 목적

로그인 form이 마크업, session, 입력 검증, Neon Auth 요청, redirect timer를 함께 소유하던
구조를 기능 경계와 독립 controller·검증 모듈로 정리한다.

## 변경

- 로그인·회원가입·계정 메뉴·브랜드 모션을 `features/auth/components`로 이동
- session·submit·redirect 수명주기를 `useAuthForm` controller로 분리
- return URL 방어, 사용자용 오류 변환, 가입 입력 검증을 순수 모듈로 분리
- redirect timer unmount cleanup 추가 및 route·공용 header import 갱신

## 안전성

서버 Neon Auth 계약과 cookie 정책은 변경하지 않는다. 외부 origin으로 이동할 수 없는 return URL,
비밀번호 범위, accessible label·오류 연결, 로그인 없이 여행 설계 가능한 제품 원칙을 유지한다.

## 검증

- `npm run lint`

- `npm run build:vercel`

## 영향

인증 UI와 요청 수명주기, 순수 검증을 서로 독립적으로 변경하고 테스트할 수 있다.
