# PR #248 — 계정 수명주기 완성

## 문제

- 로그인 화면이 비밀번호 재설정과 계정 탈퇴를 지원하지 않는다고 명시하고 있었다.
- 인증 계정만 삭제할 경우 작성 글·댓글·좋아요·신고가 사용자 식별자와 함께 남을 수 있었다.

## 변경

- 이메일 기반 비밀번호 재설정 요청과 일회용 토큰 재설정 화면을 추가했다.
- 로그인 계정에서 비밀번호 변경과 다른 세션 해제를 제공한다.
- 계정 탈퇴는 현재 비밀번호와 확인 문구를 요구하고 인증 계정 삭제와 커뮤니티 데이터 삭제를 연결한다.
- 인증 제공처가 이메일 확인 삭제를 사용하는 경우를 위해 256비트 일회용 정리 토큰의 해시만 48시간 보관한다.
- 계정과 연결된 게시글·댓글·좋아요·신고를 한 트랜잭션으로 삭제하고 만료된 정리 토큰은 기존 예약 작업에서 제거한다.
- 개인정보·이용 안내를 실제 기능과 일치시켰다.

## 보안·개인정보 경계

- 비밀번호는 커뮤니티 DB나 로그에 저장하지 않는다.
- 정리 토큰 원문은 DB에 저장하지 않고 SHA-256 해시만 저장한다.
- 탈퇴·정리 POST는 같은 출처와 본문 크기를 검사한다.
- 계정 존재 여부를 비밀번호 재설정 결과로 구분하지 않는다.
- 탈퇴 완료 화면은 `no-referrer`로 설정하고 사용한 토큰을 주소에서 제거한다.
- 인증 계정 삭제 뒤 DB 정리가 일시 실패하면 정리 권한을 폐기하지 않고 일회용 완료 화면에서 재시도한다.
