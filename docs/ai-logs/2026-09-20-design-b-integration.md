## 결과

서비스 소개를 Design B의 야경 히어로·지역 카드·여행 조건과 지도·연결된 일정·커뮤니티/축제/여행 정보로 교체했다. 인트로 구현·스타일·입자 마스크·엔진·색상과 단계는 최신 사용자 지시에 따라 현재 운영 main 버전을 그대로 유지한다. 새로운 인트로 연출은 이번 배포에 포함하지 않는다. 기존 인트로와 새 소개 화면의 연결만 회귀 검증한다.

커뮤니티와 축제 배너, 여행 설계, 로그인·계정·정책·여행집 및 나루를 navy/cyan/violet 체계로 연결했다. 관광지 사진과 축제는 공공 데이터, 홍보 배너는 생성 이미지를 사용한다. 기존 카드/목록/촘촘히 보기, 검색·카테고리·인기/댓글 정렬·저장한 글, 장소별 커뮤니티, 지도 편의, 일정 저장·공유·직접 수정·나루 적용/되돌리기를 유지한다.

카카오 로그인은 운영 서비스에 남아 있었다. 자격 증명이 없는 로컬 공개 미리보기에는 운영 로그인 진입 링크를 제공하며 로컬과 운영 세션을 혼동시키지 않는다. 나루의 로컬 미설정 health가 운영 모델을 사용할 수 있다고 잘못 보고하던 경로도 제거했다. 소개의 나루 사례 버튼은 별도 Context 모듈을 통해 실제 대화창에 연결했다.

## 전체 CI에서 확인한 회귀와 수정

첫 통합 CI `35510469943`은 품질·보안 검사는 통과했지만 브라우저 검사에서 실패했다. 기존 상세 도구의 흰 배경/고정 글자색이 새 야간 팔레트와 충돌했고, 일부 검사는 교체된 소개 화면의 제목·배치·항상 펼쳐진 영역을 전제로 했다. 실패한 CI를 우회하지 않고 실제 기능 검증과 새 디자인 검증을 구분해 수정했다.

커뮤니티 hydration 이전 검색·필터·정렬 보호, 나루 런처가 초점 받은 지도 버튼을 가리지 않도록 스크롤 보정, IntersectionObserver 없는 환경의 소개 지도 fallback을 복구했다. 세부 편의·교통·여행 당일·댓글·계정 패널을 같은 표면 토큰으로 연결했다. 검사에서는 출처·미확인 정보·언어·키보드·44px·대비 기준을 유지하며 폐기된 화면 선택자만 실제 진입점으로 갱신했다.

수정 후 로컬 타입 검사, lint 오류 0(기존 경고 23), 단위 테스트 1,588개가 통과했다. 독립 커뮤니티/여행 도구 164개는 최초 147개 통과 후 실패 17개 재검증 전부 통과했고, 여행 저장·계정 충돌·지역/교통 전환과 소개·사진 실패·키보드 회귀의 잔여 실패도 재검증했다. 최종 공통 대비/지도 검사 6개 모두 통과했다. 개발 중 HMR로 중단된 경우는 소스를 고정한 상태에서 재검증했으며 이를 기능 성공으로 세지 않았다.

최종 빌드의 CSS gzip은 81.97KiB, 랜딩 초기 JS는 140.13KiB, 설계 초기 JS는 251.68KiB다. 상세 도구 수정으로 CSS가 82.46KiB가 되어 폐기된 사진 코스 헤더·이전 출발 정보 격자 등 실제 참조가 없는 선택자를 추가 제거했다. CSS 상한 82KiB와 JS 상한은 추가로 올리지 않았다. 아래 81.00KiB는 첫 통합 후보의 측정 기록이다.

운영 모델 추가 점검에서 일정 생성·후속 날짜 변경·휴식 추가 세 요청이 HTTP 200으로 정상 변경안을 반환했고 생성 일정은 실제 관광공사 장소 ID를 사용했다. 이 역시 새 프론트 배포 전 운영 연동 확인이며 최종 배포 검증을 대신하지 않는다.

## 최초 후보의 성능 기록과 운영 제한

최종 로컬 빌드 성공. 26개 폐기 클래스의 규칙을 정리해 원문 20,631바이트를 제거했고 CSS gzip 81.00KiB, 랜딩 초기 JS 140.07KiB, 설계 초기 JS 251.38KiB로 측정했다. 변경한 성능 계약 테스트 6개도 통과했다.

추가 소개 페이지·부수 화면·팀원 기능까지 포함한 최초 전체 CSS gzip은 83.55KiB로 이전 78KiB를 넘었다. 사용하지 않는 레거시 선택자를 제거하고 새 범위의 CSS 상한을 82KiB로 명시적으로 갱신한다. 이전 상한을 통과했다고 주장하지 않는다. 초기 JS 예산은 유지한다(랜딩 155KiB, 설계 270KiB); 지도는 화면 근처에서 지연 로드하고 나루·계정도 기존 지연 경계를 보존한다.

공공 동행 프로그램과 지역 소리는 승인된 레지스트리가 비어 있어 실제 안내/음원 제공 완료가 아니다. 쓰레기통·여성용품의 운영 제공처 URL과 금연 API 활용 승인 여부는 별도 확인 대상이다. 현장 제보 게시판은 기존 플래그 기본 off를 유지한다. 미확인 시설이나 실제 이동시간을 만들어 채우지 않는다. 공모전 자료 제출이나 계정 삭제는 이 배포의 작업 범위에 포함하지 않는다.

## 두 번째 전체 CI의 잔여 회귀

CI `35512630848`에서 남은 29개 실패와 간헐 실패 3개를 각각 추적했다. 모바일 계정 유틸리티 화면의 h1이 숨겨진 보조 영역에만 있던 문제를 본문 제목으로 수정했고, 공개 소개 화면의 즉시 인증 조회를 계정 의도 이후로 지연했다. 이때 로그인 링크를 재마운트해 키보드 초점이 사라지지 않도록 세션 관찰과 링크 DOM을 분리했다.

음식점 선택 칩은 배경/글자 토큰을 같은 blue/on-blue 쌍으로 바꾸고 주차 선택·음식점 펼치기·나루 사용 방법의 대비를 복구했다. 여행 설계 지도에서 버튼마다 반복되던 인구감소지역 고시는 별표와 공통 출처 한 번으로 정리하고 각 지정 지역 버튼의 접근성 설명에 연결했다.

모바일의 간헐 클릭 유실은 나루 런처의 초점 노출 스크롤이 pointerdown과 pointerup 사이에 눌린 요소를 이동시킨 실제 문제였다. 키보드 focus-visible에만 노출 스크롤을 적용하고 포인터 동작 중 예약된 스크롤을 취소한다. 느린 상류 테스트의 원래 테마·시설 선택 절차와 요청 예산 검사는 그대로 보존한다.

화면 변경에 따른 검사는 실제 열린 나루 dialog/입력 준비 이후 Escape를 검증하도록 동기화했다. 사진 허용은 실제 렌더한 지도 썸네일에 한정하며 사용하지 않은 앨범·불필요한 사진 API·민감 좌표 전송 금지를 유지한다. 승인되지 않은 동행 프로그램 폼 금지와 이미 승인된 여행 체크리스트 입력을 구분했다. Chromium의 비모달 스크롤 dialog 자체 탭 위치를 허용하되 다음 탭이 바깥으로 나가는지와 모바일 모달의 초점 유지 검사는 보존한다.

로컬 잔여 대비/기능 54개, 계정·성능 21개, 소개·사진·언어 10개, 로그인 키보드 4개, 대안·여행 진행 반복 12개를 통과했다. 최종 포인터 회귀·빌드·전체 CI 결과는 이 이후의 Actions 실행으로 확인한다. 앞선 실패 또는 재실행의 성공을 최종 CI 성공으로 기록하지 않는다.

포인터/키보드 수정 후 원래 조건 선택을 포함한 핵심 흐름 16/16이 통과했다. 세 번째 후보 빌드와 성능 예산도 성공했다(CSS gzip81.97/82KiB, 소개140.12/155KiB, 여행 설계251.80/270KiB). 등록된 경고·검증 범위 및 외부 제공처 제한은 유지한다.

세 번째 CI `35513851507`의 잔여 문제는 나루 도움말의 흰 글자/강조 배경 조합, 포인터 이후 프로그램 초점 복귀, 지연 로딩과 무관한 동작을 비교하던 검사 두 곳이었다. 나루 메뉴 링크만 명시적인 밝은 글자색을 적용해 다른 버튼의 배경 토큰에 영향을 주지 않도록 했다. 포인터 동작 중 스크롤 취소는 유지하고 프로그램이 복구한 초점도 노출한다. 관련 나루 16개, 지도/여행 흐름18개, 말투/인증16개를 통과했다.

말투 검사는 실제 인증 링크의 lazy mount와 세션 준비 이후 이름을 비교한다. 주차 문의 검사의 추가 요청은 민감정보 전송이 아닌 장소별 공개 커뮤니티 후기의 지연 조회로 trace에서 확인했다. 공개 후기 준비와 문의/복사 동작의 네트워크 검증 시점을 분리하며 문의 내용·좌표 전송 금지는 유지한다.

최종 CI 네 번째 실행에서는 인증 로그아웃 뒤 정상적으로 존재하는 텍스트/아이콘 로그인 링크의 중복 이름, 여행 진행 지연 모듈 로드 시점, 긴 갤러리 캡처의 임시 뷰포트 복원, 문화 안내 초기 hydration 클릭을 추가로 확인했다. 계정 검사는 실제 계정 아이콘과 복귀 URL을 검증하고, 진행 화면은 실제 준비 뒤 모든 요청 0건을 확인한다. 지역 선택은 뷰포트 캡처 뒤 실제 선택과 API 응답 검사를 유지한다. 문화 details에는 준비 전 inert 보호를 적용하고 SSR/client 전환 완료 뒤 펼침·출처·보안 속성을 검증한다. CI retry/timeout/필수 검증 게이트는 변경하지 않았다.
지역 선택의 완전 노출 검증을 강화하면서 좁은 화면의 `.simple-region` 고정 aspect-ratio가 실제 210px 버튼을 잘라 사진/이름을 가리는 제품 결함도 확인했다. 이미 콘텐츠 높이를 쓰는 base 규칙과 충돌하던 초기·모바일 부모 aspect-ratio 두 줄을 제거해 카드가 버튼과 출처를 모두 담도록 복구했다.
