# PR-193 — 커뮤니티의 두 테마 글자 대비 복원

## 목적

Production 커뮤니티 목록에서 남은 밝은·어두운 테마의 본문 대비 미달을 정리한다.
게시 시각, 작성자·반응 수, 장소 태그, 게시판 탭, 페이지 이동과 푸터가 WCAG 2 AA
본문 기준 4.5:1 이상을 유지하게 한다.

## 원인

- 밝은 화면의 게시 시각은 3.18:1, 카드 푸터는 3.69:1에 머물렀다.
- 어두운 화면에서는 탭·페이지 버튼과 커뮤니티 푸터의 배경이 테마 토큰과 함께
  밝아졌지만 고정 전경색은 그에 맞춰 바뀌지 않았다.
- 어두운 카드 안의 장소 태그와 보조 정보는 짙은 표면에 밝은 전경색 쌍이 없었다.

## 변경

- 밝은 화면의 게시 시각과 카드 푸터 보조문을 5.35:1 색으로 보강한다.
- 어두운 화면의 탭·페이지 버튼, 장소 태그, 카드 보조 정보에 짙은 표면과 밝은
  전경색을 명시한다.
- 커뮤니티 푸터는 테마 토큰 반전과 무관한 짙은 표면으로 고정하고 제목·안내·링크
  전경색을 함께 맞춘다.
- 실제 게시글을 모의한 desktop/mobile Playwright 검사에서 두 테마의 관련 선택자
  전체를 계산해 4.5:1 이상으로 고정한다.

## 범위

별도 작업 단위에서 처리한다.
