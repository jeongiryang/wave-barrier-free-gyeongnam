- AI: 코드·팀원 #532 U5 대조, 구현, 회귀·접근성·크기 검증

## 변경
나루에서 내 여행 점검 또는 명확한 점검 요청을 선택하면 같은 시간표 계산으로 날짜별 방문·체류·휴식, 고정 방문 지각, 날짜 넘김, 귀가 마감·귀가시간 미확인, 추정 이동 구간, 설정된 휴식 간격을 설명한다. 기존 운영시간 조회 및 충돌 대응을 연결한다. 날짜 미정이면 날짜·출발지 설정으로 이어지며 날짜를 임의 생성하지 않는다.
점검은 상태를 바꾸거나 모델 POST를 호출하지 않는다. 여유로운 변경안은 요청문을 먼저 채우고 사용자 전송 후 기존 제안·적용·되돌리기 경로를 사용한다. 기존 여행 제약과 편의를 해제하지 않는다.
도구가 지연 로드될 때 고정 프레임 초점 이동이 실패하는 문제를 함께 수정했다. DOM 관찰은 실제 목표 발견 또는 5초 뒤 종료하며 다음 이동/언마운트에 정리한다.

## 검증
- 타입, lint(오류 0, 기존 경고 13), 단위 1501개 성공.
- 최종 관련 브라우저 34개 성공(56초). 날짜 미정 보존, 모델 오프라인 점검, 지각/귀가 미확인/휴식/추정 설명, 요청 전 상태 보존, 도구 초점 연결, 기존 여행 여정 포함.
- 1440/960/390px 넘침 없음, 점검 버튼 44px 이상, axe 통과. 960/390 캡처 시각 검수.
- 빌드 및 성능 예산 성공: CSS gzip 69.27/70KiB, planner initial 222.57/270KiB.
- 초기 테스트의 경로 fixture URL 누락 수정. 실제 발견된 지연 도구 초점 결함은 제품 코드에서 수정 후 재검증.

## 범위
합성 제공처 기반 로컬 검증이며 실시간 운영정보 정확성·보행 가능성을 보장하지 않는다. 출발지·귀가시간·휴식 공간은 사용자가 확인한다. 심사 계정 보류, ODsay hold, 최종 공모전 제출과 별개다. #532 전체 종료가 아니다.
