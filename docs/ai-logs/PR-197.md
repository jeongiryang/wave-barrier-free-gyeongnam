# PR-197 — 여행 설계 화면의 라이트·다크 대비 정리

## 목적

공통 화면 대비 검사를 추가한 뒤 별도 범위로 남겨 둔 `/planner`의 작은 글자와
상태 컨트롤을 WCAG AA 4.5:1 이상으로 맞춘다.

## 원인

- 라이트 화면의 작은 보조 글자에 `#7c98a5`~`#90a3ac` 계열이 사용돼 흰색·옅은
  표면에서 대비가 2.41~4.4에 머물렀다.
- 다크 토큰을 선언한 뒤 불러오는 작업공간 CSS가 흰색 카드와 밝은 상태 배경을
  다시 지정했다. 그 결과 밝은 글자가 흰 카드 위에 놓이거나, 어두운 글자가
  어두운 표면 위에 남았다.

## 변경

- `planner-theme-contrast.css`에서 여행 설계에 한정해 보조 글자와 상태색을
  라이트·다크 표면에 맞춘다.
- 공통 대비 E2E의 공개 화면 목록에 `/planner`를 추가한다.
- 동시에 열린 #196에서 확인된 혼잡도 범례, 출발지 버튼, 선택 요약과 편의조건
  칩의 고유 수정도 통합했다. #196의 2.5:1 가드보다 강한 4.5:1 전체 검사를 쓴다.

## 검증 기준

- lint, typecheck, 단위·통합 테스트, Vercel build
- 데스크톱·모바일의 라이트·다크 브라우저 E2E
- 반투명 조상 배경을 합성한 직접 대비 측정에서 4.5:1 미만 0건
