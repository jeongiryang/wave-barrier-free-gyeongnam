# 나루 여행 속도 선택 UI 개선

- 목적: 모호한 이동 부담/가볍게/보통을 설명이 붙은 선택 카드로 변경한다.
- 사람: 이해하기 쉬운 UI 개선 요청, 기존 기능 유지 및 PR/조건 충족 시 병합 승인.
- AI: 프론트 구현, 기존 회귀 검사 갱신, 검증과 PR 진행.
- 변경: 질문형 제목, 여유롭게 쉬어가기/적당히 둘러보기, 각 설명, 네이티브 라디오와 전체 카드 터치 영역. 기본값과 전송 프롬프트는 그대로 유지한다.
- 로컬 검증: lint 오류 0 (기존 경고 25), typecheck, 전체 단위 검사, Vercel build, performance budget, npm audit 통과. 기존 작업공간 브라우저 검사 24개 통과. 1440/960/390px 시각·axe 검사 3개 통과 및 모바일 스크린샷 확인.
- 최종 PR CI와 배포 결과는 PR에 기록한다.
