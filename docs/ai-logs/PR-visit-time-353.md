## 목적과 동작

미술관을 120분 대신 30분 둘러보기로 정하면 같은 날 뒤 장소의 도착·종료가 90분 앞당겨진다. 날짜별 일정의 더보기에서 기본값, 30/60/90/120/180분 또는 15~720분 사이 정수를 선택한다. 직접 입력은 적용·취소가 가능하고 Enter/Escape 뒤 초점을 원래 선택 상자로 돌려준다. 다른 날짜와 확인된 실제 이동시간은 바뀌지 않는다.

시간 선택은 새로고침, 내 여행 보관·다시 열기, 계정 여행 저장, 공유 링크에 유지한다. 계정 멤버는 읽기만 가능하며 소유자 변경은 명시적 저장 때 반영한다. 장소를 제거하거나 교체하면 그 장소에 지정한 시간을 제거한다. 저장 후 기본값 복원에 필요한 허용된 장소 유형만 브라우저 스냅샷에 보존한다. 서버에는 기존 장소 ID와 사용자가 선택한 시간만 추가하며 관광공사 원문·좌표·개인정보를 새로 저장하지 않는다.

## 역할

Owner가 기능·프론트 통합과 병합·Production 확인을 승인했다. Codex는 코드/상태/가이드/검사를 구현했고 별도 QA 에이전트가 브라우저와 키보드 동작을 독립 검수했다. 실제 계정·커뮤니티 쓰기와 카카오 메시지는 실행하지 않았다.

체류시간은 사용자의 계획 값이다. 실제 운영시간·예약/귀가 시각과의 충돌 판단은 다음 시간 제약 기능 단위에서 구현한다. 이동시간의 실제/추정/미확인 구분은 유지한다. ODsay 제공처 hold #454는 이 기능의 성공이나 배포로 해결됐다고 표시하지 않는다. 전체 클릭 동작 전수 감사와 나머지 후보, 최종 회귀·리팩토링·제출 점검은 계속한다.
