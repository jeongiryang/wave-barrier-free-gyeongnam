# PR 128 — 여행 조건·추천·날짜별 일정 화면 분리

## 목적

- 플래너의 가장 자주 변경되는 조건 입력과 추천 결과 영역을 사용자 작업 단위로 분리한다.

## 변경

- `PlannerJourneyBasics`: 출발 거점과 여행 지역을 담당한다.
- `PlannerThemeDates`: 여행 테마와 기간을 담당한다.
- `PlannerAccessibilityProfiles`: 편의 조건, 선택 요약, 결과 갱신을 담당한다.
- `PlannerConditionsPanel`은 세 조건 영역을 조합한다.
- `RecommendationCarousel`: 공식 추천의 로딩·오류·빈 상태, 카드, 저장·길찾기를 담당한다.
- `TripDayPlanner`: 보관 장소의 최적 순서와 날짜 배정을 담당한다.
- `RecommendationWorkspace`는 추천과 일정 영역을 조합한다.
