## 실제 문제와 수정

실제 DSW 모델·관광 API로 일정 생성, 낮잠 추가, 되돌리기는 성공했다. 이어서 카카오 지도의 주변 검색을 시작하자 늦은 장소·경로·혼잡도 응답이 지도를 다시 만들면서 검색을 지웠다. 이전에 준비 중 버튼을 보호한 수정만으로는 이 사용 흐름을 해결하지 못했다.

- 지도 수명과 표시 내용을 분리한다. 공개 출발지와 순서가 있는 장소 ID·좌표가 같으면 카카오/대체 지도 SDK, 주변 검색, 사용자의 화면 위치를 유지한다.
- 늦은 장소 정보·경로선·혼잡도를 같은 지도 위에서 갱신한다. 동일 시각 내용은 다시 그리지 않지만 마커 클릭에는 최신 장소 자료를 사용한다. 기존 표시 객체를 정리하고 장소 선택과 키보드 초점을 보존한다.
- 실제 출발지·장소 추가/삭제·순서·좌표 또는 재연결이 바뀌면 기존 세대를 취소한다. 늦은 오류·응답이 새 지도를 덮지 않으며 검색을 자동 재실행하지 않는다.
- 장소 메타데이터 갱신만으로 선택 장소에 다시 이동하던 effect도 실제 지리 범위와 명시적 선택에 맞춘다.
- 커뮤니티는 서버 HTML이 나타났으나 이벤트가 준비되기 전 클릭이 사라지던 상태를 수정한다. 기존 hydration 상태에 맞춰 조작을 활성화하고 준비 상태를 표시한다.
