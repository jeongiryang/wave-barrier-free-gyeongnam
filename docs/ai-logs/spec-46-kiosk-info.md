# 명세 46 주문 방식과 사람 응대 여부 확인

- 무인 주문기 유무를 추측하거나 저장하는 필드를 만들지 않았다.
- 기존 현장 의사소통판 `payment` 주제 안에 사람에게 주문하고 싶다는 문장을 추가했다. 주제와 직원 답변 값은 늘리지 않았다.
- 방문 전 문의에는 기본으로 선택되지 않는 `사람에게 주문` 질문을 추가했다.
- 장소 상세의 시설 단계에서 방문 전 문의와 현장 화면 대화로 바로 이어진다.
- 문장 선택과 대화 세션은 기존 React 메모리 상태만 사용하며 서버·브라우저 저장소·위치 API를 사용하지 않는다.
