# 나루 여행 작업공간

- 사람: 정이량이 나루 시안과 여행 맡기기·수정·저장 후 이어가기, 3초 간격 다섯 안내 말풍선을 승인했다.
- AI: 기존 24개 도구 조사, 같은 여행 상태를 사용하는 UI·기기 기록·회귀 검사 구현과 독립 QA.
- 범위: 나루만 변경. 인트로와 공모전 제출·계정 생성은 이번 작업에서 제외한다.

## 동작

- 차콜·연보라 시안의 대화/여행 도구/저장한 내용과 2열 여행 요약, 기존 사진·음성·읽기·근거·적용/되돌리기를 연결한다.
- 여행 준비 입력은 명시한 지역·날짜·동행·이동 부담·이동수단을 기존 나루 요청으로 전달한다. 실제 관광 조회의 진행과 일정안을 표시하고 적용 전에 확인한다.
- 24개 도구는 기존 진입점을 사용한다. 나루 전용 여행 상태나 별도 LLM 제공처를 만들지 않는다.
- 명시적 기기 저장만 제공한다. 최근 대화 30개, 최대 10개 여행의 제목·텍스트·입력과 여행집 저장본의 연결을 보관한다. 원본 사진·실행 제안·undo 영수증·좌표는 복원하지 않는다. 사진 유래 텍스트의 출처는 보존해 일반 대화에 자동 재전송하지 않는다.
- 다른 여행 열기는 기존 여행집 백업/복원으로 처리한다. 미전송 입력·현재 대화는 저장 여부를 선택하며, 저장 실패·다른 탭의 여행 변경은 덮어쓰기 전에 차단한다.
- 안내 말풍선은 실제 기능 다섯 가지를 3초마다 순환한다. 조작 중 문구를 고정하고, 닫기는 세션 동안 유지하며, 동작 감소 환경에서는 정적으로 표시한다.

## 검증 기록

- 기존 나루 직접 명령·일정 적용/되돌리기·사진 복구·도움·음성 안내·근거·스트림: 데스크톱/모바일 78개 통과.
- 말풍선과 기존 초점 보호: 데스크톱/모바일 8개 통과.
- 새 작업공간 E2E 12개 통과: 준비→확인→적용/되돌리기, 24개 도구, 저장/새 여행/복원, 다른 탭 충돌 보호.
- 1440×960·960×800·390×844 시각/접근성 3개 통과: 가로 넘침 없음, 44px 조작, 준비/저장 화면 axe 위반 0.
- 전체 단위 1,599개 통과(저장 경계 11개 포함), 타입 검사 통과, ESLint 오류 0·경고 24, Production 빌드 성공.
- CSS gzip 실측 83.60 KiB로 기존 82 KiB를 초과했다. 새 작업공간과 안내 말풍선의 범위를 명시해 85 KiB로 기준을 갱신하며 JS 한도는 유지한다.
- 운영 API에 합성 방문자 요청으로 실호출: 새 준비폼 문장에 source=local-llm, 통영·2026-10-03·자동차·relaxed를 보존한 create-itinerary 응답(HTTP 200, 6.48초). 일반 코스·피로 완화 요청의 실제 관광 조회도 HTTP 200. 기존 사용자 데이터/일정은 변경하지 않았다.
- 첫 CI에서 새 시안 이전 문구·크기 기대, 테스트 메시지 nullable 타입, 테마 전환 전 라디오 Tab 개수 캐시를 갱신했다. 제품 결함인 빠른 질문 가로 넘침과 상세 해설 버튼을 가리는 말풍선은 CSS로 수정했다. 관련 원본 기능 검사는 유지하며 연결 회복 6개·상세/크기 26개·task-first/visual 12개·설정 초점 16회 모두 통과.
- 최종 CI/배포 결과는 릴리스 후 PR에 기록한다.

## 제한

- 대화 기록은 기기 보관이며 계정/다른 기기 동기화나 브라우저 종료 후 백그라운드 AI 작업이 아니다.
- 저장된 실행 제안은 재실행하지 않는다. 다시 요청해 현재 여행과 공공데이터로 확인한다.
- 실제 LLM 연결 확인과 합성 브라우저 회귀 결과를 구분한다. 로컬 비밀값이 없는 환경에서 모델 연결 성공을 가장하지 않는다.
