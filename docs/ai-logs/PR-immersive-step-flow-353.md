## 목적

Owner의 추가 요구에 따라 사진은 8번처럼 화면을 채우고 중앙 텍스트는 10번의 여백을 사용한다. 마지막 여행 준비 장면 뒤에 지역 사진 카드가 이어진다. 데스크톱에서 가로 필름 이동 뒤 세로로 풀리며, 실제 카드 높이가 뷰포트에 맞지 않거나 동작 감소를 선택하면 일반 가로 목록으로 전환한다. 수동 조작은 스크롤 연동보다 우선한다.

여행 설계는 지역·접힌 날짜·활동을 한 카드에서 고른 뒤 편의, 결과, 일정으로 이어진다. 현재 일정의 요약은 큰 화면 옆에, 작은 화면에서는 접힌 영역에 둔다. 이전 전체 보기 선호값이 새 기본 흐름을 덮지 않도록 보기 설정 키만 갱신하며 저장한 장소·날짜·순서는 유지한다. 장소를 담기 전 달력을 열어도 첫 단계로 돌아올 수 있다.

## 역할

- Owner: 디자인 기준, 추가 기능 범위, 병합·Production 권한 승인.
- 구현: 기존 8/10 실사이트·첨부 화면 비교, 코드·CSS·테스트 수정, 실제 렌더 확인.
- 독립 QA: 별도 에이전트가 화면·키보드·저장·필름 동작 검토. 낮은 화면의 필름 하단 잘림을 발견해 높이 기반 fallback으로 수정.

## CI 후속 조사

- 최초 run 34575976693의 실패는 지역 섹션을 여행 준비 안으로 옮긴 DOM 구조, 새 가로 필름, 첫 화면에서 숨긴 비활성 탭, 간소화한 지역·활동 수정 경로에 관한 이전 기대값이었다. 7개 섹션의 순서·접근성·포커스, 앞뒤 스크롤 및 동작 감소, 저장 일정 보존·지연 응답 무효화 검사는 새 실제 조작 경로로 유지한다.
- 서비스 상태 상세 검사는 overview 복원이 끝나기 전에 숨긴 summary에 focus를 보내고 있었다. 독립 QA가 정상/실패 × desktop/mobile 4경로에서 가시성 준비조건만 추가해 기존 후속 검사를 통과했다. 제품 초점 로직은 바꾸지 않았다.
- 사진 선택의 숨긴 이름은 각 언어 span에 직접 sr-only를 적용한다. 화면에 보이지 않는 자손을 가시 텍스트로 오인하던 대비 결과를 해결하며 명칭·언어·선택 기능을 보존한다.
- 필수 gate, WCAG 대비, retry·timeout·성능 기준을 완화하지 않았다.
- 후속 영향 검사 44개 중 38개 PASS 뒤 남은 지역 선택 접근 경로·정적 필름 기대를 수정하고 해당 6개 모두 PASS. 최종 lint(기존 경고 12, 오류 0), typecheck, unit 801, Vercel build, CSS 69.82/70KiB PASS.
