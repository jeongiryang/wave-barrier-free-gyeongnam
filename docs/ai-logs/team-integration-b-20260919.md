# 팀 제안 통합 B: 시설 지도와 방문 전 정보

## 반영 범위

원본 PR #565, #568, #570, #572, #574, #576, #578, #580, #582, #584, #586의 연결된 브랜치를 통합했다. 원본 작성자 커밋을 유지한다.

- 지도에 여러 시설 종류 동시 표시, 독립 실패·재시도, 마커 상한.
- 충전 정보 안내, 안내견·점자블록 상태, 접근로 원문과 경사 정보의 한계.
- 음식점 편의 목록, 음식 종류 및 반복 상호 필터, 숙소 편의 정보, 자리 문의.
- A 묶음의 색 구분 보조와 상태 아이콘을 유지하면서 안내견·점자블록 전용 설명을 결합했다.

## 검토 중 수정

음식점 응답의 destination이 모든 항목에 기준 관광지 좌표를 복사하던 오류를 각 음식점 좌표로 수정했다. 제공처의 불완전한 빈 응답은 empty가 아닌 provider-error로 남긴다. 두 경계에 실행 가능한 단위 회귀를 추가했다. 모바일 도구 검사는 11개 고정 대신 모든 실제 버튼의 44px·잘림 검사와 신규 편의 표시 접근을 확인한다.

## 검증 및 한계

- 타입 검사 통과, lint 오류 0 / 기존 경고 14.
- 단위 1,362개 통과, 관련 desktop/mobile 브라우저 128개 및 모바일 조작 검사 4개 통과.
- 빌드·성능 예산 통과. CSS gzip 69.67 KiB, 랜딩 초기 JS gzip 137.76 KiB, 플래너 209.13 KiB.
- 로컬 테스트는 합성 제공처 응답이다. 실제 충전 장소 목록 확보나 안내견·점자블록 현장 검증을 완료했다는 뜻이 아니다.
- 충전 장소는 현재 공식 기관 안내를 제공한다. 안내견·점자블록은 원본의 확인/미확인/부재를 구분한다. 실시간 이용 가능·연속 경로 통행을 보장하지 않는다.
- 상위 제안 이슈는 이 묶음 병합만으로 전체 완료 처리하지 않는다.

최종 전체 CI·배포 결과는 통합 PR/Actions에서 확인한다.
