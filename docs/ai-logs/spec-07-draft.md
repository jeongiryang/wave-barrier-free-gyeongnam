# PR #미정 AI 작업 로그

- PR: 생성 후 연결
- 제목: 공공 동행 지원제도 안내 계약 추가
- 작성자: Codex (사람의 요구사항과 명세에 따라 작업)
- 최종 상태: 저장소 책임자의 제도 목록·문구 확인 대기
- AI 도구: Codex

## 목적

여행 설계의 출발 전 확인 영역에서 공식 동행 지원제도만 안내할 수 있는 정적 데이터·카드 계약을 추가한다. W.A.V.E는 사람을 모집·연결·배정하거나 이용 자격과 안전을 보증하지 않는다.

## 역할 구분

- 사람: 제도 이름·공식 링크·신청 문구·여행 목적 이용 가능 여부와 약관 문장의 최종 확인, 병합 결정
- AI: 공식 후보 출처 조사, 빈 목록의 정직한 상태, 표시 컴포넌트·약관 제안·스타일·검사·PR 작성
- 사람만 수행: 확인된 제도를 배열에 추가하고 최종 약관 문구를 승인한다.

## 조사 결과와 human-gate

- 2026-09-20 사회서비스 전자바우처의 장애인활동지원 공식 안내에서 신청 자격·주소지 주민센터 신청 경로를 확인했다: https://www.ableservice.or.kr/regm/info/getOHGC0006M0.do
- 2026-09-20 경상남도 복지포털의 장애인복지 서비스를 확인했다: https://www.gn.go.kr/welfare/contents.do?key=6510
- 위 공식 페이지들만으로 여행 목적 이용 가능 여부와 여행 전 신청 기한을 확정할 수 없었다.
- 저장소 책임자가 승인한 제도·링크·신청 문구가 없으므로 `companionSupportPrograms`를 빈 배열로 유지한다. 명세대로 빈 목록에서는 출발 전 카드가 렌더링되지 않는다.
- 약관의 모집·연결·배정·보증 부재 문장은 이 PR에서 검토할 제안이며 병합이 승인으로 기능한다.

## 결과와 제한

- 승인된 제도가 아직 없으므로 현재 화면에는 새 카드가 보이지 않는다. 확인되지 않은 기관·연락처·신청 조건은 만들지 않았다.
- 확인된 항목이 추가되면 기관, 한 줄 신청 방법, 확인일, 새 창으로 여는 HTTPS 공식 링크와 고정 안내 문구가 표시된다.
- 새 서버 handler, API, 환경 변수, DB, 분석 이벤트, 신청 폼, 개인정보·민감정보 필드, 위치 권한, 저장소, 네트워크 요청을 추가하지 않았다.
- 민간 자원봉사 매칭, 모집, 평가, 후기, 결제는 구현하지 않았다.
- 병합과 배포는 수행하지 않는다.
