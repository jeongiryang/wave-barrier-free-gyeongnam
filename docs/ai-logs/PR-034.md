## 목적

18개 시·군의 프로덕션 관광사진 응답을 전수 확인했을 때 남해와 산청만
정상 응답 안에 사진이 없어 빈 카드로 표시되는 문제를 해결한다.

## 설계

- 남해의 대표 검색어를 실제 관광사진이 확인된 `남해 다랭이마을`로 교체
- 산청과 남해에 공식 관광지 대체 검색어를 순차 적용
- 관광사진 API에 이미지가 없으면 한국관광공사 국문 관광정보 API의
  `firstimage`를 같은 출처 안에서 대체 이미지로 사용
- 임의 외부 이미지, 생성 이미지, 영구 저장된 관광공사 응답은 사용하지 않음
- 공급자 오류와 정상 빈 응답을 구분해 기존 상태 표시 규칙 유지

## 검증

- 프로덕션 18개 지역 사진 API 전수 확인: 16개 정상, 남해·산청 누락 재현
- 장소 사진 API로 남해 다랭이마을과 산청 동의보감촌 공식 이미지 확인
- `npm run lint`
