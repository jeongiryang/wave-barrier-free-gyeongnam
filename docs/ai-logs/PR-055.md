# PR #55 · 빌드 도구 보안 업데이트

## 발견

프로덕션 의존성에는 알려진 취약점이 없었지만 개발·빌드 도구 트리에
`react-server-dom-webpack`, `image-size`, `brace-expansion`, `js-yaml`,
`@babel/core` 보안 권고가 남아 있었다. 런타임에 직접 포함되지 않더라도 CI와
배포 빌드가 외부 입력을 처리하는 경로이므로 경고를 그대로 두지 않았다.

## 구현

- React와 React Server Components를 보안 수정 버전 `19.2.8`로 맞췄다.
- `image-size` 취약 경로를 제거하는 `vinext 1.0.0-beta.7`로 갱신했다.
- Vite와 RSC/React 플러그인을 호환되는 최신 패치 버전으로 맞췄다.
- lockfile의 Babel, YAML, glob 관련 간접 의존성을 보안 수정 버전으로 갱신했다.
- 취약 버전으로 되돌아가지 않도록 핵심 직접 의존성 버전을 회귀 테스트로 고정했다.

## 검증

- `npm audit --audit-level=high`: 취약점 0개
- `npm audit --omit=dev --audit-level=high`: 취약점 0개
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build:vercel`
- `git diff --check`

환경 변수, API 키와 사용자 데이터 처리 방식은 변경하지 않았다.

## 배포 후 확인

`vinext 1.0.0-beta.7`은 로컬 빌드와 CI를 통과했지만 Vercel 함수 실행 시 모든
경로가 500으로 응답하는 런타임 회귀가 확인됐다. 프로덕션 안정성을 우선해
PR #56에서 검증된 `vinext 0.0.50` 빌드 조합으로 복구했다. 이 때문에 전체 개발
트리에는 `image-size` 권고가 다시 남지만, 프로덕션 의존성 감사는 0건이며 외부
이미지 입력을 빌드 도구에 전달하지 않는다.
