# PR-098 — 대화형 도움말 콘텐츠와 수명주기 분리

## 목적

투어 콘텐츠, 포커스 트랩, 스크롤·리사이즈 측정과 포털 UI가 한 컴포넌트에
섞여 있던 도움말 기능을 데이터·controller·view 경계로 분리한다.

## 변경

- 랜딩·플래너 투어 단계를 `tour-content`로 이동
- 단계 상태, 포커스 복원, 키보드 트랩, reduced-motion 스크롤과 spotlight 측정을 `useHelpTour`로 이동
- `HelpCenter`는 trigger, dialog, progress와 포털 표현에 집중
- 뷰가 브라우저 측정 수명주기에 다시 결합되지 않도록 테스트 보강

## 안전성

Escape/Tab 키보드 동작, 이전 포커스 복원, ResizeObserver cleanup, 모바일 spotlight,
ARIA dialog·live copy와 reduced-motion 스크롤을 유지한다.

## 영향

사용자 화면과 투어 순서는 변하지 않으며 콘텐츠·측정·표현을 독립적으로 관리할 수 있다.
