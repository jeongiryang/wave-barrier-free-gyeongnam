## 목적

나루를 하나의 이해하기 쉬운 대화창으로 단순화하고, 첫 이용자가 샘플 요청과 실제 필요 조건으로 여행 설계를 시작할 수 있게 한다. 동시에 최근 검색 복구, 날씨 단위, 교통 지역 판별, 사진 매칭, 댓글 초안 복구 등 운영 흐름의 실패 조건을 보강한다.

## 사람과 AI의 역할

- 사람: 나루 캐릭터를 유지하고, 복잡한 영역을 줄이며, 필요별 도움과 샘플 예제, 사진 첨부, 배포까지 완결하도록 명시했다.
- AI: 기존 화면·저장·API 흐름을 분석하고 UI, 데이터 정규화, 실패 복구, 회귀 검사를 구현했다.

## 구현

- 데스크톱은 440px 축소·980px 확장, 모바일은 전체 화면으로 동작하는 단일 나루 대화창
- 첫 이용 선택, 샘플 요청, 현재 화면 제안, 도구 카드와 여행 설계 초점 이동
- 질병·사람 유형 대신 실제 편의시설, 휴식 선택, 안내 방식만 개인 여행에 저장
- 내 여행·여행집·계정 일정의 편의·안내 설정 복원과 구형 표시의 실제 시설 조건 변환
- 안내문·포스터 글자 확인으로 한정한 나루 사진 첨부
- 동일 조건 최근 성공 결과 복구, 경남 버스 코드 호환, Open-Meteo m/s 단위 명시
- 게시글·계정별 댓글 초안 복구와 제출·폐기 정리
- 사진 코스 사용 방법 다이얼로그와 경남 지역 사진 오매칭 차단

## 배포 영향

새 환경 변수나 DB 마이그레이션은 없다. 기존 `main` CI와 Vercel CD를 그대로 사용한다. 문제가 있으면 병합 커밋을 되돌려 기존 대화창과 저장 형식으로 복귀할 수 있다. Hosted CI·Production 결과는 PR에 기록한다.

## 제한

사진 결과로 계단, 경사, 접근 가능성이나 안전을 추론하지 않는다. 날씨·교통·편의시설은 조회한 공식 자료와 미확인 상태를 구분한다. 나루 운영 AI는 기존 Vercel 게이트웨이와 DSW 모델 연결을 사용하며, 이 변경이 네트워크 구성을 바꾸지는 않는다.
