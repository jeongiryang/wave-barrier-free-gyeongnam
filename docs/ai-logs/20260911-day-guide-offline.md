## 목적과 구현

전체보기에서 필요한 날 도구를 펼친다. 날짜별 방문 완료·건너뛰기·잠시 멈추기·이어가기·직전 표시 되돌리기, 출발 장소/시각을 선택한 남은 일정과 귀가 목표를 표시한다. 고정 방문의 건너뛰기는 금지하고, 기존 일정 ID/날짜/체류/휴식/보관·공유는 수정하지 않는다. 진행 기록은 공개 장소 ID와 날짜로 구분한 최대20개 기록이며 계정/공개 공유에 추가 업로드하지 않는다. 다른 창의 진행 변경은 다시 불러오고 명시적인 재개를 기다린다.

경로의 두 끝점이 같은 경우만 기존 조회 시간을 재사용한다. 건너뛰어 바뀐 구간은 기존 거리 추정, 좌표가 없으면 미확인으로 표시한다. 사용자의 현재 GPS를 자동 읽거나 전송하지 않는다. 실제 방문 표시는 사용자 기록이며 방문 인증이 아니다.

HTML/text 요약은 날짜/순서/주소/머무는 시간/휴식/고정시각/편의 상태·출처·조회시각, 선택적으로 진행 기록을 담는다. 연락처·운영·요금은 장소별로 명시적으로 조회한 기존 visit-info 결과만 담는다. 미확인을 무료/확인됨으로 바꾸지 않는다. HTML에는 외부 이미지·지도·글꼴·스크립트·폼·링크를 넣지 않고 CSP로 막으며 사용자 문자를 이스케이프한다. 파일은 오프라인에서 읽고 브라우저 인쇄/PDF로 보관할 수 있다.

## 제한

오프라인 파일은 저장 당시 요약이며 지도·로그인·실시간 교통·날씨를 오프라인으로 제공하지 않는다. 진행 기록은 계정 여행에 동기화하지 않으며, 사용자가 파일 저장할 때 포함 여부를 고른다. 교통 제공처 hold #454는 별도 외부 제한으로 유지한다. 배포 성공을 제공처 정상 응답이나 전체 서비스 검수 완료로 표시하지 않는다.
