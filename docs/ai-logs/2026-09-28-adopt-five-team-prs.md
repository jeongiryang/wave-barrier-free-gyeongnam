## 원안 기능을 성립시키는 버그 수정

시각 취향으로 재설계하지 않았다. 추가한 제품 수정은 다음 실제 오류에 한정된다.

- #728: 이슈 #727의 의도대로 임의 핀은 DEV 로컬 예시 장소에만 표시하고 실제 장소의 좌표 미확인은 목록으로 제공한다. 표시용 임의 위치를 실제 GPS 거리 계산에서도 제외했다. 지도 핀·목록·근처 장소 선택이 같은 제보 초안/알림 초기화를 사용하게 했다. 버튼 핀을 포함한 SVG의 `img` 역할을 `group`으로 고쳐 화면낭독기에서 핀을 조작할 수 있게 했다.
- #728: 지연된 개발용 예시 import 뒤 취소·새 요청을 재확인하고, 중간 조작이 없으면 예시 결과 화면으로 이동한다. 개발 예시는 기본 활성화다. `VITE_WAVE_LOCAL_EXAMPLES=off`는 개발 서버에서 운영 API 실패 경로를 검사할 때 사용하며, 운영 빌드는 기존 `DEV=false`로 예시를 제외한다.
- #736: 넓은 지도 화면의 왼쪽 장소 선택을 기존 중앙/지도 포커스 상태에 연결했다. 작은 화면은 기존 상세창 동작을 유지한다. CSS 비율·문구·사진·색은 변경하지 않았다.
- #732: 저장 실패 시 64px 높이 제한과 반응 영역의 고정 최소 폭이 오류 문장·재시도 버튼을 가렸다. 오류가 있는 footer에만 높이/줄바꿈 여유를 주며 정상 ON/OFF·색·블러는 원안 그대로 유지한다.

## 검증과 정합성

- 원안 새 배치에서 필요한 실제 선택/키보드/hover 단계를 테스트에 반영했다. 저장·실패·복구 assertion이나 접근성 기준을 제거하지 않았다.
- 최초 원안 통합의 API 단위 RED와 3열 선택 RED, 저장 실패 clipping RED를 보존하고 수정 후 실제 재검증했다. 개발 중 HMR로 중단된 한 모바일 검사는 소스가 안정된 뒤 해당 케이스만 다시 실행했다.
- 원안 영향 회귀 26개: 첫 실행 22 PASS/4 FAIL. 후속 #734 배치 기대 2개 및 SVG 중첩 역할 2개를 바로잡고 해당 4개 PASS.
- 3열 검증: desktop/mobile 각각 1440/1280/1024/960/390과 대표 편집·순서·날짜·삭제·복귀 보존 6개, 합계 12개 PASS. 좌표 없는 장소도 일정 leg에 유지됨을 확인했다.
- 커뮤니티: 카드 OFF/hover/키보드 ON·coarse tap·원안 사진 레이아웃·실패 후 재시도·오류 문장/버튼 clipping을 독립 검증했다. 390/960/1440px의 실제 사진 decode와 44px 버튼, 상세/담기/Undo를 확인했다.
- 별도 기본 DEV 서버에서 예시 2곳과 실제 예시 이미지 표시 desktop/mobile 2/2 PASS. 일반 브라우저 하네스는 `VITE_WAVE_LOCAL_EXAMPLES=off`로 운영 실패 복구를 확인한다.
- CSS 전송량 초기 106.97 KiB로 기존 105 KiB 한도 초과. Owner의 기존 승인에 따라 108 KiB로 좁게 갱신했다. 오류 상태 보완 후 107.02 KiB이며 JavaScript 한도와 접근성 기준은 그대로다.
- 최종 lint·typecheck·단위·보안·빌드·성능·Quick CI와 운영 배포 결과는 통합 PR 본문에 정확한 SHA/run URL과 함께 기록한다. 원본 로그와 독립 보고서는 `harness-results/adopt-five-prs/`에 보관했다.
- 최종 전체 단위 1,841/1,841, 통합 Quick 54/54 PASS. API 정합성 새 단위 14개와 기존 요청 훅 회귀를 통과했다. 초기 Quick의 3열 편집 선택 전제 4건은 새 원안의 실제 왼쪽 장소 선택 단계를 거치도록 이관했으며 기존 저장/401/409 검증을 그대로 유지했다.

브라우저 검증은 실제 UI/JS/CSS와 명시된 API·계정·사진 fixture를 사용했다. 실제 계정 쓰기나 유료 모델 호출은 하지 않았다. 실제 휴대폰 하드웨어 전수 검사, 전체 Release Audit, 실제 지도 제공처·나루의 재인증으로 확대해 주장하지 않는다. 이 작업은 요청한 다섯 PR의 기능·원안 보존과 관련 회귀 검증이다.
