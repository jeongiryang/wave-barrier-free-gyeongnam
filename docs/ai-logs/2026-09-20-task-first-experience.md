# 여행 작업을 먼저 보여주는 화면과 문구 정리

- 작성자: jeongiryang / Codex
- 범위: 사용자가 승인한 화면·문구 감사의 개선 항목. 서비스 소개 디자인 제외.
- 출시 상태: PR CI 및 Actions 운영 배포로 확인한다.

## 목적과 변경

검색의 고정 로딩 문구를 미확인으로 바로잡고, 항목별 근거 없는 장소에는 0개 집계 대신 재조회와 오류 복구를 제공한다. 내 일정은 시간표와 저장·공유를 먼저 보여주고 보조 기능은 아래 펼침으로 이동한다. 나루는 담은 여행의 요약과 세 가지 다음 행동을 제공하며 시간·휴식·귀가·운영시간 점검을 일정 화면에서도 같은 계산으로 사용할 수 있다. 날씨와 비·휴무·피로 대비도 일정 점검에서 연결된다.

내 여행은 저장 목록과 새 여행 버튼부터 표시하며 기기 저장과 계정 저장을 구분한다. 커뮤니티는 실제 게시글을 먼저 표시하고 편집 가이드는 접는다. 장소 상세의 방문 후기·시설 제보·외부 후기를 방문자 기록에 모으고 공식 데이터의 한계 설명은 유지한다. 반복 안내와 장식용 영문·모호한 버튼 이름을 줄인다.

## 역할

- 사용자: 개선 범위와 전체 진행 승인.
- Codex: 실제 화면·코드 조사, 구현, 회귀·접근성·반응형 검사, PR 및 배포 확인.

## 로컬 검증

- TypeScript 통과, ESLint 오류 0 / 기존 이미지 경고 13.
- 단위 테스트 1501개 통과.
- 빌드와 성능 예산 통과: CSS gzip 69.82 KiB / 70, Planner 초기 JS 223.65 KiB / 270.
- 변경 화면과 기존 핵심 여정의 브라우저 테스트: 데스크톱·모바일, 1440/960/390 화면, 키보드 초점, axe 접근성, 여행 저장·복구·되돌리기, 재조회 실패 후 복구 검증. 전체 브라우저 범위는 PR CI에서 검증.
- 화면 캡처로 모바일 나루 요약의 줄바꿈 문제를 발견해 수정하고 넘침·높이 검사 추가.
- 전체 CI에서 발견한 커뮤니티 글 쓰기 버튼의 밝은/어두운 테마 대비 오류를 수정했다. 재배치된 영역의 펼침·언어 경계·지도 버튼 검증을 갱신하고, 새 일정 점검 조회에는 미확인 운영정보 fixture를 명시했다.
- 늦게 표시되는 점검 내용 때문에 키보드로 선택한 재조회 버튼이 밀리지 않도록 기존 초점 유지 훅을 연결하고 실제 작업 영역을 관찰한다. 사용자가 직접 스크롤한 경우에는 화면을 되돌리지 않는다. 위치 경계 검사는 시각 문자열의 부분 일치 대신 좌표 값 자체를 검사하도록 바로잡았다.
- 합성 API 응답 기반 회귀 테스트와 실제 운영 화면 확인은 구분한다.

## 제한

운영의 공개 글 ‘오류 확인 테스트’는 손영탁 작성으로 확인됐다. 현재 세션에는 수정·삭제 권한이 없어 삭제하거나 코드로 숨기지 않았다. 작성자 계정에서 정리해야 한다. 심사용 계정 생성은 사용자 보류 상태를 유지한다. 외부 교통 제공처 한도 해결이나 최종 공모전 제출을 이 변경의 완료로 주장하지 않는다.
