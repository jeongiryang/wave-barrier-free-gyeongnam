## 해안 영상 제작

`wave-coast-loop.mp4`는 정적 해안 일러스트를 FFmpeg로 편집한 8초·24fps·1280×720·H.264 무음 영상이다. 부드럽게 1→1.018→1배 확대·축소하며 인물과 파도가 독립적으로 움직이는 생성형 영상은 아니다.

별도 영상 생성 서비스는 호출하지 않았다. 현재 파일에는 음악·음성·개인정보가 없다. 실제 제품 기능 시연은 검증된 제품 화면을 별도로 촬영해야 한다.
