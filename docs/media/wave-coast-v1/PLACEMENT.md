# WAVE 화면별 미디어 배치안

2026-09-07 사용자 추가 요청 반영. #257·#259의 실제 구현 담당자가 RC 안정화 후 적용한다. 이 파일과 소재를 보관한 것은 웹 적용·배포 완료를 의미하지 않는다.

## 일관된 표현

- 기존 디자인 토큰·폰트·아이콘을 먼저 확인하고 색·모서리·그림자 규칙을 맞춘다. 해안 청록, 네이비, 따뜻한 아이보리를 보조 팔레트로 사용한다.
- 이미지 속 글씨로 기능을 설명하지 않는다. 제목·본문·CTA·단계 번호는 번역 가능하고 스크린리더가 읽는 HTML이다.
- 기능마다 큰 일러스트를 반복하기보다 실제 화면, 짧은 모션, 정적인 정보 카드의 밀도를 조절한다.
- 생성 일러스트는 분위기·가치 전달 자료이며 실재 관광지나 무장애 시설 인증 자료가 아니다.

## 움직임과 GIF

- 웹에서는 멈춤 제어가 가능한 짧은 MP4/WebM 또는 DOM/CSS 모션을 우선한다. GIF는 GitHub/문서 등 필요한 채널에서만 용량과 정지 대체 이미지를 확인해 추가한다.
- 기본은 정적 poster. 사용자가 재생을 선택하면 해당 섹션 하나만 재생한다. 반복 영상은 명확한 일시정지 버튼을 제공한다.
- `prefers-reduced-motion` 또는 데이터 절약 모드에서는 영상 source를 연결하지 않는다. 화면 밖 재생 중지, 전환 시 리스너 정리, 설정 변경 즉시 중지.
- 스크롤 가로채기, 강제 패럴랙스, 점멸, 자동 소리 없음. 서비스 진입과 핵심 기능은 영상 완료를 기다리지 않는다.
- 실제 기능 녹화에는 테스트 개인정보 제거, 보여주는 배포 SHA와 촬영일 기록. 필요한 자막·텍스트 설명 제공.
