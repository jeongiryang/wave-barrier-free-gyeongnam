## 미완료 및 제한

- Cloud Browser가 로컬 HTTP/파일 URL 열기를 보안 정책으로 차단했다. 다른 브라우저 경로나 정책 우회로 재시도하지 않았다.
- 실제 DOM 렌더링·스크롤·모바일·키보드·명암 대비·미디어 오류/환경설정 변화·콘솔 검증 미완료. 소스에 대응 로직을 구현했으나 실브라우저 PASS로 기록하지 않는다.
- MP4는 소스에서 렌더링한 소재다. 실제 웹 동작을 녹화한 영상이 아니다.
- WAVE 전체 lint/typecheck/unit/E2E/build·최신 HEAD CI·Preview·Production 테스트는 수행하지 않았다. 기존 앱을 수정한 PR이 아닌, docs/media 아래 소재 전달이다.
- LCP/CLS/INP·메모리/CPU·실기기·모바일 성능은 기존 소유 PR에 적용한 뒤 측정한다.
- 패키지 업로드와 이미지 자동 표시를 운영 사이트 적용 완료로 세지 않는다.
