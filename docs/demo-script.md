# W.A.V.E 3분 시연 동선

이 문서는 심사·리뷰 환경에서 로그인 없이 핵심 가치를 확인하는 표준 동선입니다.
Production 기준 주소는 `https://wave-barrier-free-gyeongnam.vercel.app`입니다.

## 시연 전 30초 점검

1. `/api/health`에서 `checkedAt`과 공급자 상태가 표시되는지 확인합니다.
2. 브라우저 확대 100%, 창 너비 1440px 또는 모바일 390px를 사용합니다.
3. 위치 권한은 허용하지 않아도 됩니다. 출발지를 직접 검색할 수 있습니다.
4. 로그인은 준비하지 않습니다. 여행 설계·지도·일정·공유는 비로그인 여정입니다.

## 0:00–0:25 · 문제와 서비스 범위

- `/`에서 “모두가 갈 수 있는 여행”이 아니라 **내 이동 조건에 맞고 근거를 확인할 수 있는 여행**을 만든다는 문장을 설명합니다.
- 경남 18개 시·군, 밝은/어두운 화면, 동작 감소, 키보드 사용을 짧게 보여 줍니다.
- `여행 계획 만들기`로 `/planner`에 들어갑니다.

확인 포인트: 지역 소개가 핵심 Planner를 가리지 않고, 건너뛰기 링크와 44px 조작 영역이 있습니다.

## 0:25–1:05 · 조건에서 근거 있는 장소까지

1. 플래너 상단 브리핑과 왼쪽 Journey Control 레일에서 현재 단계와 다음 행동을 먼저 확인합니다. 모바일에서는 같은 기능이 하단 4단계 탐색으로 바뀝니다.
2. 출발지를 `창원중앙역`으로 검색합니다.
3. 지역 `창원`, 테마 `자연·휴양`을 선택합니다.
4. 편의조건에서 `휠체어 이용`과 `걷기 불편`을 선택합니다.
5. 일반 추천과 `공식 편의근거를 더 확인해야 하는 장소`가 분리되는지 보여 줍니다.
6. 추천 카드의 일치율·확인 항목을 읽고 `편의시설 보기`를 엽니다.

확인 포인트: 공식 긍정 근거가 없는 장소는 일반 추천·자동 일정에 들어가지 않습니다. 알 수 없는 값은 0점이나 무료로 만들지 않습니다.

## 1:05–1:45 · 직접 편집하는 일정과 이동

1. 근거가 확인된 장소 두 곳을 `일정에 추가`로 이 기기 일정에 담습니다.
2. 출발일·도착일과 `하루 시작` 시각을 바꿉니다.
3. `앞`·`뒤` 버튼으로 같은 날의 방문 순서를 바꾸고 DAY 선택으로 날짜를 옮깁니다.
4. 자동차·대중교통·도보 비교에서 실제 확인 시간, 추정, 미확인을 구분해 읽습니다. 제공기관 응답 수가 실제 경로 수를 뜻하지 않는다는 안내도 함께 보여 줍니다.
5. 지도에서 장소·경로·주변 시설을 확인합니다.

확인 포인트: 드래그 없이 키보드 버튼만으로 순서를 바꿀 수 있고, 실제 경로와 직선거리 추정이 같은 표현을 쓰지 않습니다.

## 1:45–2:20 · 출발 준비와 상황 변화

1. `출발 전 확인` 카드에서 날씨·관광 집중률·교통·장소 편의근거 네 상태를 봅니다.
2. `확인됨 / 일부 확인 / 재확인 필요`와 각 출처·조회 시각·다음 행동을 설명합니다.
3. `최신 정보 확인`을 누릅니다.
4. `캘린더(.ics) 저장`으로 공유 URL과 재확인 안내가 들어간 일정을 저장합니다.
5. 아래 날씨·상황 대응에서 강수나 혼잡 예측이 일정에 주는 영향과 대안을 확인합니다.

확인 포인트: 관광 집중률은 예측값이며 실시간 방문자 수가 아님을 표시합니다. 조회 실패는 성공 상태로 바뀌지 않습니다.

## 2:20–3:00 · 여행자 경험과 데이터 경계

1. 장소 상세에서 `이 장소의 여행자 현장 이야기`를 확인합니다.
2. `/community`에서 `[샘플]`과 실제 이용자 글의 표시 원칙을 설명합니다.
3. 여행 후기 작성 화면의 출입구·엘리베이터·화장실 등 구조화 항목을 보여 줍니다. 실제 게시에는 로그인이 필요합니다.
4. 현장 제보는 작성자 1명의 경험이고 공식 편의근거 점수에 합산되지 않는다는 안내로 마칩니다.

확인 포인트: 공식 데이터, 여행자 제보, W.A.V.E 추정/예측이 문구·색·저장 구조에서 분리됩니다.

## 실패 시 대체 동선

| 상황 | 화면에서 확인할 것 | 시연 대안 |
| --- | --- | --- |
| 관광 API 지연 | 오류 안내, 공급자 이름, `공식 데이터 다시 조회` | 오류가 추천으로 위장되지 않음을 설명한 뒤 다시 조회 |
| Kakao 지도 키 미설정 | 키 상태, Leaflet 위치 미리보기 | 주소·좌표 기반 대체 지도와 Kakao 외부 확인 링크 사용 |
| 대중교통 승인/응답 없음 | `승인 상태 확인`, `시간 정보 없음`, 공급자 상세 | 직접 확인된 자동차/버스만 읽고 KORAIL·Kakao 외부 확인으로 이동 |
| 날씨 날짜 범위 밖 | `재확인 필요`, 현재 상황과 예보의 구분 | 날짜를 가까운 날로 바꾸거나 `최신 정보 확인` 실행 |
| 커뮤니티 쓰기 불가 | 공개 읽기와 `[샘플]` 표기 | 로그인 없이 공개 글·구조화 제보 표현만 확인; 게시 성공을 가장하지 않음 |
| 공유 저장 실패 | 캘린더 미생성 오류 안내 | 현재 일정 편집·여행일지 초안 링크를 보여 주고 재시도 |

## 접근성 빠른 확인

- 키보드: 본문 건너뛰기 → 여행 조건 → 여행지 → 이 기기 일정·이동 → 출발 전 확인 순서
- 모바일: 390px에서 수평 넘침 없이 주요 버튼 44px 이상
- 동작 감소: 환경설정 `동작 효과`를 `효과 줄임`으로 전환
- 테마: 밝은/어두운 화면에서 상태 배지가 색상 외 텍스트를 함께 사용
- 입력 오류: 로그인·가입 제출 시 오류 입력으로 초점 이동 및 설명 연결
