# 공모전 심사용 로그인

## 제출 선택: 로그인 불필요

W.A.V.E의 기능심사 핵심 흐름은 **별도 로그인 없이 전부 이용할 수 있다.**

- 여행 조건 설정
- 공식 관광정보 기반 추천
- 추천 여행지 상세 확인
- 지도와 출발·도착 변경
- 도보·자전거·대중교통·자동차 이동 비교와 카카오맵 fallback
- 일정 구성과 공유 링크 생성
- 날씨·혼잡·주변 여행정보 확인
- 사진 기반 코스 복원
- 커뮤니티 게시글 읽기

공모전 안내는 별도 로그인 없이 서비스 이용 및 테스트가 가능한 경우 `로그인 불필요(테스트 계정 생성 불필요)`를 선택하도록 안내한다. 따라서 제출 양식에는 **로그인 불필요**를 선택한다.

커뮤니티의 글 작성·댓글·좋아요·신고처럼 계정 소유권이 필요한 참여 기능만 Neon Auth 로그인을 요구한다. 이 기능들은 여행 설계와 기능심사를 막지 않는 부가기능이며, 공개 게시글 읽기는 로그인 없이 가능하다.

## 심사 계정을 별도로 만들지 않는 이유

공모전 지정 계정은 `별도 계정 생성하여 로그인` 방식을 선택할 때만 필수다. W.A.V.E는 그 방식에 해당하지 않으므로 심사용 개인·공용 계정을 제출하지 않는다.

고정 비밀번호나 테스트 인증정보를 저장소·Production 환경변수·CI 로그에 넣어 계정을 억지로 만드는 방식도 사용하지 않는다. 이는 심사에 필요하지 않은 인증정보를 추가로 운영하는 것보다 안전하다.
