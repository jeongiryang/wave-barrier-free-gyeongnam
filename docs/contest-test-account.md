# 공모전 심사용 로그인

W.A.V.E의 여행 설계·추천·지도·길찾기·날씨 확인은 로그인 없이 테스트할 수 있다.

커뮤니티의 글 작성·댓글·좋아요처럼 로그인 후 기능까지 심사할 경우에는 공모전 안내의 **이메일 계정 형식**을 사용한다.

- 예정 ID: `openapi@example.com`
- 지정 비밀번호: 공모전 안내문에 명시된 `2026openapi!`
- 용도: 심사 전용. 개인 계정을 제출하지 않는다.

> 저장소나 Production 환경변수에 심사용 비밀번호를 비밀정보처럼 복제하지 않는다. 실제 계정 생성은 Production Neon Auth에 직접 등록한 뒤 로그인 성공을 확인해야 완료로 처리한다.
