# 공모전 심사용 로그인

## 제출 선택: 로그인 불필요

W.A.V.E의 기능심사 핵심 흐름은 **별도 로그인 없이 전부 이용할 수 있다.**

- 여행 조건 설정
- 공식 관광정보 기반 추천
- 추천 여행지 상세 확인
- 지도와 출발·도착 변경
- 도보·자전거·대중교통·자동차 이동 비교와 카카오맵 fallback
- 일정 구성과 공유 링크 생성
- 날씨·혼잡·주변 여행정보 확인
- 사진 기반 코스 복원
- 커뮤니티 게시글 읽기

공모전 안내는 별도 로그인 없이 서비스 이용 및 테스트가 가능한 경우 `로그인 불필요(테스트 계정 생성 불필요)`를 선택하도록 안내한다. 따라서 제출 양식에는 **로그인 불필요**를 선택한다.

커뮤니티의 글 작성·댓글·좋아요·신고처럼 계정 소유권이 필요한 참여 기능만 Neon Auth 로그인을 요구한다. 이 기능들은 여행 설계와 기능심사를 막지 않는 부가기능이며, 공개 게시글 읽기는 로그인 없이 가능하다.

## 선택형 심사 계정

핵심 기능은 로그인 없이 이용할 수 있다. 계정 저장·동행 관리·커뮤니티 작성까지 확인할 심사위원은 소유자가 지정한 기존 `openapi` 계정을 선택적으로 사용할 수 있다. 로그인 정보는 이 문서나 저장소에 기록하지 않는다.

Production 마이그레이션은 정확한 `openapi` 사용자 ID가 한 명 있는지 확인한 뒤, 그 계정에만 예시 여행 5건·`[시연]` 커뮤니티 글 2건과 댓글 1건을 한 번 삽입한다. 편의 선택이 아직 없다면 시연 선택 1건을 추가한다. 기존 계정 자료는 덮어쓰지 않는다. 공개 예시 일정의 계획과 공식 장소 ID만 복사하며 관광지·시설·날씨·경로 응답이나 실제 방문 기록은 저장하지 않는다.

사진 코스의 원본은 계정에 저장하지 않는 기능이다. AI 생성 공개 예시 사진 3장은 `/photo-course`의 시연 버튼으로만 제공하고, 직접 촬영 사진을 `openapi` 계정의 업로드로 가장하지 않는다.
