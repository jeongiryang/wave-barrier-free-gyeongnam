# 나루 연구실 주 서버 복귀 — 2026-09-30

사용자가 연구실 GPU 사용 재개를 알리고 최우선 연결을 승인했다. 기존 WAVE 전용 A6000 한 장을 사용하며 다른 연구실 작업과 공용 Ollama는 변경하지 않는다.

| 우선순위 | 서버 | 모델 |
| --- | --- | --- |
| 1 | 연구실 RTX A6000 | gemma4:26b |
| 2 | 교수님 TITAN RTX / LM Studio | gemma-4-26b-a4b-it |
| 3 | Windows RTX 4070 Ti / Ollama | gemma4:12b |

`WAVE_AI_*`, `WAVE_AI_FALLBACK_*`, `WAVE_AI_SECONDARY_*`에 각 HTTPS 게이트웨이·모델·토큰을 설정한다. 비밀값은 서버 전용 환경에만 저장한다. 세 번째 설정을 생략하면 기존 두 서버 구성이 유지된다.

서버마다 한 번만 요청하며 통신 실패·시간 초과·요청 한도 또는 건강 확인의 미준비 상태에서 다음 순서로 넘어간다. 응답을 전달하기 시작한 스트리밍, 인증 실패, 잘못된 모델 출력, 사용자 취소는 다른 서버에서 재실행하지 않는다. 전체 제한은 상태 확인 8초, 대화 45초이며 중간 서버는 각각 상태 확인 2.5초 / 대화 15초로 제한한다. 중복 게이트웨이는 한 번만 방문한다. 로그의 `route`는 primary/fallback/secondary만 기록하고 질문·주소·토큰은 기록하지 않는다.

연구실의 기존 Ollama·모델·게이트웨이 사용자 서비스를 복구하고 자동 시작을 활성화했다. 게이트웨이를 현재 코드에 맞췄고 예열 문맥도 실제 추론과 같은 16K로 맞췄다. 전용 Tailscale 네트워크는 기존 구성을 유지한다.

실제 연구실 HTTPS 게이트웨이에서 현재 나루 처리기를 사용한 한국어 작업 7건(조건, 일정 생성, 체류, 되돌리기, 점검, 삭제, 문의 도구)이 모두 통과했다. 응답 0.62~2.71초. 합성 행사 포스터의 날짜·시간 추출은 2.79초에 통과했다. 다른 GPU 3장은 사용하지 않았다. 이 결과는 모델/처리기 검증이며 브라우저 여행 완주나 Production 전환 완료를 대신하지 않는다.

운영 전환은 필수 CI 성공 및 CD 배포 후 확인한다. 일일 점검도 연구실·TITAN RTX·4070 Ti의 실제 적재 상태와 운영 응답을 구분한다. 이전 두 서버 환경으로 되돌릴 수 있도록 각 게이트웨이 설정은 개인 비밀 저장소에 보존한다.
