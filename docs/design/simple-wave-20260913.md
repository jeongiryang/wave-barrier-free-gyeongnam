## 구현 기본값

PC는 1024px부터 보조 영역을 나란히 사용하고, 모바일은 한 화면과 뒤로가기로 전환한다. 기본 색은 흰색/짙은 회색/짙은 청록색, 본문 16px, 조작 영역 44px 이상이다. 검색에는 날짜·편의·활동을 강제하지 않는다. 선택한 필수 시설은 자동 해제하지 않는다. 나루 캐릭터를 유지하고 중복 CTA·큰 도구 메뉴를 제거한다. 특정 편집은 즉시 적용+되돌리기, 새 장소·전체 일정은 제안 승인 후 적용한다. 공유는 새 링크만 자동 갱신하며 구형 링크의 스냅샷과 30일 보관을 보존한다. 민감한 편의의 계정 저장과 공개 여행 내용은 분리한다.

무거운 Actions는 최종 후보에 모으고 실패 또는 새 변경으로 필요한 검증만 반복한다. 무료 DSW 모델과 기존 Production CD 경로를 사용한다.

## 화면과 동작

- 소개는 설명과 풍경 사진의 첫 화면, 지역 사진 격자, 여행 설계 사용 예, 나루 소개의 네 구역이다. 지역은 통영·거제·남해·진주·창원·하동부터 보여주고 나머지는 펼친다. 가로 필름 대신 제자리에서 가볍게 나타나며 동작 감소 설정을 따른다. 사진과 출처는 카드 전체 비율을 유지한다.
- 여행 설계의 기본 화면은 `여행지 찾기`와 `내 일정`이다. 지역을 고르면 검색하며 날짜는 일정에 담은 뒤 정한다. 시설과 활동을 고르지 않아도 둘러볼 수 있다. 검색 결과는 사진·이름·담기와 필요한 시설 근거만 남긴다.
- 필수 시설이 모두 확인된 장소, 일부 시설이 미확인인 후보, 명시적으로 필요한 시설이 없는 장소를 구분한다. 미확인 후보를 담을 때는 실제 근거와 방문 전 확인에 동의해야 한다. 활동을 넓히는 버튼은 시설 조건을 유지하며 사용자가 누를 때만 활동 선택을 해제한다.
- 일정의 장소 편집은 하나의 수정 창에서 날짜·체류·휴식·고정 방문을 초안으로 정하고 적용한다. 같은 날의 앞/뒤 이동 버튼을 제공하며 드래그를 강제하지 않는다. 출발 정보와 추가 여행 도구는 필요한 때 펼친다.
- 나루는 캐릭터 진입점을 유지한다. 대화에서 실제 조회 결과를 보여주며 명확한 편집은 같은 여행 상태에 적용하고 되돌릴 수 있다. AI가 제안한 새 장소나 전체 일정은 먼저 검토한다. 포괄적인 `열기 / 실행` 카드, 반복 AI 라벨, 도구 버튼 벽은 제거했다. 마이크는 실제 입력 음량과 인식 중 문장을 보여주고 전송 전 확인한다.
- 현재 여행은 같은 기기에서 복원한다. 새 여행은 기존 여행 백업에 성공해야 초기화하며 현재 탭의 시설 선택을 비운다. 별도로 저장한 개인 조건은 지우지 않는다. 내 여행 저장은 동일 여행 ID를 갱신하며 첫 저장 뒤 변경도 반영한다.
- 새 공개 링크는 같은 주소에서 최신 허용 여행 내용을 보여주고 소유자가 중단할 수 있다. 구형 링크는 기존 스냅샷과 만료일을 유지한다. 공개 내용에 개인 시설 선호·메모·GPS 출발지를 추가하지 않는다. 복사가 막혀도 이미 만든 링크를 직접 열거나 다시 복사할 수 있다.

## 검증 범위와 표시 언어

검증 중 구현된 항목의 체크는 배포 완료 표시가 아니다. 최종 PR의 전체 브라우저 shard와 필수 validate, main CD, 실제 운영 여정은 아래 완료 기준으로 별도 추적한다.

새 여행 설계 조작부는 한국어를 기본으로 한다. 기존 설정의 부분 번역 안내를 유지하며 전체 다국어 지원으로 홍보하지 않는다. 영어를 제공하는 데이터·지도·오류 안내와 한국어 원문을 구분하고 화면의 실제 언어를 선언한다. 테스트는 과거 5단계·가로 카드 선택자를 새 2화면 흐름으로 바꾸되, 필수 시설·날짜·저장·초점·실패 복구 검증을 보존한다.

로컬 브라우저에서 제공처 실패, 늦은 응답, 시설 부재, 저장·공유 오류, 새 여행 백업, 나루 제안·되돌리기, 음성 생명주기, 320–1440px 배치와 키보드·대비를 검사한다. 합성 API 검사와 실제 관광 데이터·DSW 모델 응답은 구별해 기록한다. Vite의 소스 갱신에 따른 재탐색을 테스트 실패로 섞지 않도록 소스 수정 묶음 사이에 브라우저 검사를 실행한다.

최종 로컬 후보는 단위 1,210개, 타입·lint·보안 감사·빌드·기존 성능 예산을 통과했다. 단계별 브라우저 검증과 실제 나루·저장 확인 범위, 미실행 운영 검증은 [AI 작업 기록](../ai-logs/simple-wave-20260913.md)에 구분했다. PR의 전체 CI와 Production 완료 여부는 해당 PR의 후속 배포 기록을 확인한다.
