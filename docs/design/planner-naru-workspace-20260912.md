## 상태와 접근성

- 대화 작업 공간은 기존 플래너 subtree를 고정 portal target으로 이동한다. 열기/닫기로 편집 컴포넌트를 다시 만들지 않는다.
- 출발 확인 작업 공간도 처음 연 뒤 유지해 여행비 초안이 다른 도구 이동으로 사라지지 않는다. 당일 진행 메모리는 공통 여행 상태에 두어 저장 실패 시에도 같은 방문 기록을 사용한다.
- 지역 변경은 기존 일정에 추가/새 여행 결정이 성공한 다음 나머지 편의·활동을 반영한다. 취소는 현재 조건을 보존한다.
- 나루의 변경 제안은 현재 여행 revision과 실제 장소 ID를 재검사한다. 필요한 편의를 자동으로 제거하지 않으며, 고정 약속 제약과 최신 변경 기준의 되돌리기를 유지한다.
- 입력 중 취소/닫기/새 요청의 sequence를 구분한다. 늦은 이전 응답이 새 작업의 결과나 로딩 상태를 덮어쓰지 않는다.
- 모바일 대화는 native modal dialog, 넓은 화면은 modeless dialog. IME Enter·Escape·초점 복귀·44px 버튼·모션 축소를 지원한다. 비교 후 확인 버튼으로 돌아와 가려진 동작을 남기지 않는다.
- 외부 메시지를 자동으로 보내지 않는다. 나루의 공유 도구도 원래 공유 기능의 확인 화면을 사용한다.

## 로컬 모델

[운영 구성](../../server/assistant/README.md)에 전용 실행기, 서비스, 모델과 검증 절차를 기록했다. DSW의 기존 GPU 작업과 공용 Ollama는 보존한다. 생성 모델 호출은 별도 유료 API 없이 운영한다. 고정 HTTPS 연결과 배포 환경 변수가 확인되기 전에는 Production AI 운영 완료로 표시하지 않는다.

초기 실측: GPU 전용 실행기에서 동일 출처 API를 통한 한국어 조건 요청이 7.3초에 유효한 settings 제안을 반환했다. 이 한 사례는 전체 품질/부하 검증을 대신하지 않는다. 최종 테스트 수와 배포 주소는 PR의 검증 기록을 따른다.

## AI 로드맵 #476 요구 보존

우선 구현 범위는 사용자 요청의 필수 AI 기능인 P1 네 항목이다. 생성 모델은 의도를 제한된 작업으로 해석하고, 실제 여행 도구가 공식 데이터와 기존 일정을 처리한다. 비교 이유나 시설 수치를 모델이 새로 만들어 사실처럼 제시하지 않는다.

| 항목 | 상태 | 구현 또는 보존 근거 |
| --- | --- | --- |
| P1-1 자연어 조건 해석 | IMPLEMENTED | 한국어 요청에서 지역·편의·활동 작업을 제안하고 확인 후 반영. 날짜·기간 도구 연결, 기존 편의 유지, 기존 일정이 있는 지역 변경의 취소 지원. |
| P1-2 출발 전 근거 설명 | IMPLEMENTED | 대화에서 장소별 확인·미확인 편의, 실제 출처·조회 시각을 모아 표시하고 날씨·이동 검토와 원문·문의 도구 연결. 시설 유무를 생성하지 않음. |
| P1-3 부분 일정 재계획 | IMPLEMENTED | 실제 장소 ID의 대안 도구 연결, 고정 약속·날짜·순서·필수 편의 보존, 사용자가 선택한 교체와 최신 변경 되돌리기. |
| P1-4 장소 비교 설명 | IMPLEMENTED | 대화에서 실제 후보 2~3곳의 편의·미확인 정보·출처를 나란히 확인. 일정에 넣거나 뺄 때 확인 작업으로 복귀. |
| P2-5 동행 조정 | DEFERRED-IDEA | 기존 동행 편의·합류 도구는 대화에서 사용 가능. 모델이 동행자 의견을 조율하는 추가 기능은 열린 #476에 보존. |
| P2-6 여행 중 음성 안내 | DEFERRED-IDEA | 선택적 음성 입력과 기존 당일 방문 안내 도구는 제공. 상시 음성 안내·자동 행동은 이번 범위에서 제외하고 #476에 보존. |
| P2-7 쉬운 여행 브리핑 | DEFERRED-IDEA | 기존 오프라인·공유·출발 요약 도구 제공. 생성형 개인 브리핑 고도화는 #476에 보존. |
| P2-8 이미지·문서 OCR | DEFERRED-IDEA | 민감 정보 처리와 원문 검증이 필요한 추가 모델 입력이므로 #476에 보존. |
| P3-9~12 제보·후기·여행집·번역 보조 | DEFERRED-IDEA | 여행 설계 P1과 분리해 #476의 후속 아이디어로 유지. 기존 제품 기능의 AI 구현 완료로 계산하지 않음. |

#476은 후속 기능이 남아 있으므로 이 변경만으로 전체 종료하지 않는다. #475의 공유 서버 조사 자료와 인증 정보는 실행 지시로 취급하지 않았으며, Owner가 직접 승인한 전용 설치 범위만 실행했다.
