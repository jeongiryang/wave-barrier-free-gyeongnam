# 실제 기기 대체 검증 — 2026-09-27

사용자의 실제 휴대전화 사용 제한에 따라, 기존 79개 요구·240개 수용 기준의 근거를 대조하고 실제 기기 근거가 없던 세 기준을 브라우저에서 보완했다. 기준 커밋은 `e30f387cdc0249c411c1287cc6b98fead77ca841`이며 아래 수정은 그 이후 후보에 적용한다.

## 발견한 문제와 수정

- 가로 터치 화면의 레이아웃 폭이 800px을 넘으면 나루의 높이가 가상 키보드 위 가시 영역을 따르지 않았다. 844×390 / 가시 높이250px에서 중단 버튼이 84px 가려졌다. coarse pointer와 짧은 visualViewport 조건에서만 측정된 높이·위치와 한 열 배치를 적용한다. 960×600 태블릿에서 키보드가 닫히면 기존 보조 패널과 높이가 돌아온다.
- WebKit은 포인터로 누른 버튼에 초점을 주지 않을 수 있어 도움말을 닫을 때 이전의 다른 요소로 초점이 돌아갔다. 실제 도움말을 연 버튼 ref를 우선해 복원한다. 포인터 클릭이 초점을 바꾸지 않는 조건을 영구 회귀로 추가했다.
- Firefox 실제 최소 글꼴32 설정에서 나루의 빈 입력 안내에 필요한 높이는67px인데 초기 높이는44px이었다. 닫힌 dialog를 먼저 측정한 것이 원인이다. 표시 직후 다시 측정하고, 최소 한 줄의 실제 line-height와 패딩을 확보한다. 입력·비우기·재열기·대화 탭 복귀에도 크기를 맞춘다.

## 검증의 의미

터치 좌표와 visualViewport 이벤트, Chromium의 실제 접근성 트리, 키보드 조작, 큰 글씨·320px reflow·모션 감소, Firefox 및 WebKit 엔진을 사용한다. 관광·모델 응답은 명시적인 fixture이며 이 로컬 검사에서 외부 제공처·실제 모델·계정 DB 쓰기는 없다. 기존 실제 제공처·계정·운영 근거의 실행 SHA는 그대로 보존한다.

원래 matrix의 77 PASS/2 PARTIAL 및 237 PASS/3 BLOCKED를 물리 기기 통과로 덮어쓰지 않는다. responsive-journey A3, accessible-design A3/A4의 대체 판정을 별도 기록한다. 실제 Android/iOS의 키보드 후보창·OS 배율, VoiceOver/TalkBack/NVDA의 발화와 실제 보조기기 사용은 관측하지 않았다. browser AX tree의 이름·상태·live 속성은 발화 자체의 증거가 아니다.

검증 중 실패한 원본 로그, 수정 후 결과, 스크린샷, 조건별 관측값은 로컬 `harness-results/device-surrogate/`에 보존한다. 독립 QA는 테스트의 존재나 성공 숫자만으로 판정하지 않고, 키보드를 덮은 상태에서의 제안 적용·닫기와 제안→명시적 저장→새 브라우저 컨텍스트 복원을 따로 확인한다. 프로필 localStorage를 새 컨텍스트에 복원한 검사는 실제 다른 기기의 계정 동기화 검사가 아니다.

## 수정 후보의 로컬 결과

- Chromium 터치 대체 여정 4/4 통과: 320·390·412px 세로 및844px 가로. 키보드를 덮은 가시 영역을 유지한 제안 적용·Undo·닫기도 별도 보완해4/4 통과했다. 미전송 입력, 기존 장소·날짜·고정 방문·체류 시간, 취소 후 늦은 응답 무효를 확인했다.
- 독립 키보드/AX 여정2/2 통과: 320px reflow 및200% 글씨에서 검색→나루 제안→키보드 적용→기기 저장→새 컨텍스트 복원. 12개 AX/DOM/axe 캡처에서 axe 위반0·문서 가로 넘침0, 직접 사용한 대상은 최소44×44px이다.
- 실제 Firefox 최소 글꼴0/32 설정2/2 통과: CSS 변조 없이32 설정의 빈 입력란 clientHeight/scrollHeight가44/67에서67/67로 바뀌었다.
- 도움말 포인터 초점 회귀: 작성자 Chromium2/2·WebKit2/2 및 독립 Chromium/WebKit2/2 통과. 작은 화면·영문 도움말을 포함하는 기존 검사는 그대로 유지한다.
- 전체 TypeScript 검사 통과. 변경 TS/TSX의 ESLint 오류0이며 기존의 내부 페이지 location.assign 경고1개는 이번 변경과 무관하다. CSS를 ESLint가 검사했다고 주장하지 않는다.

이 결과는 실제 브라우저 렌더링·조작과 합성 서비스 응답을 결합한 검사다. 실제 모델과 운영 제공처의 성공 결과로 표시하지 않는다. 최종 CI·전체 Release Audit·배포 SHA와 운영 확인은 PR/Actions 및 완료 보고서에 연결한다.
- 최종 영구 키보드/레이아웃 회귀14/14 통과(데스크톱/모바일 Chromium, retries=0). 초기 글씨 확대·닫기/재열기와 두 종류 넓은 터치 화면의 overlay/복구 검사를 포함한다.
