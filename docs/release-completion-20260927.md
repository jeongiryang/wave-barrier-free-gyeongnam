# 9월 30일 마감 기능·프론트 보완

밤 테마·메뉴·달력(#715)과 프론트 이력·전문 하네스 책임 보강(#716)을 한 후보로 결합한다. 기능설명서의 실제 약속을 기준으로 회귀를 수정하고 근거를 검증한다.

## 현행 디자인 기준

Noto Sans KR 본문과 한정된 손글씨 장식을 유지한다. 밤 테마 나루·달력, 단일 상단 메뉴, 첫 방문부터 바로 읽히는 화면이 이번 후보 기준이다. 인트로·설치 안내·사진 재생 버튼 제거와 정책 화면의 출처 통합은 #715의 최신 변경으로 기록한다. 이전 #709의 흰 나루·인트로를 현행 규칙으로 강제하지 않는다. 사진은 정책 화면에서 제목·원본·제공처에 도달해야 하고 공식 관광사진과 AI 야경 장식을 구분한다.

## 기능설명서와 실제 확인

31쪽 제출 문서의 실제 약속을 기준으로 검토한다. 대여기관·긴급 연락처 등록부·지역 배경음·경남 말투·토큰 스트리밍의 미노출을 자동으로 제출 필수 미구현이라 부르지 않는다. 현장 자료 확대와 방문 경험 축적은 발전계획과 현재 구현을 구분한다.

8쪽의 미확인 시설 좌표 생성 금지에 맞춰 임의 마커와 대체 중심점을 제거했다. 기존 공식 공중화장실 API로 축제 장소 **주변의 확인된 좌표**를 표시하고 출처·기준일·직선거리를 함께 제공한다. 쉼터/축제장 내부 배치·현재 운영은 근거 없이 보장하지 않는다. 닫힌 요청은 취소하고 늦은 응답을 폐기한다.

첫 paint·메뉴 초점 28개는 로컬 브라우저에서 통과했다. 초기 날짜 병렬 검사는 trace 파일의 반복 새로고침과 Vite WebSocket `net::ERR_NO_BUFFER_SPACE`로 중단됐다. 같은 저장·복원·수정·공유 왕복은 단독 16.6초에 통과했다. 개발 로그에서 HTML 증거 파일을 저장할 때마다 reload가 발생함을 확인해 watcher 원인을 수정했다. 오류 필터링·timeout 연장 없이 수정 후 브라우저와 Linux Release Audit으로 판정한다.

남은 검증은 전체 Release Audit, 실제 나루의 제안→적용→후속 수정→되돌리기, 제출 API/화면의 실제 근거와 운영 확인이다. 테스트 파일·코드 존재나 과거 통과를 79개 요구의 최종 완료로 바꾸지 않는다.

## 최종 후보의 정적·빌드 근거

전체 단위 1,701개 통과 후 마지막 날짜 보호 회귀를 추가하고 영향받는 단위·서버 96개를 통과했다. 최종 전체 집합은 CI에서 검사한다. 타입 검사, 린트(전체 오류 0·기존 경고 34개, 변경 파일 오류 없음), Vercel 빌드가 통과했다. DOM에서 사라진 상단 요소의 CSS 선택자 41개를 정리했고 유지하는 규칙의 순서와 선언은 그대로다. 성능 한도를 올리지 않고 CSS gzip 95.75/96KiB, 랜딩 초기 JS gzip 146.10/155KiB, 플래너 초기 JS gzip 269.14/270KiB, 최대 JS chunk gzip 71.25/110KiB를 확인했다. 운영 지연·전체 기능 검증과는 별도 근거다.
