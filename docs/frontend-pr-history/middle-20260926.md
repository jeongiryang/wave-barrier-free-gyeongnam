## 범위와 판정 방법

전체 목록의 REST 모집단의 2026-09-12T00:00:00Z 이후 닫힌 모집단 중 번호 548–667에 해당하는 **66개 전부**를 조사했다. 이 중 원PR 자체 MERGED 16개, CLOSED·unmerged 50개다. 검색 API의 불완전한 51개 결과는 모집단으로 사용하지 않았다. 원PR의 실제 파일 diff, 본문, 일반댓글을 확인하고 중복된 통합 알림은 통합 근거 1건으로 묶었다. **일반댓글 64개, 정식 리뷰 0개, 인라인 리뷰 0개**이며 작성자의 CI/현장 샘플 보고는 독립 리뷰 승인으로 바꾸지 않았다.

각 항목의 **명시 근거**는 해당 PR 본문·diff·댓글 수준의 요구/제한이다. **확인 기준**은 그 기록을 현재 화면에 적용하기 위한 QA 추론이며 추가 제품 요구나 모든 경우의 통과 보장이 아니다. **현재 상태**는 현재 소스 연결과 Git 변경 이력에 대한 정적 판정이다. 브라우저, live API, local-llm, 실기기, 테스트를 이번 조사에서 실행하지 않았다. 과거 CI/fixture/샘플/스크린샷을 현재 통과로 재사용하지 않는다. 원PR의 `mergeCommit` 필드는 unmerged PR에도 값이 있을 수 있으므로 status는 `mergedAt`으로 판정했다.

원PR의 전체 변경 파일 목록을 확인하고, 이 부록에는 관련 대표 경로와 전체 파일 diff 링크를 남겼다. 바이너리 파일은 텍스트 patch가 없으므로 별도 공백으로 기록했다. 원PR 당시의 지적이 후속 통합에서 수정된 경우 현재 열린 결함으로 재분류하지 않았다.
