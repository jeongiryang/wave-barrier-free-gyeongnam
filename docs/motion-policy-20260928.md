# 2026-09-28 화면 배경·모션 변경

사용자는 현재 배포판의 기능 카드 8개 뒤 검정 사각 배경 제거와, 기기의 동작 줄이기 설정 때문에 사이트 애니메이션이 꺼지는 처리 제거를 직접 요청했다. 기준은 당시 Production과 main에 공통으로 배포된 `7a8ec1db28d375b405b49053e0799b9b0df2a0ae`이며 이전 PR 검토용 통합본을 배포하지 않는다.

- 기능 카드 묶음의 배경색만 제거한다. 개별 카드의 배경·테두리·문구·링크는 보존한다.
- 초기 HTML 설정과 React 환경설정은 `data-motion="full"`을 사용한다. OS 미디어 쿼리가 CSS 애니메이션·전환, 사진 전환, 나루 대화, 지역 카드 등장과 인트로 효과를 자동 중지·축소하지 않는다.
- 인트로 건너뛰기·Escape, 세션 내 재생 완료 기억, 렌더러 실패 시 종료, 화면 밖·숨긴 탭의 재생 중지는 유지한다. 음성 재생·데이터 절약 조건은 이 변경 대상이 아니다.
- 이전 테스트의 OS 연동 정지 기대값은 새 동작에 맞게 갱신한다. 핵심 브라우저 여정은 OS reduce 상태에서도 full 모드·실제 애니메이션 이름/시간·배경 투명화와 키보드 건너뛰기를 함께 확인한다.

이것은 사용자가 요청한 모션 정책 변경이다. OS 동작 줄이기 선호를 자동 반영하던 기존 정책은 더 이상 제품 요구가 아니며, 이 변경을 전수 접근성 인증으로 표현하지 않는다.
