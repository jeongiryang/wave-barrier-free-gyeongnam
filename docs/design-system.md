# W.A.V.E 디자인 시스템

경남 무장애 관광 플랫폼 W.A.V.E의 화면을 만들 때 따르는 기준입니다.
새 화면이나 컴포넌트를 만들 때는 여기 있는 토큰을 먼저 찾아 쓰고,
없을 때만 새 값을 만들되 이 문서에 함께 추가합니다.

기본 색상·레이아웃 토큰은 [`app/globals.css`](../app/globals.css)에, 공통 간격·모서리·그림자·모션 토큰과 접근 가능한 공통 패턴은 [`app/styles/design-system.css`](../app/styles/design-system.css)에 선언합니다. 도움말·모션 감소·터치 영역·반응형 안전 영역 보정은 [`app/styles/experience-accessibility.css`](../app/styles/experience-accessibility.css)가 담당합니다.

---

## 1. 원칙

이 서비스는 "갈 수 있는지"를 확인하러 오는 사람이 씁니다. 그래서 화면의 판단 기준도
보기 좋음보다 **읽히는지**가 먼저입니다.

1. **근거를 가리지 않는다.** 사진 위에 정보를 얹을 때는 항상 스크림을 깐다.
   배경 이미지가 늦게 뜨거나 밝아도 글자가 사라지면 안 된다.
2. **대비는 타협하지 않는다.** 본문·라벨은 배경 대비 4.5:1 이상.
   큰 제목(24px 이상 굵은 글자)과 비활성 요소만 3:1까지 허용한다.
3. **색만으로 상태를 말하지 않는다.** 혼잡도·연결 상태는 색과 함께
   글자나 아이콘으로도 표시한다.
4. **움직임은 끌 수 있어야 한다.** 모든 애니메이션은
   `prefers-reduced-motion: reduce`에서 정지하거나 한 프레임으로 대체된다.
5. **조작 대상은 최소 44px.** 버튼·링크·입력의 터치 영역 기준.

## 2. 색 — Deep Ocean

파도의 심연에서 포말까지를 하나의 색상 대역(168°~206°)으로 묶었습니다.
주요 액션에 쓰는 파랑은 국제 접근성 심볼(ISA)의 파랑 계열과 같은 자리에 있어,
서비스의 목적과 색이 어긋나지 않습니다.

| 토큰 | 값 | 쓰임 | 흰 글자 대비 |
| --- | --- | --- | --- |
| `--abyss` | `#04202f` | 인트로 배경, 가장 깊은 면 | 15.9:1 |
| `--ink` | `#06304a` | 본문 글자, 짙은 카드 배경 | 12.6:1 |
| `--ink-soft` | `#0f4f70` | 보조 제목, 라벨 | 7.7:1 |
| `--blue` | `#0a6baf` | 주요 액션, 링크, 강조 | 5.2:1 |
| `--blue-dark` | `#074f84` | 주요 액션 hover | 7.4:1 |
| `--surf` | `#17b8d4` | 그라데이션·글로우 전용 (작은 글자 금지) | 2.0:1 |
| `--mint` | `#6fe3d0` | 짙은 면 위의 포인트, 성공 신호 | — |
| `--sky` | `#e6f4fb` | 옅은 강조 면 | — |
| `--paper` | `#f2f9fc` | 카드 안쪽 보조 면 | — |
| `--surface` | `#eef7fc` | **모든 페이지가 공유하는 기본 배경** | — |
| `--line` | `#cbe1ed` | 테두리, 구분선 | — |
| `--muted` | `#52788c` | 보조 설명 글자 | 4.6:1 (흰 배경) |

**상태색은 색상 리매핑에서 제외합니다.** 혼잡도(여유·보통·붐빔·매우 붐빔)와
경고·오류는 초록·앰버·주황·빨강을 그대로 유지해야 의미가 유지됩니다.

다크 테마는 같은 토큰 이름을 `html[data-theme="dark"]`에서 다시 정의합니다.
명도만 뒤집고 색상은 같은 대역에 둡니다.

### 색을 고르는 순서

1. 글자면 → `--ink` / `--ink-soft` / `--muted`
2. 누를 수 있으면 → `--blue`, hover는 `--blue-dark`
3. 면이면 → `--surface`(페이지) → `--white`(카드) → `--paper`(카드 안 보조)
4. 짙은 면 위 포인트면 → `--mint`
5. 위 어디에도 없으면 새로 만들지 말고 가장 가까운 토큰을 쓴다.

## 3. 간격

8px 배수를 기본으로 하되, 화면 폭에 따라 줄어드는 자리는 `clamp()`를 씁니다.

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--s-1` | `4px` | 아이콘과 글자 사이 |
| `--s-2` | `8px` | 칩 안쪽, 인접한 작은 요소 |
| `--s-3` | `12px` | 폼 항목 사이 |
| `--s-4` | `16px` | 카드 안 블록 사이 |
| `--s-5` | `24px` | 카드 안쪽 여백(좁은 화면) |
| `--s-6` | `32px` | 카드 안쪽 여백(기본) |
| `--s-7` | `48px` | 구역 안 큰 묶음 사이 |
| `--s-8` | `72px` | 구역과 구역 사이 |
| `--gutter` | `clamp(18px, 4vw, 48px)` | 화면 좌우 여백 |

**정렬선**: 모든 구역은 `max(var(--gutter), calc((100vw - 1240px) / 2))`를 좌우
패딩으로 써서 세로 정렬선을 공유합니다. 플래너의 기능 카드만 1560px 기준을 씁니다.

## 4. 모서리와 그림자

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--r-sm` | `10px` | 칩, 작은 배지 |
| `--r-md` | `14px` | 버튼, 입력 |
| `--r-lg` | `20px` | 카드, 패널 |
| `--r-xl` | `clamp(20px, 2.2vw, 28px)` | 기능 구역 카드 |
| `--r-full` | `999px` | 알약형 |

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--shadow-1` | `0 2px 10px rgba(6,48,74,.06)` | 떠 있지 않은 카드 |
| `--shadow-2` | `0 16px 40px rgba(6,48,74,.055)` | 기능 구역 카드 |

그림자는 항상 파랑 기가 도는 잉크색을 씁니다. 순수 검정 그림자는 쓰지 않습니다.

## 5. 타이포그래피

글꼴은 `Pretendard → Noto Sans KR → Apple SD Gothic Neo → system-ui` 순입니다.

| 역할 | 크기 | 굵기 | 행간 |
| --- | --- | --- | --- |
| 페이지 제목 | `clamp(2.6rem, 6.3vw, 7rem)` | 900 | 1.08 |
| 구역 제목 | `clamp(2rem, 4.5vw, 3.4rem)` | 850 | 1.14 |
| 카드 제목 | `1.35rem` | 800 | 1.3 |
| 본문 | `clamp(1rem, .97rem + .12vw, 1.075rem)` | 400 | 1.65 |
| 보조 설명 | `.82rem` | 500 | 1.55 |
| 키커 | `.74rem` | 900, `letter-spacing: .16em` | 1.4 |

**한글 행간 주의**: 한글은 라틴보다 글자가 높아 `line-height: .98` 같은 값에서
줄이 서로 붙습니다. 큰 제목은 1.08 아래로 내리지 않습니다.
줄바꿈은 `word-break: keep-all`로 단어 중간에서 끊기지 않게 합니다.

## 6. 컴포넌트 패턴

### 기능 구역 카드 (`.planner-page > section`)
플래너는 기능 단위로 구역을 끊습니다. 각 구역은 독립된 카드입니다.

```
width: min(1560px, calc(100vw - var(--gutter) * 2));
padding: clamp(26px, 3.2vw, 52px) clamp(20px, 2.8vw, 46px);
border: 1px solid var(--line);
border-radius: var(--r-xl);
background: var(--white);
box-shadow: var(--shadow-2);
```

**짙은 카드**(`--ink` 배경)는 결과·탐색처럼 흐름의 매듭에만 씁니다.
현재는 `데이터 탐색`과 `내 W.A.V.E 코스` 두 곳입니다.
밝은 카드로 바꿀 때는 반드시 안쪽 글자색도 함께 바꿔야 합니다.
(과거에 배경만 바꿔 흰 글자가 흰 배경 위에 남은 사고가 있었습니다.)

### 랜딩 구역
랜딩은 반대로 **배경을 나누지 않습니다.** 전 구역이 `--surface` 하나를 공유하고,
구분은 여백과 타이포 위계로만 만듭니다.

### 이미지 위 정보
사진 위에 글자를 얹으면 반드시 스크림을 깝니다.

```
background: linear-gradient(180deg, transparent 30%, rgba(4,32,47,.34) 62%, rgba(4,32,47,.68));
```

### 칩 / 배지
알약형(`--r-full`), 최소 높이 32px, 테두리 `--line`, 배경 `--white`.
접근성 편의 항목은 앞에 `✓`를 붙여 색 없이도 의미가 전달되게 합니다.

### 버튼
- 주요: 배경 `--blue`, 글자 흰색, `--r-md`, 최소 높이 48px
- 보조: 테두리 `--line`, 글자 `--ink-soft`, 배경 투명
- 파괴적 동작은 이 서비스에 없습니다.

## 7. 아이콘

접근성 조건 6종은 [`components/AccessIcons.tsx`](../components/AccessIcons.tsx)의
SVG 세트를 씁니다. 이모지나 유니코드 기호(`♿ ◌ ♧`)는 쓰지 않습니다.
글꼴에 따라 모양이 달라지고, 화면 낭독기가 읽는 방식도 제각각이기 때문입니다.

- 격자 24×24, 선 두께 1.8, `stroke-linecap: round`
- 색은 `currentColor`를 상속받아 어느 면에서나 쓸 수 있게 합니다
- 장식용이면 `aria-hidden`, 의미를 담으면 `<title>`을 넣습니다

| 이름 | 뜻 |
| --- | --- |
| `wheel` | 휠체어 이용 |
| `senior` | 걷기 불편 |
| `baby` | 영유아 동반 |
| `pregnant` | 임산부 |
| `visual` | 시각 정보 지원 |
| `hearing` | 청각 정보 지원 |

## 8. 모션

| 상황 | 지속 | 곡선 |
| --- | --- | --- |
| 색·테두리 변화 | `.2s` | `ease` |
| 위치 이동, 등장 | `.28s` | `cubic-bezier(.16,1,.3,1)` |
| 구역 전환 | `.55s` | `cubic-bezier(.22,1,.36,1)` |

**인트로**(첫 방문 5초)는 `components/WaveField.tsx`가 그립니다.
파도 → 무장애 심볼 → W.A.V.E 워드마크 순으로 문자 하프톤 형상이 물결 위에 맺힙니다.
서비스가 누구를 위한 것인지 문장 없이 형상만으로 먼저 보여 주기 위한 순서입니다.
`sessionStorage`로 한 세션에 한 번만 뜨고, 언제든 건너뛸 수 있습니다.

## 9. 반응형

| 폭 | 기준 |
| --- | --- |
| `> 1180px` | 기본 다단 |
| `≤ 1180px` | 플래너 좌우 2단 → 1단 |
| `≤ 1100px` | 랜딩 히어로·지역·근거 구역 1단 |
| `≤ 960px` | **창 절반 화면.** 카드가 화면 폭을 채우고 제목 크기가 줄어듦 |
| `≤ 900px` | 헤더 메뉴 숨김, 로그인 페이지 상하 분할 |
| `≤ 620px` | 단일 열, 푸터 중앙 정렬 |

1920 모니터를 절반으로 쓰면 960px입니다. 이 폭에서 무너지지 않는지를
새 화면을 만들 때마다 확인합니다.

## 10. 성능 기준

문자 하프톤 파도는 화면당 셀이 2만 개를 넘습니다. 셀마다 캔버스 명령을 부르면
프레임당 55ms가 나와 20fps로 떨어집니다. 그래서:

- 밝기 단계별 문자를 **배경까지 합성한 픽셀 배열**로 미리 만들어 두고
- 프레임마다 프레임 버퍼에 복사한 뒤 `putImageData`를 **한 번만** 호출합니다
- 사인은 4096칸 룩업 테이블로 대체하고, 행에만 의존하는 값은 열 루프 밖으로 뺍니다

현재 프레임당 6.4ms, 1440×900·1920×1080·960×1040 모두 60fps입니다.
캔버스를 손볼 때는 이 수치를 기준으로 회귀를 확인합니다.
