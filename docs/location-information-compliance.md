## 1. 상담 결론

위치정보지원센터는 서비스의 유·무료 여부, 공모전 출품 여부, 운영 주체의 법인 여부만으로
신고 대상을 정할 수 없으며 실제 개인위치정보 처리와 제공 기능을 종합해 판단해야 한다고
회신했다.

- 사용자의 현재 위치를 W.A.V.E 서버에 전송·저장하지 않고 단말기에서만 이용하는 부분은
  신고 대상 판단에서 제외될 가능성이 있다.
- Kakao Maps JavaScript SDK가 지도 영역이나 접속 IP 등을 자체 처리할 수 있다는 사정만으로
  W.A.V.E 운영자를 위치기반서비스사업자로 단정할 수는 없다.
- 사용자가 직접 선택한 공개 장소·출발지·목적지 좌표가 특정 개인의 현재 또는 과거 위치를
  나타내지 않는다면 곧바로 개인위치정보 이용으로 보기는 어렵다.
- 주변 검색에서 지도 중심 좌표를 외부 제공자에게 전달하는 기능은 그 좌표가 단순 검색
  위치인지 특정 개인의 위치인지, 이용자와 결합되는지에 따라 별도 판단이 필요하다.
- 대학생 비법인 프로젝트팀이 무료로 운영한다는 이유만으로 신고 대상에서 자동 제외되지는
  않는다.
- 신고 여부와 별개로 개인정보를 처리하면 개인정보처리방침, 고지·동의, 보유·파기,
  접근통제 등 개인정보 보호조치를 따로 검토해야 한다.

센터는 법률전문가나 유권해석 기관이 아니며 최종 판단과 책임은 운영자에게 있다고 명시했다.
공식 목록은 [위치정보지원센터 질의응답](https://www.lbsc.kr/front/qna/qnaList.do)에서
#2680으로 확인한다. 비공개 답변의 접근 비밀번호는 저장소·Issue·로그에 기록하지 않는다.

## 2. W.A.V.E Release 데이터 경계

최종 Release Candidate는 다음 계약을 동시에 만족해야 한다.

1. 현재 위치 버튼을 명시적으로 누르고 사전 안내를 확인한 뒤에만 브라우저 권한을 요청한다.
2. GPS 위도·경도는 브라우저 메모리에서 현재 위치 마커를 표시하는 데만 사용한다.
3. GPS 좌표를 W.A.V.E API, Kakao·ODsay 경로/검색 API, Neon, 운영 로그, 분석 도구,
   오류 보고, URL, 쿠키 또는 `localStorage`로 전송·저장하지 않는다.
4. 경로 비교가 필요하면 사용자가 공개 출발 거점이나 공개 장소를 직접 선택하게 한다.
5. 주변 검색은 GPS와 분리된 지도 중심을 대상으로 사용자가 별도 실행할 때만 수행한다.
   현재 위치로 지도를 이동한 뒤 검색하면 GPS가 외부로 전달되는 우회 경로가 생기지
   않도록 데이터 출처를 구분하거나 해당 동작을 차단한다.
6. 위치 권한을 거부해도 지역·공개 출발지를 선택하여 핵심 여행 기능을 이용할 수 있다.
7. 지도 제공자가 지도 영역·접속 정보 등을 자체 처리할 수 있다는 사실과 W.A.V.E의 미저장
   정책, 대체 이용 방법을 권한 요청 전 안내와 개인정보처리방침에 표시한다.
8. 새 여행 시작·지역 변경·기능 취소 시 이전 위치·권한 안내·비동기 오류가 새 여행 상태를
   덮지 않도록 초기화한다.

## 3. Release Gate 완료 조건

아래 증거가 최신 최종 SHA에 모두 있어야 위치정보 항목을 완료로 표시한다.

- [ ] 정적 정책 검사에서 GPS 좌표의 서버 요청·공유·영속 저장 경로가 0건이다.
- [ ] 브라우저 네트워크 회귀에서 현재 위치 사용 중 W.A.V.E·Kakao·ODsay 요청의 URL,
      query, body, header에 GPS 좌표가 포함되지 않는다.
- [ ] 현재 위치로 지도 이동 후 주변 검색을 실행해도 GPS 좌표가 외부로 전달되지 않는다.
- [ ] 경로 비교는 공개 출발지를 별도 선택해야만 실행된다.
- [ ] 권한 허용·거부·시간초과·늦은 성공/실패·새 여행·지역 변경을 데스크톱과 모바일에서
      검증한다.
- [ ] 한국어·영어의 사전 안내, 오류 안내, 대체 이용 방법과 `aria-live` 순서를 검증한다.
- [ ] 개인정보처리방침·이용자 안내·README와 실제 코드 데이터 흐름이 일치한다.
- [ ] 최신 HEAD CI, 독립 QA, Preview 핵심 여정 검증이 성공한다.

## 4. 재검토가 필요한 변경

다음 변경은 구현 전에 위치기반서비스사업 신고 여부와 외부 제공자 약관을 다시 검토한다.

- GPS 또는 개인 이동경로를 서버나 제3자 API로 전송
- 계정·세션·기기 식별자와 좌표 결합
- 좌표·이동 이력의 저장, 분석, 추천 학습 또는 제3자 제공
- 백그라운드 위치 수집, 지오펜싱, 위치 기반 알림
- 현재 위치를 자동으로 주변 검색·경로 요청의 입력값으로 사용

신고 대상 여부를 최종 확정해야 할 때는 최신 Production 데이터 흐름도와 네트워크 증거를
기준으로 위치정보지원센터 또는 법률 전문가에게 다시 확인한다.
